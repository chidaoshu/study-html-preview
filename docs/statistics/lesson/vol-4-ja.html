微分：計算ができれば大丈夫！

期末試験（8/4）の微分は、証明ではなく計算ができるかが問われます。本ページは「解法ツール」として再構成されており、まずは公式の形を確認し、難易度順の例題チェーンで計算力を身につけます。各問題で「式の問題特徴 → どの公式を使うか → 各ステップで何をすべきか」を省略せずに丁寧に解説しています。

§0 · まず体感してみよう

微分＝「傾き」を求めるマシン

微分（びぶん / derivative）とは、「この曲線はある点においてどれくらい急か？」という問いに答えるツールです。スライダーを動かして、y = x2 の接線の傾きが位置によってどのように変化するか観察してみましょう。読み取り値は常に 2x に等しくなります。

この点での傾き（接線の傾き）
2.0
2 × 1.0 = 2.0
x = −20x = 2
2つの問われ方を混同しない問題文の読み取り：求められているのは「関数」か「数値」か
問題文の表現求めるもの解法アプローチ
「微分してください」
「導関数を求めよ」		関数（導関数）公式を適用し、f′(x) を求めて完了
「x = □ における接線の傾き」数値まず導関数を求め、その後に x の値を代入する（§5参照）

曲線上の点ごとに急傾斜具合（傾き）は異なります。そのため、微分した結果は単一の数値ではなく新しい関数――導関数（どうかんすう / derivative）になります。導関数は「傾きを計算するマシン」であり、傾きを知りたい点の x を入力すると、その点における接線の傾きを出力します。

重要度：🔴 試験でやることは2つだけ――① 導関数を求める（§1〜§4、§6） ② 代入して傾きを計算する（§5）
§1 · 基本の土台

基本ルール（これらをマスターすれば半分以上クリア）

5つのルール ①〜⑤ について、まずは公式の形を確認し、例題チェーンで演習しましょう。試験の多項式微分問題は、すべてこれらの組み合わせです。

① べき乗則power rule / 冪乗の微分
ddx xn = nxn−1
ポイント：指数を前に出して係数にし、指数自体は 1 引く
ウォーミングアップ　f(x) = x² → 2x
考え方：最も標準的なべき関数です。そのまま公式を適用します。（ノート 1.2 例2 で微分の定義から証明されていますが、試験では公式 ① を直接適用すれば OK です。）
公式適用指数 2 を前に出し、1 引く → 2x2−1 = 2xこれは §0 のスライダーの読み取り値 2x と一致します
ノート 1.2 例3　f(x) = x³ → 3x²
考え方：前問との違いは指数が 2 から 3 に変わった点のみです。手順は全く同じです。
公式適用指数 3 を前に出し、1 引く → 3x3−1 = 3x2
問題集 ドリル4　f(x) = x¹⁰⁰ → 100x⁹⁹
考え方：前問との違いは指数が非常に大きくなった点のみです。ルールは変わらず、どれだけ大きな数でも同様に前に出します。
公式適用指数 100 を前に出し、1 引く → 100x99
問題集 ドリル3　f(x) = 1/x → −1/x²
考え方：今回は先に式変形を行います。分母にある x を分子に持ってくると負の指数になります：1/x = x−1。その後、公式 ① を適用します（n は負の数でも成り立ちます）。
式変形1x = x−1分母から分子へ移動 → 指数が負になる
公式適用指数 −1 を前に出し、1 引く → −1·x−1−1 = −x−2 = −1x2負の数も同様に前に出します。−1 から 1 引くと −2 になります（0 ではありません）
重要度：🔴 すべての微分の基礎です。負の指数への変形は頻出の試験ポイントです
② 定数は消えるconstant rule / 定数の微分
ddx c = 0
ポイント：x を含まない単独の定数は、微分すると 0 になる
問題集 ドリル2　f(x) = 15 → 0
考え方：15 は固定された定数です。グラフに描くと水平線になり、どこでも傾きがないため、傾きは常に 0 です。
公式適用式中に x が含まれない → 0水平線の傾きは 0 です（ノート 1.2 例5：f(x)=2→0 に対応）
問題集 ドリル20（引っ掛け問題）　f(x) = e² → 0
考え方：一見すると指数関数に見えますが、罠です。指数部分を見ると x ではなく数字の 2 になっています。e も 2 も定数なので、e2 ≈ 7.39 全体が1つの定数です。
確認e2 には x が含まれないeˣ（指数が x）と混同しないようにしましょう（ルール ⑤ 参照）
公式適用定数なので → 0
重要度：🔴 「x が含まれているかどうか」が唯一の判断基準です。e² のような引っ掛けに注意しましょう
③ 定数倍はそのままconstant multiple / 定数倍の微分
ddx {c·f(x)} = c·ddxf(x)
ポイント：係数はそのまま残し、x の部分だけを微分する
ウォーミングアップ　f(x) = 2x² → 4x
考え方：係数 2 はそのまま残し、x² の部分にだけ公式 ① を適用します。
係数を出す2·ddx[x2]2 を微分の外に出す
公式①適用2 × 2x = 4x
問題集 ドリル7　f(x) = ½x² → x
考え方：前問との違いは係数が分数 ½ になった点のみです。手順は同じで、最後に ½ と公式 ① で降りてきた 2 が約分されます。
係数を出す12·ddx[x2]
公式①適用12 × 2x = x½ × 2 = 1 となり約分される
問題集 ドリル13　f(x) = ax² → 2ax（a は定数）
考え方：前問との違いは係数が文字 a になった点です。a は定数と指定されているので、数字と同様にそのまま残します。
係数を出すa·ddx[x2]a には x が含まれないため係数扱い
公式①適用a × 2x = 2ax
重要度：🔴 文字の係数（a や ½）も数値の係数と全く同じように扱います
④ 和は別々にsum rule / 和の微分
ddx {f + g} = ddxf + ddxg
ポイント：「＋」「−」で結ばれた項は分解し、各項ごとに微分して最後に足し合わせる
ウォーミングアップ　f(x) = x² + 2x + 10 → 2x + 2
考え方：3つの項が加算でつながっているため、3つに分解してそれぞれ既出のルールを適用します。
項ごとに分解ddx[x2] + ddx[2x] + ddx[10]
各項を計算2x + 2 + 0x²→2x（①）；2x→2（③+①）；10→0（②）
まとめる2x + 2定数 10 は消滅します
ノート 1.3 例1　f(x) = 2x² + 10x → 4x + 10
考え方：前問との違いは各項に係数がついている点です。講義ノートのようにステップを丁寧に分けて計算しましょう。
項ごとに分解ddx[2x2] + ddx[10x]
係数を出す2ddx[x2] + 10ddx[x]2 と 10 を外に出す（③）
公式①適用2×2x + 10×1
まとめる4x + 10
ノート 1.3 例2　f(x) = 2x² + 3x + 5 → 4x + 3
考え方：前問との違いは末尾に単独の定数項 5 がついてい点です。x を含んでいないためルール ② により 0 になります。
項ごとに分解ddx[2x2] + ddx[3x] + ddx[5]
各項を計算4x + 3 + 02x²→4x；3x→3；5→0
まとめる4x + 3
ミス注意：定数項 +5 は微分すると消滅するため、答えに「+5」を残してはいけません。3x には x があるので係数 3 が残り、5 には x がないので 0 になります。「x があれば次数を下げて係数を残し、x がなければ 0」と覚えましょう。
⑤ eˣは自分のままexponential / 指数関数の微分
ddx ex = ex
ポイント：eˣ は微分しても形の変わらない特別な関数

ノート 1.3 例3 でマクローリン展開（テイラー展開）を用いて導出されています（導出過程 ⚪ はスキップ可、結論 🔴 は必須記憶）。指数が純粋な x である場合のみそのままになります。
指数部分に「何か塊が乗っている」場合――e−x、e2x、e−x² など――は §3 の合成関数の微分を使います。また、指数が定数の e2 は定数なので 0 になります（ルール ②）。

3つのパターンの識別：ex → そのまま（⑤）；e2 → 0（②、定数）；e−x → −e⁻ˣ（パターンA、§3参照）。指数に x があるか、純粋な x かを見極めましょう。
§2 · 2つの関数の積

積の微分

せきのびぶん / product rule ―― 両方の塊に x が含まれており、展開できない場合に使います。

公式前・後 2つの積の微分
(前·後)′ = 前′·後 + 前·後′
ポイント：前を微分×後そのまま ＋ 前そのまま×後を微分
典型的な誤り：積の微分は決して 前′·後′ ではありません！必ず2つの項の和になります。1項しか書かないと半分失点します。
ノート 1.3 例4　f(x) = x·eˣ → eˣ + x·eˣ
考え方：x と eˣ の両方に x が含まれており、展開できません。そのため積の微分公式が必須です。
塊に分ける前 = x，　後 = ex
前微分×後そのまま1 · ex = ex前 x→1（①）；後そのまま
前そのまま×後微分x · ex = xex前そのまま；後 eˣ→eˣ（⑤）
足し合わせるex + xex因数分解して (1+x)eˣ と書いても正解です
問題集 ドリル10（効率的な解法との比較）　f(x) = (x+1)(x−1) → 2x
考え方：かっこ同士の積なので積の微分が使えそうですが、先に展開した方が圧倒的に簡単です。(x+1)(x−1) = x²−1 とすれば、§1 の基本問題に変わります。
展開する(x+1)(x−1) = x2 − 1平方の差の公式
項ごとに計算2x − 0 = 2xx²→2x（①）；−1→0（②）

判断基準：eˣ が掛け合わされているなど展開不可能な場合にのみ積の微分を使い、多項式同士の掛け算は先に展開するのが簡単で計算ミスも防げます。

重要度：🔴 「いつ積の微分を使うべきか」と「いつ展開すべきか」を判断できるようにしましょう
§3 · 関数の入れ子構造

合成関数の微分（置換の考え方）

ごうせいかんすう / chain rule ―― 指数、かっこ内、分母などに「塊（関数）」が入り込んでいる場合に使います。

公式（2-1）全体の傾き ＝ 外側の微分 × 内側の微分

x が g によって z になり、z が f によって y になる構造：x ─g→ z ─f→ y。z = g(x)，y = f(z) とおくと：

dydx = dydz × dzdx

歯車の例え：x、z、y を噛み合う歯車と考えます。x が 1 回転すると z が dz/dx 回転し、z が 1 回転すると y が dy/dz 回転します。したがって x が 1 回転したときの y の回転数は「2つの伝達比の掛け算」になります。

ポイント：まず外側を微分し、それに内側の微分を掛ける（変数置き換え → 外側微分 → 内側微分 → 掛け合わせて x に戻す）

試験に出る合成関数は主に2つのパターンがあります。パターンA「e の肩に塊」、パターンB「かっこの n 乗」。それぞれの解法に慣れましょう。

パターンA：e の肩に塊がある場合e塊 → e塊 × 塊′
ddx e塊 = e塊 × 塊′
ポイント：e塊 の部分はそのまま書き、そこに「指数部分（塊）の微分」を掛ける
ウォーミングアップ　f(x) = e²ˣ → 2e²ˣ
考え方：指数の肩に乗っている塊は 2x です。外側の eᶻ はそのまま残し、塊の微分を掛けます。
塊′塊 = 2x，塊′ = 2
パターンA適用e2x × 2 = 2e2x
ノート 2.1 例2（置換による完全解説）　f(x) = e⁻ˣ → −e⁻ˣ
考え方：前問との違いは塊 = −x とマイナスがついている点です。置換を行って「外側×内側」の構造をしっかり確認しましょう。
変数置換z = −x，　y = ez
外側の微分dydz = ezeᶻ を微分してもそのまま（⑤）
内側の微分dzdx = −1z = −x を微分すると −1
掛け合わせ・戻すez × (−1) = −e−x
最頻出のミス：符号のつけ忘れに注意！「e の微分は変わらない」と丸暗記して e⁻ˣ と答えてしまうミスが多発します。内側の微分である −1 を必ず掛けなければなりません。e⁻ˣ は統計学（正規分布やシグモイド関数）で頻出します。
問題集 ドリル19　f(x) = e²ˣ⁺³ → 2e²ˣ⁺³
考え方：前問との違いは塊 = 2x+3 と定数 3 が追加されている点です。塊′ の計算で 3 は 0 になるため 2 だけが残ります。
塊′塊 = 2x+3，塊′ = 22x→2，3→0（②）
パターンA適用e2x+3 × 2 = 2e2x+3
問題集 確認2-3　f(x) = e⁻ˣ² → −2x·e⁻ˣ²
考え方：前問との違いは塊 = −x² となり、塊′ が数値ではなく x を含む −2x になる点です。この形（正規分布の基礎）は今後頻繁に登場します。
塊′塊 = −x2，塊′ = −2xx²→2x（①）、前のマイナスを残す
パターンA適用e−x² × (−2x) = −2x·e−x²
重要度：🔴 パターンA は統計学で最もよく使われる微分です。負の符号と 塊′ の掛け忘れに注意しましょう
パターンB：かっこの n 乗(塊)n → n(塊)n−1 × 塊′
ddx (塊)n = n(塊)n−1 × 塊′
ポイント：かっこ全体を 1 つの変数としてべき乗則を適用し、最後に「かっこ内の微分」を掛ける
ノート 2.1 例1（置換による完全解説）　f(x) = (x−5)² → 2(x−5)
考え方：かっこ内が単なる x ではないため合成関数です。内側＝かっこ内 x−5、外側＝2乗として置換します。
変数置換z = x−5，　y = z2
外側の微分dydz = 2zz² にべき乗則を適用（①）
内側の微分dzdx = 1x→1，−5→0 より 塊′=1
掛け合わせ・戻す2z × 1 = 2(x−5)

ポイント：ここでは 塊′=1 のため掛けても値が変わりませんが、「常に 塊′ を掛ける」習慣をつけることで、塊′≠1 の問題でもミスを防げます。

問題集 ドリル8　f(x) = ½(x−5)² → x−5
考え方：前問との違いは前に係数 ½ がついている点だけです（③ で外に出す）。最後に ½ と外側の微分で降りてくる 2 が約分されます。
係数を出す12·ddx(x−5)2
パターンB適用12 × 2(x−5) × 1 = x−5½ × 2 = 1，塊′=1
問題集 確認2-5　f(x) = (x²+x+1)² → 2(2x+1)(x²+x+1)
考え方：前問との違いはかっこ内が x²+x+1 となっており、塊′ = 2x+1 が 1 ではない点です。この 塊′ を掛け忘れると不正解になります。
塊′塊 = x²+x+1，塊′ = 2x+1各項：x²→2x，x→1，1→0
パターンB適用2(x²+x+1)1 × (2x+1) = 2(2x+1)(x²+x+1)
ミス注意：かっこ内が単なる x でないときは、塊′ を 1 と決めつけないようにしましょう。
ノート 2.1 例3　f(x) = 1/(x+1) → −1/(x+1)²
考え方：分母が単なる x ではなく「塊」になっています。まず 1/(x+1) = (x+1)−1 と指数形式に変形することで、n=−1 のパターンBとして扱えます。
式変形1x+1 = (x+1)−1
パターンB適用−1·(x+1)−2 × 1n=−1 を前に出し、1 引いて −2 にする；塊′=1
整理する−1(x+1)2

ポイント：「マイナス符号 ＋ 分母の2乗」の形は、§6 のシグモイド関数の微分問題でも再登場します。

重要度：🔴 パターンB は「かっこの2乗」や「分数の逆数」を網羅しており、塊′ の計算が命です
§4 · 2変数以上の関数

偏微分

へんびぶん / partial derivative ―― 式の中に x と y など複数の変数が含まれる場合の微分です。

ルールターゲットの変数のみに着目し、他の変数は数字として扱う
講義ノートの重要ポイント 🔴：x について偏微分する＝ y をただの数字（定数）とみなして普通に微分する

記号は d ではなく ∂（「ラウンド」「パーシャル」と読む）を使用し、「多変数関数のうち1つの変数だけで微分する」ことを示します。
計算のコツ：x で偏微分する場合、y を具体的な数字（例えば 3）だと思い込んで、§1〜§3 のルールをそのまま適用します。y が単独の項なら定数として 0 になり（②）、x に掛け合わされていれば係数としてそのまま残ります（③）。

ノート 3.1 例1 準備 · 問題集 確認1　f(x,y) = x + y → 1（x について）
考え方：ウォーミングアップです。y を数字とみなすと、x→1、y（x を含まない）→0 となります。
項ごとに計算1 + 0 = 1x→1（①）；y は定数扱い→0（②）
問題集 確認4　f(x,y) = y → 0（x について）
考え方：前問との違いは式全体に x が全く含まれていない点です。全体が1つの定数扱いになります。
公式②適用x が含まれない → 0
問題集 確認3　f(x,y) = xy → y（x について）
考え方：前問との違いは x と y が掛け合わされている点です。y を数字とみなすと xy は「3x」のようなものです。係数 y を残して x→1 とします。
係数を出すy·∂∂xxy を係数扱いにする（③）
公式①適用y × 1 = y
ノート 3.1 例1　f(x,y) = x² + xy → 2x + y（x について）
考え方：基本ルールを組み合わせます。加算で分解し、各項を処理します（y=3 と考えると x²+3x の微分と同じです）。
項ごとに分解∂∂xx2 + ∂∂x(xy)
各項を計算2x + yx²→2x（①）；xy→y（③+①、前問参照）
まとめる2x + y
ノート 3.1 例2　f(x,y) = x²y → 2xy（x について）
考え方：前問の xy と同様に、x が x² になっただけです。「係数 y × x²」として扱います（y=3 と考えれば 3x² の微分と同じです）。
係数を出すy·∂∂xx2
公式①適用y × 2x = 2xy
ミス注意：x²y に対して積の微分を使おうとしないでください。y は関数ではなく定数です。（積の微分を使っても 2x·y + x²·0 = 2xy となりますが無駄な計算になります。）
問題集 確認5　f(x,y) = x² + 2xy + y² → 2x + 2y（x について）
考え方：例1と同様のパターンに y² が追加されています。y² は x を含んでいないため 0 になります。
分解して計算2x + 2y + 0x²→2x；2xy→2y（係数 2y を残し x→1）；y²→0（②）
まとめる2x + 2y
ノート 3.1 例3　f(x,y) = 1/ex+y → −e⁻ʸ·e⁻ˣ　※ やや発展 ⚪、複合テクニック

§5 · 得点源の問題

接線の傾き（2ステップ法）

せっせんのかたむき / tangent slope ―― 求められているのは「関数」ではなく「数値」です。

決まった2ステップ導関数を求める → 数値を代入する
STEP 1まず§1〜§4の公式を使って導関数 f′(x) を求める。
STEP 2問題文で指定された x の値を f′(x) に代入し、数値を計算する。
ポイント：STEP 2 を忘れずに！導関数を求めるだけで代入を行わないと途中で終わってしまいます
問題集 確認1-1　f(x) = 2x²，x = −1 における傾き → −4
考え方：標準的な2ステップです。まず導関数を求め（§1 ③+①）、次に x=−1 を代入します。
STEP 1 導関数f′(x) = 4x2x²→4x
STEP 2 代入f′(−1) = 4×(−1) = −4傾きが負 → 曲線はこの点で右下がりになっています
ミス注意：負の数を代入するときは必ずかっこをつけましょう。例えば導関数に 2 乗が含まれる場合、(−1)² = +1 となりますが、かっこを付け忘れると符号ミスを起こします。本問は 4×(−1) = −4 となります。
重要度：🔴 確実に得点できる2ステップです。STEP 2 の代入漏れと負の数のかっこ付けに気をつけましょう

シグモイド関数 / sigmoid ―― 機械学習の定番であり、問題集の大題プロトタイプです。使用する個別テクニックはすべて練習済みです。

定番の4ステップ
考え方：分母が「塊」なので、まず −1 乗に変形して §3 パターンB にあてはめます。途中で e⁻ˣ の微分に §3 パターンA を使用します。いずれも既出の要素技術です。
