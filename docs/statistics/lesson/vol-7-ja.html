§0 · 基礎知識

3つの概念：試行 → 事象 → 基本事象

この3つの用語は本冊すべての基礎であり、概念問題の土台となります。まずは概念カードで全体像を把握し、ノートの3つの例を通して「基本事象」のカウントをマスターしましょう。

試行→ しこう / trial / 試行：「実験や観測を行う」動作のこと。例：サイコロを1回振る、コインを2枚投げる、魚の長さを測る。
事象→ じしょう / event / 事象：試行によって起こる「結果・出来事」のこと。例：偶数の目が出る、1の目が出る、コインの表が出る。
基本事象→ きほんじしょう / elementary event / 基本事象：これ以上分割できない最小単位の事象。例：1の目が出る、2の目が出る…（「偶数の目が出る」はさらに分割できるため基本事象ではない）。
同義語に注意：基本事象 ＝ 根元事象（こんげんじしょう）。試験ではどちらの表記でも正解となります。
さらに分割可能な事象（例：「偶数の目が出る」＝「2の目」または「4の目」または「6の目」）を 複合事象（composite event） と呼びます。 以下の3つの例はすべてノート1.1からの抜粋です。基本事象の個数が 2 → 6 → 4（次元上昇）と変化していく流れを確認しましょう。
具体例：基本事象と複合事象の違いノート 1.1 例1〜例3
例1 導入 · ノート 1.1 例1  |  コイン投げ（コインを1回投げる）
この例のポイント：最小単位の基本事象（2つのみ）の構造と、複合事象における「または」と「かつ」の意味を理解します。
基本事象表面が出る、裏面が出る計 2 個（これ以上分割不可）
複合「または」「表面が出る または 裏面が出る」「または」＝いずれか一方が成立すればよい
複合「かつ」「表面が出る かつ 裏面が出る」「かつ」＝両方が同時に成立する（1枚のコインで同時に表裏は出ないため空事象）
例2 · ノート 1.1 例2  |  六面サイコロ（サイコロを1回振る）
この例のポイント（例1からのステップアップ）：基本事象が 2 個から 6 個 に増えます。「複合事象 ＝ 基本事象の組み合わせ」であることを、「偶数の目が出る」を分解して確認しましょう。
基本事象1の目が出る、2の目が出る、3の目が出る、4の目が出る、5の目が出る、6の目が出る計 6 個
複合「偶数」偶数の目が出る ⇔ [2の目が出る] または [4の目が出る] または [6の目が出る]1つの複合事象 ＝ 3つの基本事象のまとめ
複合「4以上」4以上の目が出る ⇔ [4の目が出る] または [5の目が出る] または [6の目が出る]

ここが重要：「これ以上分割できるかどうか」が基本事象と複合事象の境界線です。「偶数の目」は2・4・6に分解できるので複合事象、「2の目」は分解できないので基本事象です。

例3 · ノート 1.1 例3  |  2枚の区別できるコイン
この例のポイント（例2からのステップアップ）：1つの対象（1次元）から2つの対象（2次元）へと広がります。基本事象は順序対で表記し、(表, 裏) と (裏, 表) は異なる2つの基本事象となります（これが§3の 6×6=36 の基礎となります）。
表記の約束(1枚目, 2枚目)1枚目が表、2枚目が裏の場合は (表, 裏) と略記
基本事象(表, 表) (表, 裏) (裏, 表) (裏, 裏)計 4 個（＝ 2 × 2）。(表, 裏) ≠ (裏, 表) であり、順序が違えば別の事象
複合「少なくとも表1枚」(表, 表) または (表, 裏) または (裏, 表)少なくとも表面が1枚出る ＝ 3 個
複合「両方同じ面」(表, 表) または (裏, 裏)両方同じ面が出る ＝ 2 個

つまずきやすい点：コイン2枚の場合、結果は 2 + 2 ＝ 4（足し算）ではなく、 2 × 2 ＝ 4（掛け算のペアリング）です。「区別できる ＝ 順序対 ＝ 積の法則」という考え方は、§3のサイコロの問題でもそのまま使います。

重要度：🔴 試行 / 事象 / 基本事象 / 複合事象 を明確に区別し、「分割可能かどうか」を判定の基準とすること
§1 · 用語の整理

4つの用語速査（定義問題の対策）

問題集の確認問題1（問題1〜4）は「定義から用語名を答える」形式です。1対1で暗記すれば確実に得点できます。特に混同しやすい「排反」と「独立」は、まずイメージで掴み、§2で詳しく解説します。

定義（問題文の表現）解答（用語）English
分割できない最小単位の事象基本事象 / 根元事象elementary event
分割可能な事象複合事象composite event
同時に起こらない事象排反事象exclusive event
無関係に起こる事象独立事象independent event

記憶のコツ（混同しやすい2つの概念）：

排反「両立不能・同時に起きない」——2つの事象が同時に起こり得ない関係。「同時に起こるか？」に着目。
独立「互いに無関係・影響し合わない」——一方の生起がもう一方の確率に影響を与えない関係。「影響があるか？」に着目。
重要度：🟡 用語の定義を暗記すること。排反と独立は異なる次元の概念であるため、混同しないように注意
§2 · 最重要ポイント

排反 vs 独立（期末試験の超重要判定問題）

問題集の問題5では、各シナリオにおいて「排反か否か」と「独立か否か」の両方を同時に判断する必要があります。これらは全く異なる2つの視点（同時発生できるか / 影響を与えるか）に基づいている点に注意しましょう。

2つの視点による判定カードどの視点で考えているかを意識する
視点 A：排反かどうか？

「同時に起こり得るか？」を確認

同時に起こり得る → 排反ではない
同時に起こらない → 排反である
判定方法：重複するケースを探す。両方が同時に成立する結果が存在すれば「非排反」
視点 B：独立かどうか？

「一方の生起が他方の確率に影響を与えるか？」を確認

明確に影響しない → 独立である
問題文に記載がない → 独立かどうかはわからない
情報がない場合は安易に「独立」と決めつけない
シナリオ① 基本例 · ノート 1.2 例1  |  1つのサイコロ：「偶数の目」vs「奇数の目」→ 排反
この例のポイント：「排反」の典型的な正例です。「重複を探す」方法で判定しましょう。偶数であり、かつ奇数でもある出目は存在するか？
重複の確認1〜6の出目のうち、偶数かつ奇数である目は存在しない同時に成立するケースが存在しない
結論重複なし → 排反事象である
シナリオ② 反例 · ノート 1.2 例2  |  1つのサイコロ：「1の目」vs「奇数の目」→ 非排反
この例のポイント（例1からのステップアップ）：ノートで示された重要な反例です。名前が違うからといって安易に排反だと判断してはいけません。「ケースの重複があるか」を確認します。「1の目」は奇数でもあるため、1が出たときに両方の事象が同時に成立します。
重複の確認「1の目が出た」とき：「1の目が出た」も「奇数の目が出た」も同時に成立1 は奇数に含まれるため、重複が存在する
結論重複あり（同時に起こり得る）→ 排反事象ではない

例1との比較（重要）：①「偶数 vs 奇数」は互いに排他で重複なし → 排反。②「1の目 vs 奇数」は名前は異なりますが重複がある → 非排反。「事象の名称」ではなく「結果の重複の有無」だけで判断します。

速解のコツ：同じサイコロ・コインの2つの結果 → 排反 ＋ 独立ではない ／ 2つの異なるサイコロ・コイン → 排反ではない ＋ 独立かどうかはわからない
シナリオ③ 実践 · 問題集 問題5  |  5つの設問を速解コツ＋2つの視点で解答
この例のポイント（実践への応用）：①②の「重複探索」をさらに深め、「排反（A/B）」と「独立（C/D/E）」の組み合わせを判定します。対象が「同じ1つの物体」か「2つの異なる物体」かが判別の分かれ目です。
(1) 1つのサイコロ偶数の目 vs 奇数の目 → 1回の試行で同時に出ない → A. 排反事象である ＋ D. 独立事象ではない
(2) 1枚のコイン表が出た vs 裏が出た → 上記と同様、1枚で同時に出ない → A. 排反事象である ＋ D. 独立事象ではない
(3) 2つのサイコロサイコロ1が偶数 vs サイコロ2が奇数 → 異なる2つのサイコロで同時に成立可能 → B. 排反事象ではない ＋ E. 独立事象かどうかはわからない
(4) 2つのサイコロサイコロ1が偶数 vs サイコロ2が偶数 → (3)と同様、同時に成立可能 → B. 排反事象ではない ＋ E. 独立事象かどうかはわからない
(5) 2枚の硬貨100円が裏 vs 10円が表 → 異なる2枚の硬貨 → B. 排反事象ではない ＋ E. 独立事象かどうかはわからない

なぜ(1)(2)は「独立事象ではない」となるのか？1つの同じ対象において、一方が起きると他方は絶対に起きない（同時に起きない）ため、「互いに無関係に起きる」という独立の定義を満たさないからです。

なぜ(3)(4)(5)の独立性は「独立である」ではなく「わからない」になるのか？（深掘り解説）
独立の定義は「一方の生起が他方の生起する確率に影響を与えないこと」です。独立であると断定するには、2つの物体が互いに影響を及ぼさないという保証が必要です。しかし問題5の文面では、2つのサイコロや硬貨の出目が相互に影響するかどうかについて一切言及されていません。情報が不足しているため、勝手に独立だと断定することはできず、「わからない」と答えるのが数学的に厳密な解答となります。日常の直感で「独立」と答えると失点するトラップです。条件の記述がない ＝ 決めつけずに E を選択。
重要度：🔴 排反は「重複があるか」、独立は「影響があるか」で判定する。影響についての記述がない場合は「わからない」を選択すること

§4 · 核心概念

確率変数（概念問題の中心テーマ）

確率変数（random variable）は、名前に「変数」とついていますが、実際には「関数（対応規則）」のことです（ノートでもこの紛らわしさについて触れられています）。ノート2.2〜2.4に登場する6つの例を通して、基礎から四則演算、標本平均、連続型確率変数までの流れを網羅します。

定義カードノート 2.1
確率変数 ＝ 「試行の結果（事象）」を「実現値（数値）」に対応させる規則（関数）
ポイント：事象を数値に変換する翻訳機（通常は大文字 X などで表記する）

「関数なのに変数」と呼ばれる理由：「事象を入力すると数値を出力する」働きを持つため本質的には関数ですが、慣例的に「変数」と呼ばれ、大文字 X などで表されます。言葉の違和感に惑わされず、その働きを理解しましょう。

2つの種類を区別する：
離散型確率変数（discrete random variable）：実現値が飛び飛びの値をとる（例：サイコロの出目 1, 2, 3…）
連続型確率変数（continuous random variable）：実現値が連続的な値をとる（例：魚の体長。小数をいくらでも細かく取れる）。「小数を連続的に取り得るかどうか」で見分けます。
具体例：確率変数 X の決め方ノート 2.2〜2.4 の6例を完全網羅

§5 · 概要の理解

Gauss 分布（式の構造と意味の理解）

Gauss（ガウス）分布 / Gaussian distribution（＝正規分布）は、魚の体長のような連続型確率変数が従う代表的な確率分布です。vol.7では複雑な積分計算は求められず、公式の形と μ, σ の意味を理解することが中心となります。

公式 (2-3) の要素分解ノート 2.4
f(x) = 1√(2πσ2) e−(x−μ)2 / 2σ2

一見複雑に見えますが、4つのパーツに分解すればシンプルです：

正規化定数1√(2πσ2)全体の定数倍。曲線下の総面積を 1 に保つための係数（vol.5の「全確率密度面積＝1」に対応）
e の指数部分e−(x−μ)2/2σ2「釣鐘型」の形状を作る部分（vol.4で学んだ e^-(x^2) の形）
μ（ミュー）平均値。釣鐘の中心の位置を表す。 x ＝ μ のとき指数が 0 となり f(x) は最大値をとる
σ（シグマ）標準偏差。分布の広がりの度合いを表す。 σ が大きいと横広がり（平べったい）、小さいと鋭く尖った形状になる
図2-1 の読み解き橙色 vs 青色

図の中で2種類のグラフ（度数分布）が重ね合わされています。いずれも中央（5付近）を頂点とする釣鐘型です：

橙色真の確率密度——母集団が持つ本当の確率分布（理論上の真値）
青色標本からの確率密度——実際に観測・サンプリングしたデータから得られた分布

重要メッセージ（§4とvol.6との関わり）：青（標本）は橙（真の分布）に近似しますが、完全には一致しません。有限の標本から推測を行う以上、標本分布は真の分布の周りで揺らぎます。これこそがシナリオ⑤の $\bar{X}$ が変動することの意味であり、統計的推測の基本原理です。
