母平均：1つの公式で全パターン攻略

期末 8/4。vol.6 の計算問題はほぼ1つの公式——母平均 μ = Σ（値 × 確率）だけで解くことができます。残るは「離散か連続か」の分類、2つの分布公式の識別、そして「密度 ≠ 確率」といった概念判定です。本ページは解法ツールごとに再構成し、各法則に難易度順の例題チェーンを配置しています。講義ノートの例題をメインとし、問題集を応用補足として網羅的に解説します。

§0 · 基礎固め

なぜ「割合 ＝ 確率」なのか

本冊すべての出発点です。講義ノートでは「10人の成績」実験からステップバイステップで導出しています（ノート 2.1〜2.2）。この導出プロセスをたどることで、後半の母平均公式が自然な結果として理解できます。

成績実験：「平均点」から生まれる「確率」ノート 2.2 の段階的導出

背景：10人の成績を評価ポイント（S=4, A=3, B=2, C=1）に換算します。10人中、ポイント1が2人、2が4人、3が3人、4が1人です。まず「5人を抽出して平均を計算する」ことから始め、この平均の式を段階的に変形していきます。

STEP 1 · 直接平均  |  ノート式 (2-1)
出発点：抽出された5人のポイントを x1, …, x5 とすると、標本平均は「すべて足して5で割る」となります。
平均の式x̄ = x1 + x2 + ⋯ + x55
STEP 2 · 同じ値でグループ化  |  ノート式 (2-2)
操作：グループごとにカウント。1つずつ足す代わりに、「ポイント k が何回現れたか」を数えます。ポイント1が n1 回、ポイント2が n2 回…… とおき、同じ値をまとめます。
グループ変形x̄ = n1×1 + n2×2 + n3×3 + n4×45分子 ＝ 各ポイント × その出現回数 の総和
STEP 3 · 「÷5」を各項に分配
操作：分解。「足してから5で割る」＝「各項を先に5で割ってから足す」。分母の5を各 nk に分配します。
各項の分解x̄ = n15×1 + n25×2 + n35×3 + n45×4
STEP 4 · 「割合」の登場  |  ノート式 (2-3)(2-4)
観察：各項の前の nk5 とは何でしょうか？それは「ポイント k の人数 ÷ 全人数」＝ ポイント k の割合（標本内の割合）です。そして、すべての割合を足し合わせると当然全体 ＝ 1 になります。
割合の確認nk5 ＝ ポイント k の割合
割合の和 = 1Σ nk5 = n15 + n25 + n35 + n45 = 1全員を足し合わせると全体になるため、割合の総和は必ず 1
STEP 5 · 標本から母集団全体へ → 「確率」  |  ノート式 (2-5)(2-6)
操作：極限をとる。標本サイズを5人から母集団全体の10人へ広げると（n を大きくする）、割合 nkn はある定数値に近づき、それを pk と書きます。この pk を「ポイント k が出現する確率」と呼びます。
割合→確率nkn → pk母集団におけるポイント k の割合が、そのまま出現確率となる
本例の計算p1=210, p2=410, p3=310, p4=110
確率の和 = 1Σ pk = 1割合の総和が 1 であり、確率も割合と同義であるため、確率の総和も 1 になる
結論：割合（ひ / 比）＝ 確率（かくりつ / probability）。本質的に同じ概念の異なる呼び名です。
Σp = 1（すべての確率の総和＝1）——「割合の総和が全体（=1）になる」ことから直接導かれる極めて重要な性質であり、正誤問題で頻出です。
重要ポイント：有限母集団は「可知」、無限母集団は「不可知」正誤問題の頻出出題点

同じ「確率」であっても、真の値を知ることができるかどうかは母集団が有限か無限かによって決まります。正誤問題で最も狙われやすい落とし穴です。

母集団例真の確率を知ることができるか理由
有限母集団10人の成績可能要素数が有限であるため、すべての要素を調べ尽くすことができ、割合＝確率が直接求まる
無限母集団サイコロ / コイン（無限回可能）不可真の割合を得るには無限回の試行が必要であり、現実には不可能なため、標本から推測するしかない
正誤問題の罠：「いかなる状況でも人間は確率分布を必ず知ることができる」は誤りです。無限母集団の真の確率は完全には知り得ません——これこそが「標本から母集団を推測する」統計的推測を学ぶ理由です。（対応：問題集 Q4 の選択肢 A）
重要度：🔴 割合＝確率、Σp=1、無限母集団は不可知——この3点を確実に暗記
§1 · 分類

確率分布の2種類：「離散型か連続型か」

問題集 Q1・Q2 で直接問われる分類です。測定値が飛び飛びの値（離散的）か連続した値（連続的）かで決まります。

測定値の性質分布の名称日文 / English具体例
離散（飛び飛びの値）確率質量関数pmf / probability mass functionサイコロの出目、コインの表裏
連続（切れ目のない値）確率密度関数pdf / probability density function魚の体長、身長
暗記のコツ：質量（mass）＝1粒1粒重みのある「粒」→ 離散；密度（density）＝連続して広がる「面」→ 連続

サイコロの目は 1, 2, 3, 4, 5, 6 しか出ず、間に「3.5の目」はありません——これを離散的（飛び飛び）と呼び、確率質量関数を用います。一方、魚の体長は 2.13 cm, 2.134 cm, 2.1349 cm…… などどんな小数値も取り得ます——これを連続的（切れ目のない値）と呼び、確率密度関数を用います。

選択肢のひっかけ注意：「確率分布関数」「累積分布関数」は本講義の対照範囲における正解用語ではありません。惑わされないようにしましょう。離散は「質量」、連続は「密度」一択です。（対応：問題集 Q1→質量, Q2→密度）
重要度：🔴 離散＝質量、連続＝密度、この対応をセットで覚える
§2 · 核心公式

★ 母平均 μ = Σ（値 × 確率）

母平均（population mean）——本冊唯一の計算公式です。§0の成績の導出も最終的にこの式に行き着きます。以下の6つの例題を通して、基本形から分数・逆算までステップアップしていきましょう。

μ = Σ x · px = （値1 × 確率1）+（値2 × 確率2）+ ⋯
覚え方：各実現値 × その確率 をすべて足し合わせる。「加重平均」と同じ構造です
間違いやすいポイント：「値 × 確率」であって、「値 × 度数（回数）」ではありません。また、確率だけを単に足すのでもありません。必ず各項で取リ得る値そのものを掛ける必要があります。
例題チェーン ①〜⑥基本 → 共通因数のくくり出し → ゼロ項 → 極端な例 → 分数 → 確率の事前計算
① 基本例 · ノート 2.4  |  成績の母平均 μ = 2.3
考え方：§0で求めた4つの確率 p1=0.2, p2=0.4, p3=0.3, p4=0.1 を用い、公式「値 × 確率 を足す」をそのまま適用します。全4項を順に代入します。
代入μ = 0.2×1 + 0.4×2 + 0.3×3 + 0.1×4
各項の計算= 0.2 + 0.8 + 0.9 + 0.4
足し算= 2.3平均ポイントが 2 と 3 の間に収まり妥当
② ノート 3.4 例1  |  公正なサイコロ μ = 3.5
①との違い：全6項 ＋ 確率がすべて等しいため共通因数をくくり出せる
考え方：サイコロの各目が出る確率はすべて 16 です（これを一様分布 / uniform distributionといいます）。全6項に共通する 16 をシグマの外にくくり出すことができます。
代入μ = 16×1 + 16×2 + ⋯ + 16×6
くくり出し= 16(1+2+3+4+5+6) = 16×21
約分= 216 = 3.5対応：問題集 Q10 同様
③ ノート 3.4 例2  |  偶数の目しか出ないサイコロ μ = 4
②との違い：「ゼロ項」が存在するため、まず全6項を書いてから確率 0 の項を消去する
考え方：確率は p1=p3=p5=0, p2=p4=p6=13 です。全6項の公式を一通り書き下し、確率が 0 の項は掛け算すると 0 になるため消去します。
全6項の列挙μ = 0×1 + 13×2 + 0×3 + 13×4 + 0×5 + 13×6
ゼロ項の消去= 13×2 + 13×4 + 13×6確率が 0 の 3 項が消滅
くくり出しと計算= 13(2+4+6) = 123 = 4
④ ノート 3.4 例3  |  イカサマサイコロ（2の目しか出ない） μ = 2
③との違い：極端なケースであり、1項しか残らず即計算完了
考え方：p2=1 で、残りはすべて 0 です。ゼロ項消去のテクニックを極限まで推し進めると、6項のうち「2の目の項」しか残りません。
1項のみ残留μ = 1×2 = 2100% 2が出るため、平均も当然 2 となる
⑤ 問題集 Q9  |  歪んだサイコロ μ = 56/15
これまでの例との違い：確率が分数で与えられており、主な作業は「通分」
考え方：確率は分数で与えられています：p1=160, p2=1960, p3=112, p4=14, p5=16, p6=16。公式は変わらず、各項の「値×確率」を計算してから分母を 60 に通分して相加します。
立式μ = 1·160 + 2·1960 + 3·112 + 4·14 + 5·16 + 6·16
分母を60に通分160 + 3860 + 1560 + 6060 + 5060 + 60603·1/12=15/60；4·1/4=60/60；5·1/6=50/60；6·1/6=60/60
分子の和= 1+38+15+60+50+6060 = 22460
約分= 5615分子・分母を 4 で割る
⑥ 問題集 Q8  |  箱の中のボール μ = 1/2
⑤との違い：確率が直接与えられていないため、先に「個数 ÷ 総数」で確率を求める
考え方：箱の中に赤2個、青3個、緑1個の合計6個が入っています。得点は赤 −1点、青 1点、緑 2点です。確率は問題文に書かれていないため、まず「各色の出現確率 ＝ その色の個数 ÷ 総数6」を自分で計算し、その後で公式に代入します。
確率の算出赤 26, 青 36, 緑 16個数 ÷ 総数 6
公式への代入μ = (−1)·26 + 1·36 + 2·16
足し算= −2+3+26 = 36 = 12
「標本平均」との混同に注意（Q8〔2〕）：非復元抽出で実際に赤2個、青1個を取り出した場合、問われているのは標本平均 x̄ です。その場合は実際に取り出されたデータを直接平均します：x̄ = (−1)+(−1)+13 = −13。
母平均 μ は「確率」を使い、標本平均 x̄ は「抽出されたデータ」を使う——問題がどちらを求めているか慎重に読み取りましょう。
重要度：🔴 μ=Σ(値×確率) 1つの公式で Q8・Q9・Q10 をカバー。ゼロ項消去、通分、確率の事前計算が3大ポイント

§3 · 即答テクニック

0-1 型（コイン）の即答ルール：μ = p₁

実現値が 0 と 1 のみ（コインの表裏、ダミー化）である場合、母平均には一瞬で答えが出る結論が存在します。これは §2 例題③「ゼロ項消去」の最短応用です。

導出：0の項が自動的に消滅ノート 4.3
μ = 0·p0 + 1·p1 = p1
理由：値が 0 と 1 のみであるため、公式 μ = 0·p0 + 1·p1 に代入すると、「0の項は 0 を掛けるため消滅」（§2 ③のゼロ項テクニックと同様）、直接 1·p1 だけが残ります。
結論：母平均 ＝ 「1（表）が出る確率」であり、計算不要で即答可能
基本例 · 問題集 Q11  |  p₁ = 1/3 → μ = 1/3
考え方：結論 μ = p1 を直接適用します。
結論適用μ = p1 = 130の項が消滅するため、母平均は表（1）が出る確率にそのまま等しくなる
問題集 Q12  |  公正なコイン（一様分布） → μ = 1/2
Q11との違い：確率が直接書かれておらず、「一様」から p₁ を導く
考え方：「一様分布」＝表裏の確率が等しいことを意味するので、p1=p0=12 となります。これを結論に代入します。
一様→1/2p1 = p0 = 12
結論適用μ = p1 = 12
ダミー化（dummy coding）の補足：コインの「表 / 裏」は元々数値ではないため、平均を計算できるように表 = 1、裏 = 0 と数値に置き換えます（ノート 4.1）。これにより 0-1 の数値データとなり、母平均の公式が適用できるようになります。
重要度：🔴 「0と1の2値のみ」を見たら、母平均は立式せずに即座に p₁ を書く
§4 · 識別

2つの確率分布公式（識別問題）

問題集 Q3・Q6・Q7 では選択肢から正しい公式を選ばせます。暗記するよりも、それぞれの「検証法 / 識別ポイント」を押さえる方が確実に解けます。

Bernoulli 分布（ベルヌーイ分布）0-1 型 · ノート 4.4
f(x) = p1x(1 − p1)1−x　(x = 0, 1)
検証法：x = 1 と x = 0 を実際に代入し、それぞれ p₁ と 1−p₁ が再現されるか確かめる
検証法 · 対応 問題集 Q3・Q6
考え方：指数の付け方を丸暗記しなくても、0と1を代入して確認すれば確実です。正しい公式であれば、「1が出る確率」と「0が出る確率」が正しく得られます。
x = 1 を代入p11(1−p1)0 = p1✓ 「1が出る確率」に一致
x = 0 を代入p10(1−p1)1 = 1−p1✓ 「0が出る確率」に一致
誤り選択肢の判定指数の組み合わせが不適切な式（両方 x、両方 1−x など）は代入しても p1 や 1−p1 にならない対応 Q6：D が正解、A/B/C は不可

コインの種類p0（裏）p1（表）母平均 μ = p1
若干裏が出やすい（図 4-1）0.70.30.3

Gauss 分布（正規分布）連続型・ベル型曲線 · ノート 5.4
f(x) = 1√(2πσ2) e−(x−μ)2 / 2σ2
識別3大チェックポイント：① 指数にマイナス（負号）がある ② 分子が (x−μ)² ③ 分母が 2σ²
識別法 · 対応 問題集 Q7
考え方：Q7の誤り選択肢は、上記の3大ポイントのいずれかを壊した形になっています。指数の部分を1つずつ照合しましょう。
誤りパターン1分子分母の逆転：e−2σ2/(x−μ)2(x−μ)² と 2σ² が上下逆になっている
誤りパターン2分母の二乗抜け：2σ2 ではなく 2σ になっている
誤りパターン3マイナス抜け：e+(x−μ)2/2σ2指数前のマイナスが脱落している
正解の判定3大ポイントがすべて揃っているものが正解対応 Q7：C が正解
記号とパラメータ（対応 問題集 Q14）：

記号 N(μ, σ2) で表されます。2つのパラメータが曲線全体を決定します：

パラメータ役割直感的な意味
μ（母平均）分布の中心位置中心が左右に移動
σ2（母分散）分布の広がり（形状）大きいほど低く幅広く、小さいほど高く鋭くなる
パラメータに関する解答の注意（Q14）：「Gauss分布のパラメータは何か」と問われたら、母平均 μ と母分散 σ²（または母平均と母標準偏差）と答えます。σ² と σ は相互に定まるためどちらでも可です。
重要度：🔴 Bernoulli は「0/1代入による検証」、Gauss は「マイナス・(x−μ)²・2σ²」の3大ポイントで識別
§5 · 概念の徹底理解

確率密度関数 pdf と「密度」の本質

連続型は講義全体で最も抽象的な概念であり、正誤問題（Q4・Q5）の主戦場です。「池の中の魚」の実験を通して直感を構築し（ノート 5.2〜5.3）、「密度 ≠ 確率」の理由を明確に理解しましょう。

魚の実験：「密度」はいかにして生まれるかノート 5.2 の段階的導出

背景：池の中の魚の体長は連続的（どんな小数も取り得る）です。目的は平均体長を求めることですが、連続値はサイコロのように「1つずつカウントする」ことができません。

STEP 1 · 連続値は直接数えられない → 区間に区切る
課題：魚の長さは 2.13 cm, 2.134 cm…… など無限に存在するため、特定の長さにぴったり一致する魚を数えても意味がありません。対策：長さの軸を小さな区間 Δx に分割し、「各区間に何匹の魚が入っているか」を数えます。
区間分割区間幅 Δxk、第 k 区間内の魚の数を nk とする
STEP 2 · 密度 = 割合 ÷ 区間幅  |  ノート式 (5-6)
密度の定義：区間内の魚の「割合」は nkn です。これを区間幅 Δx で割ることで、「単位長さあたりの割合」＝密度 f が定義されます。幅で割ることで、異なる幅の区間同士を公平に比較できます。
定義式f(xk) = nkn·Δxk = 区間内の割合区間幅
重要な帰結区間が十分に狭く Δx が極小のとき → f の値は > 1 となり得る割合自体は最大 1 ですが、極小の Δx で割るため、計算結果（密度）は 1 を超えることができます！
STEP 3 · 母集団全体へ拡大 → 「確率の密度」  |  ノート式 (5-9)
極限操作：釣る魚の数を無制限に増やしていくと（n → ∞）、「割合」は「確率」へと収束し、関数 f は「確率の密度」——単位長さあたりの確率の濃密さ——を表すようになります。
n→∞f(x) ＝ 確率の密度（pdf）密度そのものは確率ではなく、「確率の濃度」を表す
STEP 4 · Δx → 0 → 面積＝確率  |  ノート式 (5-12)(5-13)
極限の細分化：区間幅 Δx を 0 に限りなく近づけると、和 Σ は積分 ∫ へと変化します。このとき「密度 × 幅」で表される長方形の面積を足し合わせた曲線下の面積こそが確率となります。

導出全体の核心：密度 ≠ 確率。密度は「確率の濃度」であり、1を超えることがあります。一方、確率は密度曲線の下の特定区間の「面積」（積分によって得られる）であり、常に 1 以下です。密度が 1 を超え得るという事実こそ、両者が別物である明確な証拠です。

連続型の母平均：Σ を ∫ に置き換えるノート 5.3 / 6.2 · 対応 問題集 Q13

離散型と連続型は同じ数学的構造の別表現です。離散型は各値に確率を掛けて求和（Σ）し、連続型は各値に密度を掛けて積分（∫）します。「和 Σ → 積分 ∫」「確率 p → 密度 f(x)」の対応関係です。
