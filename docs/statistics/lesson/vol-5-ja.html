積分：微分を逆向きにたどる

期末試験（8/4）で積分は必出です。証明や導出ではなく、「実際に計算できるか」が問われます。本ページでは「解法ツール」として再構築し、「積分＝面積」という視点から、唯一の基本動作である原関数を求める → 上端・下端を代入する → 上端の代入値から下端の代入値を引くをマスターします。各ルールには易しい問題から順に並んだ例題チェーンを用意し、応用問題に入る前に必要なパーツを一つずつ身につけられる構成にしています。

§0 · まずはイメージをつかむ

積分＝「曲線と x 軸で囲まれた面積」を求める

積分（せきぶん / integral）＝曲線と x 軸で囲まれた部分の面積です。曲線が複雑で公式がない場合、細長い長方形をたくさん並べて近似します——長方形の数が増えるほど、精度が高くなります。スライダーを動かしてみましょう。これこそが講義ノートの定義式 (1-10) で行っていることです。

—
真の面積 ∫02x2dx = 83 ≈ 2.667
N = 2N = 6N = 60
幾何学的に計算する：公式を使わず、直接面積を見るノート 1.2〜1.3 例題

最もシンプルな積分は、小学生で習う三角形の面積公式だけで計算できます。以下の4題でステップアップしながら、「積分＝面積」の感覚を養いましょう。

ウォームアップ · ノート 1.2 例1  |  ∫03x dx = 92
考え方：f(x)=x は原点を通る右上がりの直線で、[0,3] の範囲で x 軸と直角三角形を作ります。この三角形の面積がそのまま積分の値になります。
グラフ描画[0,3] で直角三角形を形成：底辺 = 3、高さ = 3
面積計算底辺 3 × 高さ 3 ÷ 2 = 92
ノート 1.2 例2  |  ∫−10x dx = −12
考え方：前問との唯一の違い：区間が x 軸の負の側 [−1,0] に移動し、三角形が x 軸の下側に現れます。面積の計算方法は同じですが、下側の面積にはマイナス符号を付けます。
グラフ描画[−1,0] の三角形：底辺 1、高さ 1（全体が x 軸の下側）
面積計算底辺 1 × 高さ 1 ÷ 2 = 12
符号付加x 軸の下側にあるため → −12図形的な面積は ½ ですが、「定積分の値」としてはマイナスがつきます
ノート 1.3 例2  |  ∫−11x dx = 0
考え方：前問との違い：区間が 0 を跨いで [−1,1] になっています。左半分は x 軸の下側（負）、右半分は上側（正）であり、2つの領域は大きさ（面積）が等しく正負が打ち消し合います。
左半分 [−1,0]−12前問の結論（x 軸の下側）
右半分 [0,1]+12対称な三角形（x 軸の上側）
合計−12 + 12 = 0

予告：この「左が負・右が正でちょうど打ち消し合って 0 になる」という性質は、§4 テクニック②の「奇関数を対称区間で積分すると 0 になる」の図形的プロトタイプです。

ノート 1.3 例1  |  区間の分割 ∫010x dx = ∫05 + ∫510
考え方：これまでの問題との違い：大きな区間を2つに分けてそれぞれ計算し、後から足し合わせます。結果は全体の計算と一致するはずです（面積は分割して足しても変わらないため）。
全体 [0,10]底辺 10 × 高さ 10 ÷ 2 = 50
2つに分割[0,5] → 252，  [5,10] → 752
足し合わせ252 + 752 = 1002 = 50全体の計算結果と一致 ✓

これが区間加法性（1-13）：∫ac = ∫ab + ∫bc です。§3 で公式として再び登場しますが、図から直感的に成り立つことが分かります。

記号の読み方（記述式問題や講義の理解で役立ちます）：

∫ab f(x) dx

∫ 積分記号（Sum「和」の頭文字 S を引き伸ばしたもの）  a → 下端、b → 上端（積分区間）  f(x) 被積分関数（ひせきぶんかんすう / integrand）  dx「変数 x について積分する」ことを示す記号

重要度：🔴 2つのポイントを確実に抑える——① 定積分の計算結果は「面積」を意味する；② x 軸より下側の面積にはマイナスがつく
§1 · 基本の土台

計算の3ステップ（すべての問題で共通）

講義ノートでは「積分の基本定理（(1-11)）」と呼ばれる概念です。難しそうに聞こえますが、実際の操作はわずか3ステップです。

STEP 1 原関数 F を探す　→　STEP 2 [F(x)] と書いて上下端を置く　→　STEP 3 上端の代入値 − 下端の代入値
合い言葉：微分して問題の関数になるものは何か？それを見つけて上下端を代入し、上から下を引く

「原関数」（げんかんすう / antiderivative）＝微分すると元の被積分関数に戻る関数のことです。積分とは、「微分すると 2x になるものは何か？」と微分を逆向きに問う操作です（答えは x2）。

ウォームアップ · ノート 1.6 例1  |  ∫ab1 dx = b − a
考え方：最も基本的な例です。被積分関数は定数 1 です。まず「微分して 1 になる関数は何か？」と考えます。答えは x です（x を微分すると 1 になるため）。原関数が見つかったら、あとは上下端を代入して引き算するだけです。
STEP 1 原関数を探す微分して 1 になるのは？ → x
STEP 2 上下端を置く[x]ab角括弧 ＝「b と a をそれぞれ代入する準備」
STEP 3 上 − 下b − a
問題集 問題1  |  ∫012 dx = 2
考え方：前問との唯一の違い：定数が 1 から 2 に変わり、上下端が具体的な数値 0 と 1 になっています。全く同じ 3 ステップで解けます。この問題は図形的にも確認できます：[0,1] の範囲で高さ 2、幅 1 の長方形の面積です。
STEP 1 原関数を探す微分して 2 になるのは？ → 2x
STEP 2 上下端を置く[2x]01
STEP 3 上 − 下2×1 − 2×0 = 2＝長方形の面積（高さ 2 × 幅 1）と一致
標準 · 問題集 問題7  |  ∫123x2 dx = 7
考え方：前問との違い：被積分関数に x が含まれています。考えるべき核心は同じです——「微分して 3x2 になる関数は何か？」。微分の公式「指数を前に出して 1 引く」を逆算すると、x3 を微分すればちょうど 3x2 になります。
STEP 1 原関数を探す微分して 3x2 になるのは？ → x3確認：x³ を微分すると 3x² になるので正しい
STEP 2 上下端を置く[x3]12
STEP 3 上 − 下23 − 13 = 8 − 1 = 7
微分との大きな違い：微分の計算結果は関数になりますが、上下端がある定積分（ていせきぶん）の計算結果は1つの「数値」になります。計算を最後まで終えると式の中に x は一切残りません。
重要度：🔴 試験のすべての計算問題はこの3ステップに従います。特に STEP 1 の「原関数を探す」が最大の核心です
§2 · パーツライブラリ

原関数の早見表（この 4 行を覚える）

STEP 1 の「原関数を探す」で迷う必要はありません。試験範囲に出てくるパーツは以下の 4 種類のみです。ルールの適用は微分の手順とちょうど逆になります。各行がどのように導かれるか確認しましょう。

被積分関数 f(x)原関数 F(x)逆算のコツ
c（定数）cx定数に x がつく
xn　(n ≠ −1)xn+1n+1指数に 1 を足し、新しい指数で割る
exex不死鳥：そのまま変わらない
ecx1cecxe はそのまま書き、指数の係数 c で割る
各公式の成り立ちノート 1.6 例2〜4：「微分の逆算」による導出

丸暗記する必要はありません。被積分関数を「ある関数の微分」の形に変形してから 3 ステップを適用しているだけです。具体例から通式へと追っていけば自然と頭に入ります。

ウォームアップ（数値例）  |  x2 の原関数は x33
考え方：馴染みのある x2 で試してみましょう。逆算ルール「指数に 1 を足し、新しい指数で割る」：2 + 1 = 3 とし、3 で割ります。検算：微分して元に戻るか確かめます。
指数に 1 を足すx2 → x3
新指数で割るx33
検算x33 を微分 = 3x23 = x2問題の式に戻る → 正しい
公式 · ノート 1.6 例2  |  xn → xn+1n+1　(n ≠ −1)
考え方：前問との違い：具体的な 2 を任意の指数 n に置き換えた一般公式です。やり方は全く同じで、文字で表現しただけです。微分のルールとちょうど逆になります（微分は「前に出して 1 引く」、積分は「1 足して割る」）。
1 足して割るxn → xn+1n+1n = 2 のときは前問の x³/3 になります

条件 n ≠ −1：n = −1 の場合、分母 n+1 が 0 になってしまうためです。試験範囲で 1/x の積分が問われることはないので、この条件の存在を知っておくだけで十分です。

ノート 1.6 例3  |  ex → ex（不死鳥）
考え方：指数関数です。ex は微分してもそのままなので、逆に積分してもそのままです。形を変えずにそのまま残ります。
そのまま書くex の原関数 = ex，代入すると eb − ea
ウォームアップ（数値例）  |  e2x の原関数は 12e2x
考え方：ex との違い：指数の上に係数 2 がついています。e の部分はそのまま書き、その係数で割ります（合成関数の微分の逆操作）。検算で確認しましょう。
e はそのままe2x
係数 2 で割る12e2x
検算12e2x を微分 = 12×2e2x = e2x問題の式に戻る → 正しい
公式 · ノート 1.6 例4  |  ecx → 1cecx　(c ≠ 0)
考え方：前問の 2 を任意の係数 c に変えた通式です：e の部分はそのまま書き、指数の係数で割ります。
そのまま＋割るecx → 1cecxc = 2 のとき前問と一致します
頻出 · 問題集 問題11  |  e−x → −e−x
考え方：通式の中で最もミスが起きやすい特例：c = −1 のケースです。c で割る ＝ −1 で割る ＝ −1 を掛ける、となるため、前にマイナス符号が現れます。このマイナスの付け忘れは失点原因の第1位です。
公式適用 c=−1e−x → 1−1e−x = −e−x
検算−e−x を微分 = −(−1)e−x = e−x問題の式に戻る → 正しい
微分対照カード同じ関係を逆方向から見る
微分 ↔ 積分：逆向きに進む
微分の方向x3 —（指数を前に出し1引く）→ 3x2
積分の方向3x2 —（1足して割る）→ 3x33 = x3
微分の方向−e−x —（合成関数の微分）→ e−x
積分の方向e−x —（係数 −1 で割る）→ −e−xマイナス符号を忘れない！
検算の習慣：見つけた原関数を1回微分してみる習慣をつけましょう。微分して元の式に戻れば確実に正解です。この10秒の確認が完答につながります。
重要度：🔴 4行の早見表は STEP 1 を解くための弾薬です。特に e⁻ˣ のマイナス符号は落とし穴です
§3 · 分解の道具

3つの実用公式（微分と同ルール）

講義ノートには 5 つの公式（(1-12)〜(1-16)）が載っていますが、実際の計算で使うのは最初の 3 つだけです。ルールは微分のときと全く同じです。各公式の形を確認し、段階的な例題でマスターしましょう。

① 定数倍は外へ出す定数倍の性質 · (1-12)
∫c·f(x) dx = c∫f(x) dx
合い言葉：x を含まない係数は、あらかじめ積分記号の外に出す
ウォームアップ（数値の係数）  |  ∫2x2 dx = 2∫x2 dx
考え方：係数 2 は純粋な定数なので ∫ の外に出します。残った x2 に §2 の早見表を適用します。
定数を出す2∫x2 dx
早見表を適用2 × x33 = 2x33x² の原関数は x³/3（§2 の第1例）
応用（数値の係数 × 指数）  |  ∫ab5ex dx
考え方：前問との違い：外に出した後に残るのが ex になっています。係数 5 はそのまま外に出し、中は §2 の「不死鳥」を適用します。
定数を出す5∫abex dx
早見表を適用5[ex]ab = 5(eb − ea)
応用発展 · ノート 1.7 例5  |  ∫abex−c dx
考え方：前問との唯一の違い：係数が「5」のように分かりやすく前に出ておらず、指数のの中に隠れています。まず「指数の引き算 ＝ 割り算」の性質を使って係数を分離します。
準備・指数を分解ex−c = exec = e−c·ex指数の引き算 ＝ 割り算；e⁻ᶜ には x が含まれていません
定数を外へe−c は x を含まない → ∫ の外へ：e−c∫abex dx
早見表を適用e−c[ex]ab = e−c(eb − ea)

前問との違い：係数が直感的に見えない形になっていますが、「指数の引き算＝割り算」を使って e−c を取り出せば、5ex と全く同じ計算になります。

重要度：🔴 「x を含まない定数部分」を正しく見極め、指数の奥に隠れている定数も外に取り出せるようにする
② 和は別々に計算する和の線形性 · (1-14)
∫(ex + x2) dx = ∫ex dx + ∫x2 dx
合い言葉：「＋」「−」を見つけたら項ごとに分割し、それぞれ積分してから足し合わせる
ウォームアップ（2項） · 問題集 問題12  |  ∫01(e−x + 1) dx
考え方：2つの項がプラスでつながれています → 2つに分割し、それぞれの原関数を求めます。e−x には §2 の頻出パターン（マイナス符号に注意）、定数 1 には第1行を使います。
項ごとに分割∫01e−x dx + ∫011 dx
各項の原関数[−e−x]01 + [x]01e⁻ˣ → −e⁻ˣ（符号注意）；1 → x
上 − 下(−e−1 + 1) + (1 − 0) = 2 − e−1
標準（4項） · 問題集 問題5  |  ∫01(2x3 + x2 + 5x + 7) dx = 313
考え方：前問との違い：項数が 4 つに増え、係数もついています。項ごとに原関数を求めます（冪乗は「1 足して割る」＋ 係数を処理）。下端が 0 なので、下端の代入結果はすべて 0 になり計算が楽になります。
各項の原関数2·x44 + x33 + 5·x22 + 7x = 12x4 + 13x3 + 52x2 + 7x
x = 1 を代入12 + 13 + 52 + 7
x = 0 を代入すべて 0下端が 0 なのでこの部分は 0
通分して引き算3+2+15+426 = 626 = 313
重要度：🔴 多項式積分の王道手順：分割 → 各項の原関数 → 代入 → 通分
③ 上下端を入れ替えると符号反転(1-15)
∫ab f dx = −∫ba f dx
上下端を交換すると、定積分全体の符号が反転します。概念として知っておけば十分です。
残りの2つの公式について：
· 区間加法性(1-13)：∫ac = ∫ab + ∫bc —— §0 の図で見た通り（[0,10] ＝ [0,5]＋[5,10]）、直感的に明らかです。
· 部分積分(1-16 / Integration by Parts)：問題集の 16 題では一度も使わないため、名称を知っておく程度で問題ありません。
§4 · 時短テクニック

2つの時短テクニック（計算を大幅省略）

問題集で繰り返し登場する「真面目に計算する必要がない」パターンです。見抜くことができれば、計算量を大幅に減らせます。

テクニック① 定数の積分 ＝ 定数 × 区間の長さ
「∫ 定数 dx」を見たら、即座に 定数 × (上端 − 下端)
秒殺 · 問題集 問題1  |  ∫012 dx = 2
考え方：§1 では基本の 3 ステップで解きましたが、長方形の面積というイメージがあれば一瞬です：高さ 2 × 幅 (1−0)。
定数 × 区間の長2 × (1 − 0) = 2
問題集 問題2  |  ∫−111 dx = 2
考え方：前問との違い：区間が 0 を跨いでいるため、区間の長さを正確に計算します。区間の長さ ＝ 1 − (−1) ＝ 2 です。
定数 × 区間の長1 × (1 − (−1)) = 1 × 2 = 2区間の長さは 2 です（1 ではありません）
テクニック② 奇関数 × 対称区間 ＝ 0奇関数（きかんすう）
対称区間（[−1,1] や [−2,2] など）では、奇数乗の項を即座に消去できる
ルールの由来 · ノート 1.3 例2  |  ∫−11x dx = 0
考え方：§0 で登場した図形的イメージです。f(x)=x のグラフにおいて、左半分は x 軸の下側（負）、右半分は上側（正）で面積が等しいため打ち消し合います。
左半分 [−1,0]−12x 軸の下側（負）
右半分 [0,1]+12x 軸の上側（正）
合計−12 + 12 = 0

判定方法：式の中の x に −x を代入したとき、全体が元の式のマイナス倍になるものが奇関数です。該当するもの：x, x3, x5…（奇数乗の項）や 2xex2 のような原点対称な関数です。

応用（多項式） · 問題集 問題14  |  ∫−11(2ex + x3 + x2 + x + 1) dx
考え方：対称区間 [−1,1] での積分です。奇数乗の項（x3, x）は計算せずに 0 として消去し、残った 3 つの項だけを計算すれば手間が半減します。
奇数乗を消去x3 と x を消去対称区間＋奇数乗 → それぞれ 0 になる
残りを計算2∫−11ex + ∫−11x2 + ∫−111
合計2(e − e−1) + 23 + 2 = 2e − 2e−1 + 83
秒殺 · 問題集 問題16  |  ∫−112xex2 dx = 0
考え方：前問との違い：関数全体が奇関数（−x を代入すると符号が反転する）になっています。対称区間上の積分なので直接 0 になります。
奇偶判定−x を代入：2(−x)e(−x)2 = −2xex2符号が反転する → 奇関数
秒殺奇関数 × 対称区間 [−1,1] = 0
正面から計算原関数は ex2，[ex2]−11 = e1 − e1 = 0(−1)² = 1² = 1 より両端の値が等しいため 0 になり、一致します
奇数乗のみ適用可能！x2 や x4 は偶関数（ぐうかんすう）であり、左右の領域で同符号となるため消去できません（問題 14 の x2 は真面目に計算する必要があります）。判定は必ず「−x を代入して全体がマイナス倍になるか」で行ってください。
重要度：🔴 対称区間を見たら、まず奇数乗の項を探して消去する
§5 · 無限大への拡張

広義積分（積分区間に無限大を含む場合）

広義積分（こうぎせきぶん / improper integral）——上端が ∞ の場合、∞ を「非常に大きな値」とみなし、代入したときにどの値に収束するかを考えます。

∫0∞ e−x dx = [−e−x]0∞ = 0 − (−1) = 1
ノート 1.7  |  ∫0∞e−x dx = 1
考え方：基本の 3 ステップ通りに進めます（上端が ∞ である点だけが異なります）。原関数は −e−x（§2 の頻出パターン）です。∞ を代入する際は「極限値」として挙動を確認します。
