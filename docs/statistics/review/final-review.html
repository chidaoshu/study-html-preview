箱ひげ図の構造

$$IQR = Q_3 - Q_1$$
IQR の中にデータの 50% が含まれる。散らすと箱が広がり、寄せると縮む。

度数分布表の構造

検算 3 点：累積度数の最終行＝N ／ 累積相対度数の最終行＝1.000 ／ 相対度数の合計＝1.000

対数関数

$$y = \log_a x \iff a^y = x$$
底が $e = 2.7182818\ldots$（ネイピア数）のとき自然対数 $\log_e x = \ln x$。基本は $\log_a 1 = 0$、$\log_a a = 1$、$\log_a a^n = n$。
公式 1〜3
$$\log_c a + \log_c b = \log_c ab$$
$$\log_c a - \log_c b = \log_c \frac{a}{b}$$
$$\log_c a^b = b\log_c a$$
公式 4 — 底の変換
$$\log_a b = \frac{\log_c b}{\log_c a}$$
教材では優先度の低い印だが、問題集では換底が 3 問中 3 問。捨てない。

対数の計算パターン

真数を底の冪に書き換える$\log_2 4 = \log_2 2^2 = 2$　$\log_2 512 = 9$　$\log_2 1024 = 10$
逆数は負の指数$\log_2 \frac{1}{2} = -1$　$\log_2 \frac{1}{64} = -6$　$\log_2 \frac{1}{128} = -7$
小数も負の指数に直す$\log_{10} 0.01 = \log_{10}10^{-2} = -2$　$\log_{10}1000 = 3$
自然対数も同じ$\log_e e = 1$　$\log_e \frac{1}{e} = -1$　$\log_e 1 = 0$
和差 → 積商$\log_2 10 + \log_2 4 = \log_2 40$　$\log_2 10 - \log_2 5 = 1$

換底公式の実戦

$\log_9 27$
$$\frac{\log_3 27}{\log_3 9} = \frac{3}{2}$$
底を 3 に揃える。$27 = 3^3$、$9 = 3^2$
$\log_3 5 \times \log_5 9$
$$\log_3 5 \times \frac{\log_3 9}{\log_3 5} = \log_3 9 = 2$$
$\log_3 5$ が約分で消える
$\dfrac{1}{\log_2 10} + \dfrac{1}{\log_5 10}$
$$\log_{10}2 + \log_{10}5 = \log_{10}10 = 1$$
$\frac{1}{\log_a b} = \log_b a$ の形に直してから公式 1
03
記述統計量 — 代表値・平均偏差・分散・標準偏差

平均偏差 → 分散 → 標準偏差 パイプライン

教材は $\delta_i = x_i - \bar{x}$ を平均偏差（mean deviation）と呼ぶ。単に「偏差」ではなくこの語で問われることがある。

ばらつきを測るまでの 3 段階

どう動かしても①は必ず 0。だから②絶対値、③2 乗へ進む。
平均偏差mean deviation — 教材の術語。単に「偏差」ではない
A・B・C はどれも平均 10 cmそれでもばらつきは全く違う → 平均だけでは分布はわからない

全データに定数 c を加えたら

平均だけ動き、分散・標準偏差は不変。
$$(x_i+c)-(\bar{x}+c) = x_i-\bar{x}$$
偏差から $c$ が消えるため
統計検定の実例平均 46・標準偏差 9 に 5 点加点 → 平均 51・標準偏差 9
逆算も出る標準偏差 9 → 分散 81誤答：$S=V^2$ ／ $S=\frac{1}{V}$

代表値の比較

対称なら 3 つ一致 → 平均を採用。非対称なら中央値・最頻値。
鉛筆データ（外れ値 1 個）除去すると 平均 98.23 → 100.20 と大きく動く中央値 105.05 → 105.3、最頻値 107.3 → 107.3 はほぼ不動

代表値の定義と落とし穴

平均 mean$\bar{x} = \frac{1}{N}\sum x_i$　データの「重心」誤答選択肢：$\bar{x} = x_1+\cdots+x_N$ ／ $N(x_1+\cdots+x_N)$
中央値 medianソート後の中央の値偶数個は真ん中 2 つの平均。$3,1,4,2$ → ソート $1,2,3,4$ → $\frac{5}{2}$。ソートを忘れない
最頻値 mode最も度数の高い値複数あり得る（$63,63,72,72,78$ → 63 と 72）。全部 1 個ずつなら存在しない
範囲 range最大値 − 最小値外れ値が直に効くのでヒストグラムで全体像を確認する

公式カード

平均 Mean
$$\bar{x} = \frac{1}{N}\sum_{i=1}^{N} x_i$$
度数分布表からの平均
$$\bar{x} = \frac{f_1v_1 + \cdots + f_nv_n}{f_1 + \cdots + f_n}$$
$f_k$＝度数、$v_k$＝階級値。階級分け後の平均は元データの平均と一般に一致しない。教材例（N=100）の答は 60.4。
分散 Variance
$$S^2 = \frac{1}{N}\sum_{i=1}^{N}(x_i - \bar{x})^2 = \overline{x^2} - \bar{x}^2$$
誤答：$\frac{1}{N}\sum x_i^2$（平均を引いていない）／$\frac{1}{N}\sum|x_i-\bar{x}|$（2 乗していない）／$\frac{1}{N}\sum(x_i-\bar{x})$（0 になる）
標準偏差
$$S = \sqrt{S^2} = \sqrt{\overline{x^2} - \bar{x}^2}$$
偏差値
$$T_i = \frac{10(x_i - \bar{x})}{\sigma} + 50$$
平均 50、標準偏差 10 に正規化。ピークが複数ある分布では有効な意味を持たない可能性があり、異なるデータ間の偏差値の比較は無意味。

Σ（総和）の計算

$$\sum_{\blacksquare=\bullet}^{\blacktriangle}\blacklozenge \;:\; \blacksquare について \bullet から \blacktriangle までの \blacklozenge の和$$
基本
$$\sum_{k=1}^{3}k = 6 \qquad \sum_{k=1}^{5}k = 15 \qquad \sum_{k=1}^{4}k^2 = 30$$
$$\sum_{k=1}^{5}1 = 5 \qquad \sum_{n=1}^{3}n(n+1) = 20 \qquad \sum_{n=1}^{5}2^n = 62$$
定数の和＝定数 × 項数。共通因子は $\sum$ の外に出せる：$\sum_{n=1}^{5}\frac{n}{5} = \frac{1}{5}(1+2+3+4+5) = 3$
符号と負の指数 — 最大の失点源
$$\sum_{k=1}^{3}(-2)^k = (-2)+4+(-8) = -6$$
$$\sum_{n=0}^{5}(-1)^n = 1-1+1-1+1-1 = 0$$
$$\sum_{n=-2}^{2}3^n = \frac{1}{9}+\frac{1}{3}+1+3+9 = \frac{94}{9}$$
必ず逐項展開してから足す。暗算で飛ばすと符号を間違える。開始インデックスは 1 とは限らず、$n=0$ や $n=-2$ から始まることもある（項の個数に注意）。

微分 — べき乗法則・積の微分・合成関数・偏微分

接線の幾何学的意味

$\Delta x \to 0$ で割線が接線に重なる。これが微分の定義の意味。
$y = ax + b$$a$＝傾き（gradient）、$b$＝切片（intercept）
接する図形1 変数 → 直線／2 変数 → 平面／3 変数以上 → 超平面
接線の傾き＝導関数に代入$f=x^3$、$x=2$ → $3\times2^2 = 12$$(3\times2)^2$ としない

連鎖律（合成関数の微分）

外の微分 × 中の微分。中身を $z$ と置くのが手順の型。中の微分を掛け忘れる失点が最多。
指数の中身が変わる型
$$e^{2x} \to 2e^{2x} \qquad e^{-x} \to -e^{-x} \qquad e^{5x} \to 5e^{5x}$$
$$e^{2x+3} \to 2e^{2x+3} \qquad e^{x^2} \to 2xe^{x^2} \qquad e^{-x^2} \to -2xe^{-x^2}$$
括弧の冪
$$(x-5)^2 \to 2(x-5) \qquad (x-a)^2 \to 2(x-a)$$
$$(x^2+x+1)^2 \to 2(2x+1)(x^2+x+1)$$
$$\tfrac{1}{2}(x-5)^2 \to x-5 \qquad \tfrac{1}{2}(x-a)^2 \to x-a$$
$\frac{1}{2}$ と 2 が約分される頻出パターン。$\frac{1}{x+1}$ は $(x+1)^{-1}$ と見て $-\frac{1}{(x+1)^2}$。

微分の公式一覧

べき乗法則
$$\frac{d}{dx}x^n = nx^{n-1}$$
$n$ は任意の実数。負でも分数でも可
定数
$$\frac{d}{dx}c = 0$$
$e^2$ もただの定数 → 0
指数関数
$$\frac{d}{dx}e^x = e^x$$
微分しても自分自身
定数倍
$$\frac{d}{dx}\{cf\} = c\,f'$$
係数はそのまま外に出す
和
$$\frac{d}{dx}\{f+g\} = f' + g'$$
項ごとに分けて微分
積
$$\frac{d}{dx}\{fg\} = f'g + fg'$$
前を微分×後ろ ＋ 前×後ろを微分
商の微分は履修していない。分数は $(\;)^{-1}$ にして積＋連鎖律で処理する。

べき乗法則

$$\frac{d}{dx}x^n = nx^{n-1}$$
$$\frac{d}{dx}c = 0$$
$x^{100}$$\to 100x^{99}$
$\frac{1}{x} = x^{-1}$$\to -\frac{1}{x^2}$　負の指数でも公式そのまま
$\frac{1}{2}x^2$$\to x$
$ax^2$$\to 2ax$
$\frac{1}{a}x^a$$\to x^{a-1}$　$a$ が約分される

指数関数・和・積

$$\frac{d}{dx}e^x = e^x$$
$$\frac{d}{dx}[fg] = f'g + fg'$$
$xe^x$$\to e^x + xe^x$
$x^2e^x$$\to 2xe^x + x^2e^x$
$(x^3-1)e^x$$\to (x^3+3x^2-1)e^x$
$e^x+e^{-x}$$\to e^x-e^{-x}$　第 2 項が符号反転

偏微分

$$\frac{\partial f}{\partial x} : \text{他の変数を定数扱い}$$
$\frac{\partial}{\partial x}(x^2+xy)$$= 2x+y$
$\frac{\partial}{\partial x}(x^2y)$$= 2xy$
$\frac{\partial}{\partial x}(xy)$$= y$　（$y$ は係数扱い）
$\frac{\partial}{\partial x}(y)$$= 0$　（$x$ を含まない＝定数）
$\frac{\partial}{\partial x}(x^2{+}2xy{+}y^2)$$= 2x+2y$

積の微分と分数の処理

複数の積
$$(x-2)(3x-5) \to 6x-11$$
$$(x+1)(x-1) \to 2x$$
$$(x-1)(x-2)(x-3) \to 3x^2-12x+11$$
3 つの積は「1 つだけ微分して残り 2 つはそのまま」を 3 回足す。展開してから微分した方が速いこともある（$(x-1)(x-2)(x+3) = x^3-7x+6 \to 3x^2-7$）。
積 × 連鎖律
$$e^x(x-1)^2 \to e^x(x^2-1)$$
$e^x(x-1)^2 + 2e^x(x-1)$ → 公因子 $e^x(x-1)$ でくくると $(x-1)+2 = x+1$
分数・sigmoid
$$\frac{x^2-3x}{x+3} \to \frac{x^2+6x-9}{(3+x)^2}$$
$$\frac{1}{1+e^{-x}} \to \frac{1}{(1+e^x)(1+e^{-x})}$$
$$\frac{1}{1+e^{-2x}} \to \frac{2}{(1+e^{2x})(1+e^{-2x})}$$
$$\frac{1}{1+e^{-ax-b}} \to \frac{a}{(1+e^{-ax-b})(1+e^{ax+b})}$$
$(1+e^{-x})^{-1}$ と見て、中の微分 $-e^{-x}$、外の微分 $-z^{-2}$。ロジスティック回帰の勾配の形。

偏微分と Σ の組み合わせ

Σ を展開してから
$$\frac{\partial}{\partial x_1}\sum_{i=1}^{2}x_i^2 = \frac{\partial}{\partial x_1}(x_1^2+x_2^2) = 2x_1$$
連鎖律との合わせ技
$$\frac{\partial}{\partial x}e^{x^2+y^2} = 2xe^{x^2+y^2}$$
$$\frac{\partial}{\partial x}(x^2+y^2)^2 = 4x(x^2+y^2)$$
$$\frac{\partial}{\partial x}(xye^x) = y(e^x+xe^x)$$
最小二乗法の勾配
$$\frac{\partial}{\partial x_1}\left[\frac{1}{2}\sum_{i=1}^{10}(a_ix_1+b_ix_2+c_i)^2\right] = \sum_{i=1}^{10}a_i(a_ix_1+b_ix_2+c_i)$$
① 係数 $\frac{1}{2}$ を外へ ② 偏微分を $\sum$ の中へ ③ 連鎖律（中の微分は $a_i$、$b_ix_2$ と $c_i$ は定数）④ $\frac{1}{2}$ と 2 が約分。

付録 A — 階乗・二項係数

$$n! = n\times(n-1)\times\cdots\times2\times1,\qquad 0! = 1$$
$3! = 6$　$5! = 120$　$\frac{5!}{3!} = 5\times4 = 20$（共通部分は約分する）
$${}_nC_r = \frac{n!}{(n-r)!\,r!}\qquad (0 \le r \le n)$$
$$(a+b)^n = \sum_{r=0}^{n}{}_nC_r\,a^r b^{n-r}$$
$(a+b)^2$$= b^2+2ab+a^2$
$(a+b)^3$$= b^3+3ab^2+3a^2b+a^3$

付録 B — 初等関数の微分

$$\frac{d}{dx}x^n = nx^{n-1} \qquad \frac{d}{dx}e^x = e^x$$
$$\frac{d}{dx}a^x = a^x\log_e a$$
$$\frac{d}{dx}\log_e x = \frac{1}{x} \qquad \frac{d}{dx}\log_a x = \frac{1}{x\log_e a}$$
$\sin x \to \cos x$、$\cos x \to -\sin x$ も表にはあるが、本文の例題に三角関数は一度も登場しない。時間がなければ後回し。
05
積分 — 面積と符号・基本定理・5大公式

積分 = 面積

定義は暗記不要。矩形の和（リーマン和）で幅を 0 に近づけるイメージ。
$a$ / $b$下端 lower limit / 上端 upper limit
$f(x)$被積分関数 integrand
$dx$$x$ について積分することを示す

符号 — 負の面積と対称区間

$[-1,1]$ で積分値は 0、だが面積は 1。相殺であって「面積 0」ではない。
対称区間の時短
$$\int_{-2}^{2}(2x^3+x^2+5x+7)dx = \int_{-2}^{2}(x^2+7)dx = \frac{100}{3}$$
奇数次の項（$x$、$x^3$）は消えるので、残りだけ計算する。

基本定理 & 基本積分

微積分の基本定理
$$\int_a^b \frac{df(x)}{dx}\,dx = [f(x)]_{x=a}^{b} = f(b) - f(a)$$
被積分関数を「何かの微分の形」に書けるかが計算の核心。原関数を見つけて代入するだけ。
基本積分の 4 パターン（暗記）
$$\int_a^b 1\,dx = b - a$$
$$\int_a^b x^n dx = \frac{1}{n+1}(b^{n+1}-a^{n+1}) \;\;(n\neq -1)$$
$$\int_a^b e^x dx = e^b - e^a$$
$$\int_a^b e^{cx} dx = \frac{1}{c}(e^{cb}-e^{ca}) \;\;(c\neq 0)$$
$n = -1$ だけ別扱い：$\frac{x^{n+1}}{n+1}$ は分母が 0 になるので使えず、$\int\frac{1}{x}dx = \ln|x|$。ただし $\frac{1}{x^2} = x^{-2}$ は $n=-2$ なので公式が使える（原関数 $-x^{-1}$）。
広義積分
$$\int_0^{\infty} e^{-x}dx = [-e^{-x}]_0^{\infty} = 0-(-1) = 1$$
$x\to\infty$ で $e^{-x}\to 0$。被積分関数が 0 に収束することが必要（指数分布の正規化）。$\int_a^b e^{x-c}dx = e^{-c}(e^b-e^a)$ のように定数は外に出す。

連鎖律の逆 — 原関数を推測する

4 パターンに当てはまらないとき
$$\int_{-1}^{1} 2xe^{x^2}\,dx = \;?$$
① 4 パターンに当てはまらない → ② 原関数を $e^{x^2}$ と推測 → ③ vol.4 の連鎖律で検算
$$\frac{d}{dx}e^{x^2} = e^{x^2}\cdot\frac{d}{dx}(x^2) = 2xe^{x^2}\;\checkmark$$
被積分関数と一致 → 原関数は $e^{x^2}$ で確定
$$[e^{x^2}]_{-1}^{1} = e^{1} - e^{1} = 0$$
$x=-1$ でも $(-1)^2 = 1$ なので同じ値。奇関数 × 対称区間としても同じ結論。
展開してから積分する型
$$\int_{-1}^{1} e^x(1+e^{-2x})dx = \int_{-1}^{1}(e^x+e^{-x})dx$$
$$= [e^x - e^{-x}]_{-1}^{1} = 2(e-e^{-1})$$
先に展開すると既知の形になる。原関数 $e^x-e^{-x}$ は微分して $e^x+e^{-x}$ になることで検算できる。

積分の 5 大公式

定数倍
$$\int_a^b cf\,dx = c\int_a^b f\,dx$$
区間加法性
$$\int_a^c + \int_c^b = \int_a^b$$
和の線形性
$$\int(f+g) = \int f + \int g$$
上下端の交換
$$\int_a^b = -\int_b^a$$
部分積分
$$\int_a^b f g'\,dx = [fg]_a^b - \int_a^b f' g\,dx$$
$\int_{-1}^{1}x^2dx = \frac{2}{3}$原関数 $\frac{1}{3}x^3$

確率と確率分布 — pmf・pdf・母平均・Gauss 分布

Gauss 分布（正規分布）

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left[-\frac{(x-\mu)^2}{2\sigma^2}\right]$$
σ を小さくするとピークが 1 を超える。それでも積分は常に 1。
式の選択で見る 3 点① 指数に負号 ② 分子が $(x-\mu)^2$ ③ 分母が $2\sigma^2$$2\sigma$ にした選択肢はダミー
正規化条件$\int_{-\infty}^{\infty}f(x)dx = 1$

確率分布の体系

※文献によっては「確率質量関数」を単に「確率分布」と呼ぶことがあるので注意。

割合 → 確率 → 母平均

$\sum p_k$ は常に 1 に正規化。$\mu$ は重心のように動く。
$$\bar{x} = \frac{n_1}{n}(1)+\frac{n_2}{n}(2)+\cdots \;\longrightarrow\; \mu = p_1(1)+p_2(2)+\cdots$$
$n$ を大きくすると 割合 → 確率、標本平均 → 母平均。教材が 4 章で反復する核。
無限母集団サイコロ・コイン・池の魚 — 真の確率は実験では知り得ない
有限母集団標本＝母集団のとき、割合と確率は等価
母平均の計算に必要なもの母集団の確率質量関数／確率密度関数現実にはわかっていない → 統計的推測へ

pmf と pdf — 密度は確率ではない

$$\int_a^b f(x)\,dx = 値が\,[a,b]\,になる確率$$
魚の実験では $f(x_k) = \frac{n_k}{n\Delta x_k}$、$f(x_k)\Delta x_k$ が区間の確率。$\Delta x \to 0$ で $\sum \to \int$。
pdf の値が 1 を超えることがある○ — 密度は確率ではない
pdf の値が負になることがある× — 密度は 0 以上
pdf の値は確率を表す× — 確率は積分した面積
pdf の導関数は確率の変化量× — そのような意味はない
確率は必ず知ることができる× — 無限母集団では知り得ない

母平均の計算

$$離散：\mu = \sum_x x\,p_x \qquad 連続：\mu = \int_{-\infty}^{\infty} x f(x)\,dx$$
成績ポイント
$$0.2(1)+0.4(2)+0.3(3)+0.1(4) = 2.3$$
サイコロ（一様分布）
$$\frac{1}{6}(1+2+3+4+5+6) = \frac{21}{6} = 3.5$$
偶数の目のみ $p_2{=}p_4{=}p_6{=}\frac{1}{3}$$\mu = \frac{1}{3}(2+4+6) = 4$
2 しか出ない $p_2 = 1$$\mu = 2$
$p_1{=}\frac{1}{60},\,p_2{=}\frac{19}{60},\,p_3{=}\frac{1}{12},\,p_4{=}\frac{1}{4},\,p_5{=}p_6{=}\frac{1}{6}$通分して 60 に揃え $\frac{224}{60} = \frac{56}{15}$
コイン（表=1, 裏=0）
$$\mu = p_1\times1 + p_0\times0 = p_1$$
$x=0$ の項が消えるので母平均＝表が出る確率。$p_1=\frac{1}{3}$ なら $\mu=\frac{1}{3}$、一様分布なら $\frac{1}{2}$。
連続（Gauss 分布に従う場合）
$$\mu = \int_{-\infty}^{\infty} x\cdot\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}dx$$
空欄補充では「$x \times$ ガウス密度」を書く。

母平均 vs 標本平均

箱に赤 2 個（−1 点）、青 3 個（1 点）、緑 1 個（2 点）。ランダムサンプリングで 1 つ取り出す。
母平均 — 確率で重み付け
$$\mu = (-1)\frac{2}{6} + 1\cdot\frac{3}{6} + 2\cdot\frac{1}{6} = \frac{1}{2}$$
確率＝個数 ÷ 全体 6
標本平均 — 出たデータをそのまま平均
$$\bar{x} = \frac{(-1)+(-1)+1}{3} = -\frac{1}{3}$$
非復元抽出で赤 2・青 1 が出た場合。この 2 つの計算方法を取り違えない。
Bernoulli 分布
$$f(x) = p_1^{\,x}(1-p_1)^{1-x} \quad (x = 0,\,1)$$
$$\sum_{x=0}^{1} f(x) = 1$$
検算法：$x=1$ で $p_1$、$x=0$ で $1-p_1$ が出れば正しい式。
ダミー選択肢$p^{1-x}(1-p)^{1-x}$ ／ $p^{1-x}(1-p)^{x}$ ／ $p^x(1-p)^x$代入すると必ず破綻する

TRAP 01 — 分散 vs 標準偏差

分散 $S^2$ は偏差の 2 乗平均。単位は cm²（平方単位）、√ なし。
標準偏差 $S = \sqrt{分散}$。単位は cm（測定値と同じ単位に戻る）。
逆方向も出る：標準偏差 9 → 分散 81。$S=V^2$ ／ $S=\frac{1}{V}$ は誤り。
中間試験 問12/17/19/20 で繰り返し失点した最重要弱点。

TRAP 02 — 定数加算と標準偏差

全データに同じ定数 $a$ を加算 → 平均は $+a$、分散・標準偏差は不変。
理由：偏差 $(x_i+a)-(\bar{x}+a) = x_i-\bar{x}$ で $a$ が消える。
「平均も変わらない」「標準偏差も増える」はどちらもひっかけ。中央値・最頻値は $+a$、範囲・IQR は不変。

TRAP 03 — クロス集計表の割合

「男性の不満の割合が減った」≠「不満な男性の人数が減った」
割合は分母（行合計 / 列合計 / 全体）で意味が変わる。$136/550 = 0.247$ と $136/1200 = 0.113$ は同じ人数。中間試験 問6 で失点。

TRAP 04 — 積分の負の面積

$y$ 軸の負の側にある面積は、幾何学的には正だが 積分値は負になる。
例：$\int_{-1}^{0} x\,dx = -\frac{1}{2}$（面積は $\frac{1}{2}$ だが符号はマイナス）
奇関数を対称区間で積分すると 0 になるが、これは「面積が 0」ではない。

TRAP 05 — Σ の負数の累乗

$(-2)^k$ の計算は必ず逐項展開してから足す。暗算で飛ばすと符号を間違える。
$\sum_{k=1}^{3}(-2)^k = (-2)+4+(-8) = -6$
負の指数も注意：$\sum_{n=-2}^{2}3^n = \frac{1}{9}+\frac{1}{3}+1+3+9$。開始インデックスは 1 とは限らない。
中間試験 問22 で失点（答 −19 とすべきところ −21）。電卓不可なので特に注意。

TRAP 06 — 商の微分は使わない

この科目では商の微分を教えていない。分数形の微分は 積の微分 ＋ 合成関数 で処理。
$\frac{1}{x+1} \to (x+1)^{-1}$、$\frac{1}{1+e^{-x}} \to (1+e^{-x})^{-1}$ として連鎖律を適用する。

TRAP 07 — $e^2$ の微分は 0

$e^2$ は $e$ も 2 も固定値なのでただの定数（≈ 7.39）。微分すると 0。
$\frac{d}{dx}e^x = e^x$ と混同して $e^2$ と答えるのが典型的失点。
同様に $e^{2x+3}$ の定数 3 も微分で消える（答 $2e^{2x+3}$）。

TRAP 08 — 連鎖律の「中の微分」忘れ

$(x^2+x+1)^2 \to 2(2x+1)(x^2+x+1)$。中の微分 $(2x+1)$ を掛け忘れる失点が最多。
$e^{-x} \to -e^{-x}$ の負号、$e^{5x} \to 5e^{5x}$ の係数 5 も同じ理由で落としやすい。
中の微分が 1 のとき（$(x-5)^2$）だけ結果が変わらないが、手順は省かない。

TRAP 09 — 中央値・最頻値

中央値：偶数個なら真ん中 2 つの平均。$3,1,4,2$ → ソート $1,2,3,4$ → $\frac{5}{2}$。ソートを忘れない。
最頻値：複数あり得る（$63,63,72,72,78$ → 63 と 72）し、存在しないこともある（全部 1 個ずつのとき）。

TRAP 10 — pdf の値は確率ではない

確率密度関数の値は 1 を超えてもよい（教材の図でも密度は 2.0 まである）。密度は「確率の密度」であって確率ではない。
確率は区間で積分した面積 $\int_a^b f(x)dx$。
一方、値が負になることはない。

TRAP 11 — 4 尺度の「比」

比が有意味なのは比例尺度のみ。「30℃ は 15℃ の 2 倍暑い」は無意味（0℃ は原点ではない）。
テストの点数は間隔尺度（0 点は得点の 1 つにすぎない）。
絶対温度 K・長さ・血圧は 0 が「何もない」を意味するので比例尺度。

TRAP 12 — $\int x^n dx$ の条件

$\int x^n dx = \frac{x^{n+1}}{n+1}$ は $n \neq -1$ が条件（$n=-1$ だと分母が 0）。
$n = -1$ のときは $\int \frac{1}{x}dx = \ln|x|$。
$\frac{1}{x^2} = x^{-2}$ は $n=-2$ なので公式が使える（原関数 $-x^{-1}$）。

TRAP 13 — ダミー化は 0/1 に限らない

「表＝1、裏＝−1」も適切なダミー化。「コイン投げは 0/1 でなければならない」は誤り。
ただし 1/0 にする利点は別途問われる：結果の総和がそのまま表の枚数になる。

TRAP 14 — 母平均と標本平均の関係

「必ず同じ」「必ず異なる」「母平均の方が必ず小さい／大きい」はすべて誤り。
正解は「上記のどれも正しくない」。一般には異なるが、一致することもある。

TRAP 15 — 数値でも質的データ

クラスの「3 組」、出席番号「5 番」、住所の「4 丁目」は四則演算が無意味 → すべて質的データ。
逆に、値が多い離散データ（テストの点数）は連続データとして扱うことがある。
学籍番号・ID はデータの次元にカウントしない。

TRAP 16 — 積分は「原関数を探す」

$2xe^{x^2}$ は 4 パターンに当てはまらない。原関数を推測 → vol.4 の微分で検算という手順を使う。
$\frac{d}{dx}e^{x^2} = 2xe^{x^2}$ ✓ → よって $\int_{-1}^{1}2xe^{x^2}dx = [e^{x^2}]_{-1}^{1} = 0$。
対称区間を見たら、まず奇数次の項を消すと計算量が激減する。
