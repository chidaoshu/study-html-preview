§0 · 1行の判定方法を理解する

1つの買い方に対し、ネットワークはどう判定するのか？

課題全体は、以下の判定プロセスを何度も繰り返すことです。まずこの単行判定ツールを使い、1行の計算方法を理解しましょう。後の表埋め作業はそのバッチ処理版です。

買うお菓子にチェックを入れ、パラメータを変更して、ユニットAがどう反応するか観察してください：

お菓子1310 円 / B
お菓子2220 円 / C
お菓子370 円 / D
発火したユニット(買った)-
重み合計0
合計 vs 閾値-
OKA 不発火 -> 買い方はOK
判定プロセス（要記憶）加总 -> 比閾値 -> 定発火 -> 定OK/NG
手順操作概念
① 合計「買う」ユニットの重みを足し合わせる = 重み合計買う = 対応するユニットが発火し、自身の重みを送る；買わない = 不発火、送らない（0とする）
② 比閾値合計 > 閾値 A か？「超えた」= 厳密に大きい。等しい場合は超えたとは見なさず、発火しない
③ 発火判定合計 > 閾値 -> Aが発火する；そうでなければ発火しない発火（Firing）= 信号が次に伝わる
④ OK/NG判定発火 -> NG（失敗）；不発火 -> OK（成功）直感に反する点：発火は「超えた」ことを意味するため、NGとなる
発火 = NG、不発火 = OK。これを逆に判定すると全て間違える。

2組のパラメータを混同しないこと：重み B/C/D 入力層ユニット（買う時に送る）のパラメータ（買う时送出），閾値 A 出力層ユニットのパラメータ。学習とはこれら2組の数値を調整すること。正解ラベル（Ground Truth Label）は実際の金額に基づいた正しい答え（合計金額 > 500 -> NG）であり、ネットワークの判定と比較して正誤を確認する。

重要度：🔴 この4ステップは課題全体の基礎。§2の表埋めではこれを5回実行する。
§1 · 課題の進め方

指定された操作フロー

課題に唯一の正解はない。以下のサイクルを回し、バリデーション（検証）も全て「正しい」になるまで続ける。1ターム終わるごとにExcelで新しいシートをコピーして作成する。

指定された操作フロートレーニングサイクル -> バリデーション -> 間違いがあればトレーニングに戻る -> 再バリデーション
学習1ターム目へ進む：初期値 B=1 C=3 D=8 A=6 を使い、5行のトレーニングデータを計算し、各行の重み合計・正誤を判定。
有「間違い」-> 分 T1/T2 -> 调重み和閾値 -> 复制 sheet 进学習2ターム目へ進む。
学習を複数ターム繰り返し、5行全て「正しい」になるまで続ける -> ここで学習を中断する（このパラメータが収束値）。
バリデーション1ターム目へ進む：収束したパラメータを使い、3行のバリデーションデータを判定。
バリデーションが全て「正しい」 -> パラメータ完成、課題終了。
バリデーションに「間違い」がある -> T1/T2に分けてパラメータ調整 -> 新規学習タームを作成して確認 -> 再び新規バリデーションタームを作成 -> まだ間違いがあればこの手順を繰り返し、全て「正しい」になるまで続ける。
重要な認識：トレーニングデータで全問正解でも完成ではない（それに合わせて調整したのだから当然）。真の性能は未知のバリデーションデータで試される。そのため、バリデーションで間違いがあれば学習に戻って再調整し、バリデーションでも全て正解になるまで繰り返す。

3つの間違いやすい点（毎ターム要確認）：
① 発火 = NG（直感に反するが、逆にすると全滅する）
② 等しい場合は超えたとは見なされない（合計 = 閾値の時は不発火となり、判定はOK）
③ パラメータ調整時、発火していない（買わない）ユニットは変更せず、発火したユニットのみ増減する
调参规则：T1（発火过头）-> 発火单元重み −1、閾値 +1；T2（発火不足）-> 発火单元重み +1、閾値 −1

なぜこのように調整するのか（ヘップの法則 Hebb's Rule）：T1はAが過敏に発火してしまうため、重みを下げ、閾値を上げて発火しにくくする；T2はその逆。発火したユニットのみ調整するのは、発火していないユニットは今回の間違いに関与していないため。これはまさに「繰り返し発火することで伝達効率が向上する」仕組みの手動シミュレーションである。

§4 · 完了

いつ完了と見なすか？

特定の固定された数値を算出するのではなく、プロセスを完了させることです：学習で全正解 -> バリデーションで全正解。

完了条件両方を満たすこと
トレーニングデータ5行が全て「正しい」（学習中断）
バリデーションデータ3行が全て「正しい」

パラメータは一意ではない：教材では初期値から B=8 C=6 D=2 A=11 付近に収束すると言及されていますが、これが唯一の正解ではありません。手順通りに進め、バリデーションで全正解できるパラメータであればどれも正解です。重要なのはプロセスが追跡可能であること（各シートに1タームを記録し、パラメータ調整の根拠があること）です。

課題提出：Excelファイルには、学習1 -> 学習2 -> ... -> 検証1（-> 間違いがあれば：学習N -> 検証2 -> ...）という完全なシートの連鎖が残っている必要があります。担当教員が確認するのはこのパラメータ調整の軌跡です。
一言で言うと：学習で全て正解しても完了ではなく、バリデーションで全て正解して初めて真に学習したと言える。
