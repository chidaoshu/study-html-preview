SECTION 4.1.1 & 4.1.2

画像フォーマットとピクセル/ Image Formats & Pixels

Webで扱う画像形式の分類（ラスタ vs ベクタ）、主要拡張子ごとの圧縮特性、および画面表示の最小単位であるピクセル（Pixel）の概念。

画像形式分類 / Classification ラスタ形式（Raster / Bitmaps） vs ベクタ形式（Vector Graphics）
圧縮方式 / Compression 非可逆圧縮（Lossy Compression） vs 可逆圧縮（Lossless Compression）
画素単位 / Minimum Unit ピクセル（Pixel / 画素） — 色情報（RGB）を持つ格子状の最小単位点 
<!-- ラスタ形式 (PNG/JPG): ピクセルの集合。拡大するとドットが見える (ジャギ) -->
<img src="photo.jpg" alt="ラスタ画像 (Raster)">

<!-- ベクタ形式 (SVG): 数式・座標で描画。拡大しても画質劣化なし (無段階拡大) -->
<img src="logo.svg" alt="ベクタ画像 (Vector)">
<!-- 主要画像フォーマットの比較と用途 -->
<!-- JPG : 写真・複雑なグラデーション（非可逆 / 1677万色 / 透過不可） -->
<!-- PNG : ロゴ・イラスト・透明画像（可逆 / 1677万色 / Alpha透過） -->
<!-- GIF : アニメーション・アイコン（可逆 / 256色 / 2値透過） -->
<!-- WebP: 次世代規格。JPGの軽量＋PNGの透明＋GIFのアニメを統合 -->
<!-- SVG : ベクタテキスト（拡大無損 / CSS・JS制御可能） -->
<!-- BMP : Windows非圧縮。ファイルサイズ巨大のためWeb使用不可 -->
<!-- ピクセル（Pixel / 画素）: 画像・画面の最小格子単位 -->
<!-- 1px は R(赤) G(緑) B(青) の輝度情報を持つ -->
<div style="width: 200px; height: 100px;">
  幅200ピクセル × 高さ100ピクセル = 合計 20,000 画素
</div>
SECTION 4.1.3

img 要素/ img Element

画像および代替コンテンツ（Fallback Content）の表示。空要素。

カテゴリー / Category フロー（Flow）, フレージング（Phrasing）, エンベッディド（Embedded）, インタラクティブ（Interactive, usemap使用時）, パルパブル（Palpable）
コンテンツモデル / Content Model なし（空要素）
主要属性 / Attributes src (必須), alt, usemap, width, height, グローバル属性 
<!-- images/cat01_640.jpg を標準表示 -->
<img src="images/cat01_640.jpg">
<!-- パス間違い時、alt 属性の代替テキストを表示 -->
<img src="images/cat" alt="座っている猫">
<!-- width のみ指定（アスペクト比を維持して自動縮小） -->
<img src="images/cat01_640.jpg" width="160">
<!-- height のみ指定（縦幅に合わせてアスペクト比維持） -->
<img src="images/cat01_640.jpg" height="50">
<!-- width と height の両方を明示指定（比率が強制変化） -->
<img src="images/cat01_640.jpg" width="50%" height="200">
SECTION 4.1.5 & 4.1.6

picture 要素 & source 要素/ picture & source Elements

端末環境や画面幅に応じて最適な画像を選択（レスポンシブ Web デザイン / Responsive Web Design）。記述順に判定され、最初に条件一致したソースが表示される。最後に img 要素を記述する。

picture カテゴリー / Content Model フロー, フレージング, エンベッディド / 0個以上の source 要素 ＋ 最後の 1 つの img 要素
source 属性 / Attributes src (video/audio用), type (MIMEタイプ), srcset (画像パス), media (メディアクエリ)
区分 キーワード / 特性名 内容・意味
メディアタイプ
(Media Type)		 screen / all (初期値) ディスプレイ画面 / すべての機器（他: print, handheld, projection）
print 印刷・印刷プレビューモード
メディア特性
(Media Feature)		 min-width / max-width ウィンドウ幅の最小値 / 最大値
min-height / max-height ウィンドウ高さの最小値 / 最大値
演算子 / Operator and / , (カンマ) AND 条件結合 / OR 条件結合 
<picture>
  <!-- 1280px 以上 -->
  <source media="(min-width:1280px)" srcset="images/cat01_1280.jpg">
  <!-- 640px 以上 -->
  <source media="(min-width:640px)" srcset="images/cat01_640.jpg">
  <!-- 上記以外 -->
  <source srcset="images/cat01_320.jpg">
  <!-- 非対応ブラウザ用 / 寸法属性保持 -->
  <img src="images/cat01_320.jpg" alt="猫">
</picture>
<picture>
  <!-- WebP 対応ブラウザへ配信 -->
  <source type="image/webp" srcset="images/cat.webp">
  <!-- 未対応ブラウザへ PNG 配信 -->
  <img src="images/cat.png" alt="猫">
</picture>
<picture>
  <source media="(min-width: 2000px)" srcset="huge.jpg">
  <!-- 条件に一致しない場合、最後の img が表示される -->
  <img src="images/cat01_320.jpg" alt="猫" width="300">
</picture>
SECTION 4.2.1 & 4.3.1

メディアフォーマット/ Video & Audio Formats

Webで利用される動画ファイル形式（.mp4 / .webm / .mov / .avi）および音声ファイル形式（.mp3 / .m4a / .wav）の拡張子と特徴。

動画拡張子 / Video Formats .mp4 (Web標準 / H.264+AAC), .webm (VP9/AV1), .mov (QuickTime), .avi (MS非圧縮)
音声拡張子 / Audio Formats .mp3 (万能非可逆 / 1/10圧縮), .m4a (AAC高音質), .wav (RIFF非圧縮)
マルチブラウザ対応 / Fallback <video> または <audio> 内に複数の <source> を順に記述して互換性を担保 
<!-- 動画ファイルフォーマットの指定 -->
<!-- MP4 (.mp4)  : H.264/AAC。全主要ブラウザ対応のデファクトスタンダード -->
<!-- WebM (.webm): Google提唱のオープン形式。高圧縮率 (VP9 / AV1) -->
<!-- MOV (.mov)  : Apple QuickTime 標準。Mac/iOSで親和性高 -->
<!-- AVI (.avi)  : MS標準形式。容量が大きくWeb配信には非推奨 -->

<video controls>
  <source src="movie.webm" type="video/webm">
  <source src="movie.mp4" type="video/mp4">
</video>
<!-- 音声ファイルフォーマットの指定 -->
<!-- MP3 (.mp3): 非可逆圧縮。約1/10の圧縮比。全端末・全ブラウザ対応 -->
<!-- M4A (.m4a): AACコーデック。MP3より同ビットレートで高音質 -->
<!-- WAV (.wav): 非圧縮RIFF。スタジオ品質だが容量巨大でWeb非推奨 -->

<audio controls>
  <source src="sound.m4a" type="audio/mp4">
  <source src="sound.mp3" type="audio/mpeg">
</audio>
SECTION 4.2.2

video 要素/ video Element

動画コンテンツの挿入。複数 source 要素や WebVTT 字幕（track 要素）にも対応。

カテゴリー / Category フロー, フレージング, エンベッディド, インタラクティブ (controlsあり), パルパブル
コンテンツモデル / Content Model srcあり: トランスペアレント, track / srcなし: トランスペアレント, track, source
主要属性 / Attributes src, autoplay (Chromeはmuted必須), loop, muted, controls, poster, width, height, playsinline
字幕機能 / 字幕要素 <track> 要素 (src属性に WebVTT 形式 .vtt ファイルを指定) 
<!-- video 要素単体指定 (autoplay, muted, loop) -->
<video src="videos/sea01_640.mp4" autoplay muted loop></video>
<video width="320" autoplay loop muted poster="images/broken-link_640.png">
  <source src="videos/sea01_640.mov">
  <source src="videos/sea01_640.mp4">
  video 要素はサポートされていません。
</video>
<video controls src="videos/sea01_640.mp4">
  <!-- WebVTT (.vtt) 形式の字幕ファイルを指定 -->
  <track src="subtitles_ja.vtt" kind="subtitles" srclang="ja" label="日本語">
</video>
SECTION 4.3.2

audio 要素/ audio Element

音声ファイルの挿入。コントロール操作 UI の表示や複数形式のフォールバック指定が可能。

カテゴリー / Category フロー, フレージング, エンベッディド, インタラクティブ (controlsあり), パルパブル (controlsあり)
コンテンツモデル / Content Model srcあり: トランスペアレント, track / srcなし: トランスペアレント, track, source
主要属性 / Attributes src, autoplay (Chrome未対応), loop, muted, controls 
<!-- audio 要素のみで1つのファイルを指定 -->
<audio src="audios/gekko.mp3" controls></audio>
<audio controls autoplay muted>
  <source src="audios/birds.m4a">
  <source src="audios/gekko.mp3">
  再生可能な音声がありません。
</audio>
<audio controls>
  <source src="audio.invalid">
  <!-- 非対応ブラウザではタグ内の文書代替が表示される -->
  再生可能な音声がありません。
</audio>
SECTION 4.4.1 & 4.4.2

図とキャプション/ figure & figcaption Elements

図表・写真・コード・引用文などの自律的コンテンツ（figure）と、そのキャプション・見出し（figcaption）のセマンティックな紐付け。

カテゴリー / Category フロー（Flow）, パルパブル（Palpable）, セクショニングルート（Sectioning Root）
コンテンツモデル / Content Model 1つの <figcaption> 要素（最初または最後） ＋ フローコンテンツ
配置位置ルール / Position Rule <figcaption> は <figure> の直下の【最初】または【最後】のみ配置可能（中間に置くと文法エラー）
大綱構造 / Outline Sectioning Root であるため、内部の <h1>〜<h6> は主文書の大綱（Outline）に影響を与えない 
<!-- キャプションを下部に配置する一般的な図表構造 -->
<figure>
  <img src="images/cat01_640.jpg" alt="猫">
  <figcaption>図1: 日向ぼっこをする猫</figcaption>
</figure>

<!-- キャプションを上部に配置（直下の最初も文法的に正解） -->
<figure>
  <figcaption>図2: 山頂の夕焼け</figcaption>
  <img src="images/sunset.jpg" alt="夕焼け">
</figure>
<!-- figure 要素は引用文 (blockquote) と出典の指定にも利用される -->
<figure>
  <blockquote cite="https://example.com">
    <p>シンプルさは究極の洗練である。</p>
  </blockquote>
  <figcaption>出典: <cite>レオナルド・ダ・ヴィンチの言葉</cite></figcaption>
</figure>
<!-- ソースコードブロックと見出しタイトルの紐付け -->
<figure>
  <figcaption>リスト1.1: HTML5 基本骨格コード</figcaption>
  <pre><code>&lt;!DOCTYPE html&gt;
&lt;html lang="ja"&gt;
  &lt;head&gt;&lt;title&gt;Sample&lt;/title&gt;&lt;/head&gt;
  &lt;body&gt;&lt;h1&gt;Hello World&lt;/h1&gt;&lt;/body&gt;
&lt;/html&gt;</code></pre>
</figure>
SECTION 4.5.1

iframe 要素/ iframe Element

インラインフレーム（inline frame）。外部 HTML 文書やウェブサービス（YouTube, Google Map等）をページ内にインライン埋め込み表示する。

カテゴリー / Category フロー, フレージング, エンベッディド, インタラクティブ, パルパブル
コンテンツモデル / Content Model iframe 非対応ブラウザで表示される代替コンテンツ
主要属性 / Attributes src (URL指定), name, width, height, グローバル属性 
<!-- sample.html を幅 500、高さ 300 の枠内に埋め込み -->
<iframe src="sample.html" width="500" height="300">
  iframe が表示できないときはこの内容が表示されます。
</iframe>
'> 
<!-- YouTube の「共有」→「埋め込む」より取得した iframe -->
<iframe width="560" height="315"
  src="https://www.youtube.com/embed/XXXXXX"
  title="YouTube video player"
  frameborder="0" allowfullscreen>
</iframe>
<!-- Google Maps の「共有」→「地図を埋め込む」の HTML -->
<iframe src="https://www.google.com/maps/embed?pb=..."
  width="600" height="450"
  style="border:0;" allowfullscreen="" loading="lazy">
</iframe>
SECTION A.1 & A.2

パスの設定/ Absolute & Relative Paths

ファイルの位置を特定するための道筋。Web サーバー公開を前提とするため、区切り文字は常に / を使用する。

区分 起点（基準） 特徴・用途
絶対パス
(Absolute Path)		 ルートディレクトリ (/) 参照元を移動しても壊れない。他PCへのコピー時は同一ディレクトリ構成が必要。
相対パス
(Relative Path)		 カレントディレクトリ (現在地) フォルダ構造ごとそのままコピー・移設可能。参照元移動時は書き換えが必要。
. (ドット1つ) カレントディレクトリ（現在操作対象のディレクトリ）を表す。
.. (ドット2つ) 1つ上位の親ディレクトリ（Parent Directory）を表す。 
<!-- hello.html から配下の sample.png を参照 -->
<!-- カレントディレクトリ (vol.4) からの道筋 -->
<img src="images/sample.png" alt="サンプル">
<!-- または -->
<img src="./images/sample.png" alt="サンプル">
<!-- hello.html から 隣の vol.5/foo.html を参照 -->
<!-- .. で一度親ディレクトリ (html) に上がって下りる -->
<a href="../vol.5/foo.html">vol.5 へ移動</a>
<!-- ルートディレクトリ (/) からの完全な道筋を指定 -->
<img src="/html/vol.4/images/sample.png" alt="サンプル">
