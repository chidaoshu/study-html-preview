SECTION 7.1 / 基本構造を示す要素

基本構造要素/ Header, Main & Footer

Web ページ全体の骨格（ヘッダー・メイン・フッター）を定義し、検索エンジンに正しい文書構造を伝える要素。

<header>
  <h1>埼玉紹介サイト</h1>
  <p>埼玉県を紹介する Web サイトです。</p>
</header>
カテゴリーフロー・コンテンツ（Flow）, パルパブル・コンテンツ（Palpable）
コンテンツモデルフロー・コンテンツ（※header・footer 要素は含みません）
属性グローバル属性（Global Attributes）
役割・特徴文書冒頭のタイトル・ロゴ・ナビゲーション等のヘッダー、または1つのセクションのヘッダーとして使用
<main>
  <h1>埼玉とは？</h1>
  <p>埼玉県は、日本の関東地方に位置する広域地方公共団体（都道府県）のひとつです。</p>
</main>
カテゴリーフロー・コンテンツ（Flow）, パルパブル・コンテンツ（Palpable）
コンテンツモデルフロー・コンテンツ
属性グローバル属性（Global Attributes）
役割・特徴body 内の主要情報・中心主題。複数ページ共通の項目（header, footer等）は含めない。原則 1つの body に 1つ設定
<footer>
  <small>
    Copyright &copy; 2019 Denshi Taro(19CA0000), All rights reserved.
  </small>
</footer>
カテゴリーフロー・コンテンツ（Flow）, パルパブル・コンテンツ（Palpable）
コンテンツモデルフロー・コンテンツ（※header・footer 要素は含みません）
属性グローバル属性（Global Attributes）
役割・特徴文書・セクションの末尾のフッター（著作権表記・ページ番号・関連情報など）
<body>
  <header>
    <h1>埼玉紹介サイト</h1>
  </header>
  <main>
    <h1>埼玉とは？</h1>
    <p>埼玉県は、日本の関東地方に位置する...</p>
  </main>
  <footer>
    <small>Copyright &copy; 2019 Denshi Taro</small>
  </footer>
</body>
構造関係body ➔ header（共通頭部） ➔ main（主要主題） ➔ footer（共通脚部）
設計ルール1つの body に main は原則 1 つ。header・footer 内に他の header・footer を入れ子に不可
SECTION 7.2 / セクションを表す要素

セクションを表す要素/ Section, Article, Aside & Nav

「見出しとそれに対応する内容」をグループ化する要素。意味や目的に応じて使い分ける。

<section>
  <h1>見出しサンプル</h1>
  <p>段落サンプル</p>
</section>
カテゴリーフロー, セクショニング・コンテンツ（Sectioning）, パルパブル
コンテンツモデルフロー・コンテンツ
属性グローバル属性（Global Attributes）
役割・特徴一般的な章・節・項を表す普通のセクション。通常は見出し（h1〜h6）を伴う。具体的に他意がない場合に使用
<article>
  <h1>見出しサンプル</h1>
  <p>段落サンプル</p>
</article>
カテゴリーフロー, セクショニング・コンテンツ（Sectioning）, パルパブル
コンテンツモデルフロー・コンテンツ（※main 要素は除く）
属性グローバル属性（Global Attributes）
役割・特徴単独で完結しているセクション（ニュース記事・ブログ/SNS投稿等）。個別配信・再利用を意図。入れ子の場合は外側と関係を持つ
<aside>
  <h2>見出しサンプル</h2>
  <p>段落サンプル</p>
</aside>
カテゴリーフロー, セクショニング・コンテンツ（Sectioning Content）, パルパブル
コンテンツモデルフロー・コンテンツ（※main 要素は除く）
属性グローバル属性（Global Attributes）
役割・特徴主要な内容に関係しているが切り離せるセクション（サイドバー・補足記事・広告等）を表す
<h1>埼玉紹介サイト</h1>
<nav>
  <a href="#">ホーム</a>
  <a href="#">観光地</a>
  <a href="#">食べ物</a>
  <a href="#">場所</a>
  <a href="#">その他</a>
</nav>
カテゴリーフロー, セクショニング・コンテンツ（Sectioning）, パルパブル
コンテンツモデルフロー・コンテンツ（※main 要素は除く）
属性グローバル属性（Global Attributes）
役割・特徴Web ページ内または他ページへの主要なナビゲーションリンクの集合を表す
要素内容役割
h1埼玉紹介サイトページまたはサイトの見出し
navホーム・観光地・食べ物・場所・その他主要ページへのリンク集合
SECTION 7.3 / 特別な意味を持たない要素

div / span 要素によるグループ化/ div & span Elements

固有のセマンティック（意味）を持たず、スタイル適用やレイアウト範囲をまとめるための要素。

<!-- 属性 class="cls" を子要素 h1, p に一括適用 -->
<div class="cls">
  <h1>見出しサンプル</h1>
  <p>段落サンプル</p>
</div>
カテゴリーフロー・コンテンツ（Flow）, パルパブル・コンテンツ（Palpable）
コンテンツモデルフロー・コンテンツ、他
属性グローバル属性（Global Attributes）
役割・特徴特別な意味を持たない。要素をグループ化（Grouping）し、デザインやレイアウトの適用範囲をまとめる
<!-- div 要素の中に div 要素を入れ子にする構造 -->
<div class="cls">
  <div>
    <h1>見出しサンプル</h1>
    <p>段落サンプル</p>
  </div>
</div>
入れ子構造div 内にさらに div を自由に配置可能（ブロックレベル要素）
使用目的外枠のレイアウト枠（コンテナ）と内側のデザイン枠を分離するなど、複雑な UI グループ化に使用
<!-- div (ブロックレベル): 改行され、独立したブロックとなる -->
<div class="box">div 1 (block)</div>
<div class="box">div 2 (block)</div>

<!-- span (インライン): 改行されず、テキスト行内でスタイリング -->
<p>文章の中に <span class="mark">span 1 (inline)</span> と <span class="mark">span 2 (inline)</span> をインライン配置。</p>
カテゴリーフロー, フレージング・コンテンツ（Phrasing / インライン）, パルパブル
コンテンツモデルフレージング・コンテンツ（Phrasing Content）
属性グローバル属性（Global Attributes）
役割・特徴固有の意味を持たないインライングループ化要素。div（ブロック：改行あり）に対し、span は行内に留まり改行されない
要素レベル改行用途
divブロックレベル (Block)自動改行（縦並び）レイアウト・段落単位のグループ化
spanインライン (Inline)改行なし（横並び）テキスト行内の一部分のスタイリング
