SECTION 1.2

グリッドレイアウトの構成物/ Grid Concepts & Structure

2次元（水平・垂直）レイアウトを形成する7つの基本構成要素とその位置関係。

構成物 / Concept 説明 / Description
グリッドコンテナ 親要素。display: grid または inline-grid を指定した枠組み。
グリッドアイテム 子要素。グリッドコンテナの直下に配置される各コンテンツ。
グリッドライン 区切り線。縦（左から1, 2…）および横（上から1, 2…）の通し番号が振られる。
グリッドセル 隣り合うグリッドラインで囲まれた最小のマス目単位。
グリッドエリア 複数のグリッドセルが結合して形成される矩形領域。
グリッドトラック グリッドの「1行（Row）」または「1列（Column）」の単位。
グリッドギャップ グリッドセル同士の間に生じる間隔（隙間）。
SECTION 1.3.1 - 1.3.2 🔴

グリッドトラックのサイズ指定/ Track Sizes & repeat()

grid-template-columns / grid-template-rows でトラック寸法を指定。fr 単位や repeat() の挙動対比。

.container {
  display: grid;
  height: 200px;
  grid-template-columns: 100px 2fr 1fr;
  grid-template-rows: 50px 1fr 2fr;
}
.container {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(80px, 1fr));
  grid-template-rows: 60px 60px;
}
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(80px, 1fr));
  grid-template-rows: 60px 60px;
}
SECTION 1.3.3 🔴

グリッドアイテムの配置位置指定/ Item Placement & Span

grid-row-start / grid-column-start 等でライン番号や span を指定し、アイテムを配置。

.target {
  grid-row-start: 2;
  grid-row-end: 4;
  grid-column-start: 2;
  grid-column-end: 5;
}
.target {
  grid-row-start: 2;
  grid-row-end: span 2;
  grid-column-start: 2;
  grid-column-end: span 3;
}
.target {
  grid-row: 2 / 4;
  grid-column: 2 / span 3;
}
