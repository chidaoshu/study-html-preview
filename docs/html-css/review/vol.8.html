SECTION 1.1

1.1 CSS の基本書式/ Basic Syntax

CSS（Cascading Style Sheets）は Web ページのレイアウト・装飾を定義する言語。セレクター { プロパティ: 値; } で指定する。

h1 {
  color: blue;
  font-size: 28px;
}
h1 {
  color: #d02020;
  font-size: 20px;
  border-bottom: 2px solid #d02020;
}
SECTION 1.1.2 & 1.1.3

1.1.2 & 1.1.3 CSS コメントと注意事項/ Comments & Formatting Rules

CSS のコメント表記法（/* ... */）と、コード内の空白・改行・タブの自由な記述性（等価コード）について理解する。

/* これが CSS のコメントです */
h1 {
  color: blue; /* 1行内でのコメント */
}
/*
  複数行にわたるコメントも
  記述することができます
*/
/* ※ // による 1 行コメントは CSS では無効 */
/* 1. 標準的な改行とインデント */
h1 {
  color: blue;
  font-size: 24px;
}

/* 2. 空白・改行のない 1 行圧縮記述（全く同じ意味） */
h1{color:blue;font-size:24px;}
SECTION 1.2

1.2 CSS の組み込み/ Linking External CSS

外部 CSS ファイル（.css）を作成し、head 要素内に <link rel="stylesheet" href="..."> を記述して読み込む。

<!-- index.html の head 要素内 -->
<link rel="stylesheet" href="style.css">

<!-- style.css -->
body { background: #f5f5f3; color: #111; }
h1 { color: #d02020; }
<!-- CSSファイルの読み込みなし -->
<!-- ブラウザ標準のスタイル（User Agent Stylesheet）のみ -->
SECTION 1.2.2 & 1.2.3

1.2.2 & 1.2.3 CSS 組み込み方法（style要素・style属性）/ Internal & Inline CSS

外部ファイルを使用せず、HTML 文書内に直接 CSS を埋め込む方法。<style> タグ（内部スタイルシート）と style 属性（インラインスタイル）。

<head>
  <style>
    h1 { color: #d02020; font-size: 20px; }
    p  { color: #666; }
  </style>
</head>
<!-- 各HTMLタグの中に直接 style 属性を記述 -->
<h1 style="color: blue; font-size: 20px;">見出し</h1>
<p style="color: green; font-weight: bold;">本文テキスト</p>
SECTION 2.1.1

2.1.1 要素を指定するセレクター/ Universal & Type Selectors

ユニバーサルセレクター *（全要素対象）とタイプセレクター 要素名（指定要素対象）。

* {
  color: red;
}
h1 {
  color: blue;
}
SECTION 2.1.2

2.1.2 属性を指定するセレクター/ ID, Class & Attribute Selectors

ID セレクター #id、クラスセレクター .class、属性セレクター [attr] / [attr="val"]。

#rank { color: blue; }
li#piyo { color: green; }
.choco { color: blue; }
li.sweets { color: purple; }
[title] { color: blue; }
p[lang] { color: purple; }
[title="no2"] { color: blue; }
p[title="no1"] { color: purple; }
SECTION 2.2.1

2.2.1 疑似クラス :hover/ Hover Pseudo-class

要素上にマウスカーソルが存在する状態に限定してスタイルを適用する。

h1:hover {
  color: blue;
}
.btn:hover {
  background: #111;
  color: #fff;
}
SECTION 2.2.2

2.2.2 疑似クラス :nth-child/ Nth-child Pseudo-class

子要素としての特定の順番を指定。正の整数、キーワード（even/odd）、一次関数式（An+B）。

:nth-child(4) {
  color: blue;
}
li:nth-child(4) {
  color: blue;
}
li:nth-child(even) {
  color: blue;
}
li:nth-child(3n+1) {
  color: blue;
}
SECTION 2.2.3 ★高頻

2.2.3 その他の疑似クラス/ Other Pseudo-classes

リンク状態指定（:link, :visited, :active）、子要素の位置特定（:first-child vs :first-of-type）、否定・条件選択（:not(), :is()）。

/* LVHAの順序で記述する必要がある（Link - Visited - Hover - Active） */
a:link    { color: #0066cc; } /* 未訪問リンク */
a:visited { color: #884488; } /* 訪問済みリンク */
a:hover   { color: #d02020; } /* ホバー時 */
a:active  { color: #00aa00; } /* 押下中 */
/* :first-child: 種類に関係なく最初の子要素 */
.box p:first-child { color: red; }

/* :first-of-type: 同一要素（p）の中で最初の要素 */
.box p:first-of-type { color: blue; font-weight: bold; }
/* :not(セレクター): 条件に一致しない要素 */
li:not(.skip) { color: blue; font-weight: bold; }

/* :is(セレクター群): いずれかに一致する要素 */
:is(h3, p.highlight) { color: #d02020; }
SECTION 2.3.1

2.3.1 疑似要素 ::before / ::after/ Pseudo-elements

HTML に記述のない要素を前後に生成する。content プロパティの指定が必須。

h1::before { content: "🎉 "; }
h1::after  { content: " 😊"; }
li::before {
  content: "★ ";
  color: #d02020;
}
SECTION 2.3.2

2.3.2 その他の疑似要素/ Other Pseudo-elements

テキストの1行目（::first-line）、1文字目（::first-letter）、リスト記号（::marker）、選択範囲（::selection）を指定する疑似要素。

p::first-letter { font-size: 1.6em; color: #d02020; font-weight: bold; }
p::first-line   { color: blue; }
li::marker      { color: #d02020; font-weight: bold; }
::selection     { background: #d02020; color: #ffffff; }
SECTION 2.4

2.4 セレクターの組み合わせ/ Selector Combination

タイプ/ユニバーサル ＋ クラス/ID/属性/疑似クラス ＋ 疑似要素を連結して対象を特定する。

h2.jec:hover {
  color: red;
}
li.ai::first-letter {
  color: orange;
  font-size: 1.3em;
}
[title="jn"]:active.it::first-letter {
  color: blue;
}
SECTION 2.5

2.5 セレクターのグループ化/ Selector Grouping

カンマ（,）で複数のセレクターを区切ることで、同じスタイルルールを一括適用する（セレクターリスト）。

.baseball, .soccer, .rugby {
  color: blue;
  font-weight: bold;
}
SECTION 2.6 ★主役

2.6 結合子/ Combinators

HTML は不変。セレクターだけが変わる。 書式：セレクター1　結合子　セレクター2

.area p { color: blue; }
.area > p { color: blue; }
.mark ~ p { color: blue; }
.mark + p { color: blue; }
SECTION 3.1

3.1 継承/ Inheritance

親要素（div等）のスタイルが子要素（p等）へ引き継がれる。直接的な要素指定がある場合はそちらが優先される。

div {
  color: red;
}
p {
  color: blue;
}
div {
  color: red;
}
SECTION 3.2

3.2 詳細度/ Specificity

同じ要素に対する複数の指定が競合した場合、詳細度の点数が高い指定が優先される（桁上がりは発生しない）。

指定方法 / セレクター 点数 4桁表記
HTML の style 属性による指定 1000点 1.0.0.0
ID セレクター (#id) 100点 0.1.0.0
Class, 属性セレクター, 疑似クラス (.class / [attr] / :hover) 10点 0.0.1.0
要素セレクター, 疑似要素 (h1 / ::before) 1点 0.0.0.1
ユニバーサルセレクター, 結合子, 否定疑似クラス (* / > / :not()) 0点 0.0.0.0 
#bar { color: orange; }       /* 100点 */
.foo { color: blue; }         /* 10点  */
[title="hoge"] { color: pink; } /* 10点  */
h2 { color: green; }         /* 1点   */
SECTION 3.3

3.3 ソースオーダー/ Source Order

詳細度が全く同じである場合、記述順が後（下）の指定が前の指定を上書きする。

.foo { color: red; }
.foo { color: blue; }  <-- 後勝ちで青
<!-- 1. head 内 style -->
<style> .bar { color: yellow; } </style>

<!-- 2. 後続の style タグ（より後に記述） -->
<style> .bar { color: blue; } </style>
SECTION 3.4

3.4 !important の優先規則/ !important Rule

宣言の末尾に !important を付与すると詳細度・記述順を無視して最優先。!important 同士では通常の詳細度勝負に戻る。

.bar {
  color: blue !important;  <-- IDを無視して青
}
#foo {
  color: red;               /* 100点 */
}
.bar {
  color: blue !important;  <-- クラス(10点)が勝利
}
h2 {
  color: green !important; /* 要素(1点) */
}
