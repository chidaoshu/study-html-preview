SECTION 3.1.1

横方向の配置指定/ text-align

ブロックコンテナ要素内のインラインコンテンツの水平配置（揃え位置）を指定する。

初期値 start 継承 あり（継承される）
適用要素 主に display が block, inline-block の要素など（ブロックコンテナ） 
p {
  text-align: start;
}
p {
  text-align: end;
}
p {
  text-align: left;
}
p {
  text-align: right;
}
p {
  text-align: center;
}
p {
  text-align: justify;
}
p {
  text-align: justify;
  text-align-last: justify;
}
SECTION 3.1.2 🔴高頻

縦方向の配置/ vertical-align

インライン要素、インラインブロック要素、およびテーブルセル要素の垂直方向の配置（揃え位置）を指定する。

初期値 baseline 継承 なし（継承されない）
適用要素 インライン要素、インラインブロック要素、テーブルセル要素（inline, inline-block, table-cell） 
/* display: table-cell 内での縦方向の配置 */
td.base   { vertical-align: baseline; } /* ベースライン揃え */
td.top    { vertical-align: top; }      /* 上揃え */
td.middle { vertical-align: middle; }   /* 中央揃え */
td.bottom { vertical-align: bottom; }   /* 下揃え */
/* インライン要素 / 画像の縦方向揃え */
.sub         { vertical-align: sub; }         /* 下付き文字 */
.super       { vertical-align: super; }       /* 上付き文字 */
.text-top    { vertical-align: text-top; }    /* 親文字の上端 */
.text-bottom { vertical-align: text-bottom; } /* 親文字の下端 */
.middle      { vertical-align: middle; }      /* 中央（x-height中央） */
SECTION 3.2.1

要素の配置方法/ position

通常フロー（Normal Flow）に従うか、フローから外れて任意の位置や固定位置に配置するかを指定する。

初期値 static 継承 なし（継承されない）
適用要素 すべての要素 
.target {
  position: static;
  top: 20px;  /* static のため無効 */
  left: 30px; /* static のため無効 */
}
.target {
  position: relative;
  top: 15px;
  left: 20px;
}
.parent { position: relative; }
.target {
  position: absolute;
  top: 10px;
  right: 10px;
}
.target {
  position: fixed;
  bottom: 10px;
  right: 10px;
}
.target {
  position: sticky;
  top: 0px;
}
SECTION 3.2.2

要素の配置位置の指定/ top, right, bottom, left

position の指定内容に応じて、四方の基点（基準位置）からの距離を設定する。

初期値 auto 継承 なし（継承されない）
適用要素 位置指定要素（position プロパティが static 以外の要素） 
.target {
  position: relative;
  top: 15px;
  left: 25px;
}
.parent { position: relative; }
.target {
  position: absolute;
  top: 15px;
  right: 15px;
}
SECTION 3.2.2

対向プロパティの競合と優先順位/ Conflict Resolution

top と bottom、left と right を同時に指定した場合、top および left が優先される（LTR書字方向時）。

div {
  position: relative;
  top: 15px;    /* 優先される */
  bottom: 60px; /* 無視される */
}
div {
  position: relative;
  left: 20px;   /* 優先される */
  right: 80px;  /* 無視される */
}
div {
  position: relative;
  top: 15px;    /* 優先 */
  bottom: 50px;
  left: 20px;   /* 優先 */
  right: 80px;
}
SECTION 3.3 🔴高頻

要素の回り込み/ float & clear

要素を左右に寄せて後続コンテンツを回り込ませる float と、回り込みを解除する clear、および親要素の高さ塌陷を防ぐ clearfix。

初期値 float: none / clear: none 継承 なし（継承されない）
適用要素 すべての要素（float 指定時、display は自動的にブロック化される） 
/* 左・右への回り込みと回り込みなし */
.box-left  { float: left; margin: 0 10px 5px 0; }
.box-right { float: right; margin: 0 0 5px 10px; }
.box-none  { float: none; }
/* 回り込みの解除 */
.cleared-left  { clear: left; }  /* 左 float の回り込み解除 */
.cleared-right { clear: right; } /* 右 float の回り込み解除 */
.cleared-both  { clear: both; }  /* 左右両方の回り込み解除 */
/* 親要素の高さ Collapse (塌陷) と解決策 */
/* clearfix (疑似要素による解法) */
.parent::after {
  content: "";
  display: block;
  clear: both;
}
/* または BFC (Block Formatting Context) 生成 */
.parent-bfc { overflow: hidden; }
SECTION 3.4.1 🔴高頻

要素の重なり順/ z-index

位置指定要素（position が static 以外）および Flex/Grid アイテムの画面垂直方向（Z軸）の重ね合わせ順序を指定する。

初期値 auto 継承 なし（継承されない）
適用要素 位置指定要素（position が static 以外の要素）、Flexアイテム、Gridアイテム 
/* z-index の数値が大きいほど手前（上）に表示される */
.box1 { position: absolute; top: 10px; left: 10px; z-index: 1; }
.box2 { position: absolute; top: 30px; left: 40px; z-index: 3; } /* 最前面 */
.box3 { position: absolute; top: 50px; left: 70px; z-index: 2; }
/* 【超高頻考点】重ね合わせコンテキスト (Stacking Context) */
/* 親: z-index: auto → 新規文脈を作らない (子 z-index:-1 は親背景の後ろへ) */
.parent-auto { position: relative; z-index: auto; }

/* 親: z-index: 0 → 新規文脈を生成 (子 z-index:-1 は親の枠内に留まる) */
.parent-zero { position: relative; z-index: 0; }
SECTION 3.4.2

要素を透過する/ opacity

要素全体の不透明度を 0.0（完全透明）から 1.0（完全不透明）の数値で指定する。

初期値 1.0 継承 なし（継承されない）
適用要素 すべての要素 
.box-100 { opacity: 1.0; }  /* 100% 不透明 */
.box-75  { opacity: 0.75; } /* 75% */
.box-50  { opacity: 0.5; }  /* 50% 半透明 */
.box-25  { opacity: 0.25; } /* 25% */
.box-0   { opacity: 0.0; }  /* 0% 完全透明（領域は保持） */
/* 1. opacity: 子要素・テキストもまるごと半透明になる */
.box-opacity {
  opacity: 0.5;
  background: #d02020;
}

/* 2. rgba(): 背景色のみ透過（子要素テキストは不透明） */
.box-rgba {
  background: rgba(208, 32, 32, 0.5);
}
