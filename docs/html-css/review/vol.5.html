SECTION 5.1 / a 要素

a 要素の構造とコンテンツモデル/ Anchor Element

ハイパーリンクを構成する要素。子要素の内容をリンク化する。

<a href="https://www.jec.ac.jp">
  日本電子専門学校
</a>
カテゴリーFlow, Phrasing, Interactive (href時), Palpable
コンテンツモデルTransparent（親要素を継承。※aやbutton等のインタラクティブ要素は子不可）
<a href="sample.html">
  <img src="banner.png" alt="サンプルページへ">
</a>
要素のネスト`img`（フレージング・コンテンツ）を包含して画像全体をリンク化できる
<!-- 値省略：元のファイル名で保存 -->
<a href="report.pdf" download>資料ダウンロード</a>

<!-- 値指定：指定したファイル名で保存 -->
<a href="report.pdf" download="期末対策_vol5.pdf">資料保存</a>
download 属性リソースを遷移せずダウンロード。値で保存時のファイル名を指定。
SECTION 5.1.1 / href 属性

href で設定できるリンク先種別/ href Link Targets

指定するパス形式やスキームによって、ブラウザの挙動が変化する。

<!-- 相対パス（同一PC/サーバー内） -->
<a href="images/test.html">相対パス</a>
<a href="images/test.jpg">画像パス</a>

<!-- 絶対パス・URL -->
<a href="https://www.jec.ac.jp">外部URL</a>
相対パス現在のファイル位置を基準に指定（`images/test.html`）
絶対パス / URLドライブレター（`c:/...`）やプロトコル（`https://...`）から全指定
<!-- 特定要素（id="test"）へジャンプ -->
<a href="test.html#test">特定セクションへ</a>
<a href="#sec2">同一ページ内の #sec2 へ</a>

<!-- ページの先頭へジャンプ -->
<a href="#">ページ先頭へ</a>
`#id`リンク先要素に `id="id名"` が設定されている必要がある
`#`単体指定の場合、ページの最上部（先頭）へジャンプする
<!-- リンク押下で JavaScript を実行 -->
<a href="javascript:alert('test');">スクリプト実行</a>

<!-- メールソフトを起動 -->
<a href="mailto:user@example.com">メールを送信</a>
`javascript:`擬似プロトコル。指定した JavaScript ソースコードを実行
`mailto:`既定のメールクライアントを起出し送信画面を開く
<!-- ページをリロード（再読み込み） -->
<a href="">ページ再読み込み</a>
`""` （空文字）現在の URL 自体を指定した扱いとなり、ページを再読み込み（リロード）する
SECTION 5.1.2 / target 属性

target 属性の属性値と表示場所/ target Attribute Values

リンク先のリソースを表示させるウィンドウ・フレームの場所を指定する。

<a href="sample.html" target="_self">リンク</a>
`_self`現在と同じウィンドウ・フレームに表示（属性省略時のデフォルト挙動）
<a href="https://www.jec.ac.jp" target="_blank">リンク</a>
`_blank`新しいタブ（または新しいウィンドウ）にリソースを表示する
<a href="sample.html" target="if01">リンク</a>

<!-- リンク先の表示対象となる iframe -->
<iframe name="if01" src="default.html"></iframe>
iframe の name`name="if01"` が付けられた iframe 内へリソースを表示する
<!-- 親ウィンドウに表示 -->
<a href="sample.html" target="_parent">親ウィンドウ</a>

<!-- 最上位ウィンドウに表示 -->
<a href="sample.html" target="_top">最上位ウィンドウ</a>
`_parent`親ウィンドウに表示。親が無い場合は `_self` と同じ挙動
`_top`最上位のウィンドウに表示。親が無い場合は `_self` と同じ挙動
SECTION 5.2.2 / area 要素 🔴

イメージマップの領域指定/ shape & coords

`` と `` を使用して、画像内の特定図形領域に個別のリンクを定義する。

<img src="sample.jpg" usemap="#map01">
<map name="map01">
  <area shape="rect"
        coords="0, 0, 100, 100"
        href="test1.html" alt="領域1">
</map>
`shape="rect"`長方形・正方形
`coords` (4値)左上角(x1, y1) と 右下角(x2, y2) の座標
例：`0, 0, 100, 100`
<img src="sample.jpg" usemap="#map01">
<map name="map01">
  <area shape="circle"
        coords="100, 100, 50"
        href="test2.html" alt="領域2">
</map>
`shape="circle"`円形
`coords` (3値)中心点(x, y) と 半径(r)
例：`100, 100, 50` (中心(100,100)、半径50)
<img src="sample.jpg" usemap="#map03">
<map name="map03">
  <area shape="poly"
        coords="55,10, 10,110, 110,110"
        href="test1.html" alt="三角形">
</map>
`shape="poly"`多角形（ポリゴン）
`coords` (偶数値)すべての角の座標 (x1, y1, x2, y2, x3, y3, ...)
三角形＝6個の座標値
<img src="sample.jpg" usemap="#map04">
<map name="map04">
  <area shape="default" href="all.html" alt="全域">
</map>
`shape="default"`画像全体の領域を指定（`coords` 属性の指定は不要）
SECTION 5.3 / 出題ポイント & 落とし穴

試験頻出ルールと構造的注意事項/ Exam Pitfalls

`usemap` の構文紐付け、空要素の性質、ネスト制限に関する重要ルール。

項目・構文点 正誤・試験上の落とし穴
`usemap` の `#` 指定 `usemap="#map01"` ✅ / `usemap="map01"` ❌ （`#` が無いと紐付かない）
`area` 要素のタグ構造 Void Element (空要素)。閉じタグ `</area>` は不可（`<area ...>` または `<area ... />`）
`a` 要素のネスト制限 `a` 要素の中に `a` 要素を含めることは**不可**（`<a><a>...</a></a>` ❌）
インタラクティブ要素の包含 `a` 要素の中に `button` や `input` などのインタラクティブ・コンテンツを含めることは**不可**
`target="_blank"` のセキュリティ 外部リンクを別タブで開く際、`rel="noopener noreferrer"` の併用が現代のベストプラクティス
