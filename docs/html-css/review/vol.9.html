SECTION 1.1 - 1.2

文字色と色の指定方法/ color & Color Specifications

文字色は color プロパティで変更。RGB（加法混合）や HSL（色相・彩度・輝度）のモデルに基づき、HEX や色関数（rgb, rgba, hsl, hsla）で指定する。

プロパティ / 項目 初期値 適用要素 継承
color ブラウザ依存 全要素 継承される 
/* 16進数（Hexadecimal） 6桁 または 3桁 */
h1 { color: #ff7700; }
h2 { color: #f70; }  /* 同義の短縮形 */
/* RGB 関数：0-255 または 0%-100% */
h1 { color: rgb(255, 119, 0); }
h2 { color: rgb(100%, 50%, 0%); }
/* RGBA 関数：alpha 不透明度 (0.0-1.0) */
h1 { color: rgba(255, 0, 0, 0.5); }
h2 { color: rgba(100%, 0%, 100%, 0.5); }
/* HSL 関数：色相(0-360), 彩度(%), 輝度(%) */
h1 { color: hsl(100, 50%, 40%); }
h2 { color: hsl(28, 100%, 50%); }
/* HSLA 関数：HSL + alpha 不透明度 (0.0-1.0) */
h1 { color: hsla(200, 70%, 40%, 0.5); }
SECTION 1.2.3

キーワードによる色指定/ Color Keywords

基本16色などの名前（red, blue）のほか、現在の文字色を動的に継承する currentColor や、完全な透明を表す transparent が使用できる。

特殊キーワード 説明 用途・試験ポイント
currentColor その要素の color プロパティ値 枠線（border）や影の色を文字色と自動的に同期させる
transparent 完全透明（不透明度 0.0） 背景の透過、ボーダーの非表示、グラデーションの始点終点に利用 
.box {
  color: #d02020;  /* 赤色テキスト */
  /* border の色に currentColor を指定すると
     文字色 (#d02020) が動的に同期適用される */
  border: 2px solid currentColor;
}
/* 完全透明な背景指定（背景パターンが透ける） */
button {
  background-color: transparent;
  border: 2px solid #111;
  color: #111;
}
/* 基本16色キーワード例 (navy, teal, coral 等) */
h1 { color: navy; }  /* #000080 */
h2 { color: teal; }  /* #008080 */
p  { color: coral; } /* #FF7F50 */
SECTION 2.1

フォントの設定/ font-family

font-family で書体を設定。スペース含む名前は引用符で囲み、優先順にカンマ区切りで複数指定。末尾には総称フォント名（sans-serif 等）を記載する。

プロパティ 初期値 適用要素 継承
font-family ブラウザ依存 全要素 継承される 
body {
  font-family: "Hiragino Kaku Gothic ProN", "Yu Gothic", "Meiryo", sans-serif;
}
body {
  font-family: "Hiragino Mincho ProN", "Yu Mincho", "MS Mincho", serif;
}
body {
  font-family: "SF Mono", "Consolas", "Courier New", monospace;
}
SECTION 2.2

テキストの大きさを設定する/ font-size

font-size で文字サイズを指定。絶対サイズキーワード（xx-small〜xx-large）と HTML 見出しの対応関係、および相対サイズキーワード（larger / smaller）が定義されている。

キーワード xx-small x-small small medium large x-large xx-large
HTML 見出し h6 - h5 h4 (初期値) h3 h2 h1
倍率 3/5 (0.6) 3/4 (0.75) 8/9 (0.89) 1.0 6/5 (1.2) 3/2 (1.5) 2.0 
p {
  font-size: medium;  /* 初期値 (h4 相当, 倍率 1.0) */
}
p {
  font-size: xx-large;  /* h1 相当 (倍率 2.0) */
}
p {
  font-size: xx-small;  /* h6 相当 (倍率 3/5 = 0.6) */
}
.big   { font-size: larger; }   /* 親より1段階大きい */
.small { font-size: smaller; }  /* 親より1段階小さい */
SECTION 2.3

テキストのスタイル/ font-style

font-style でフォントのイタリック体や斜体を設定。筆記体風にデザインされた italic と、標準字形を機械的に傾けた oblique の違いを押さえる。

プロパティ 初期値 適用要素 継承
font-style normal 全要素 継承される 
p {
  font-style: normal;  /* 標準（直立スタイル） */
}
/* イタリック体 (筆記体風にデザインされた専用グリフ) */
p {
  font-style: italic;
  font-family: "Georgia", serif;
}
/* 斜体 (標準グリフを角度をつけて傾けた表示) */
p {
  font-style: oblique;
}
SECTION 2.4

テキストの太さ/ font-weight

font-weight で文字の太さを設定。キーワード normal / bold と数値 400 / 700 の対応関係（試験最頻出）および 100〜900 の数値スケールを理解する。

プロパティ 初期値 適用要素 継承
font-weight normal 全要素 継承される 
/* キーワードと数値の完全対応（★超高頻出考点） */
.norm-kw  { font-weight: normal; } /* 標準 */
.norm-num { font-weight: 400; }    /* = normal と同義 */

.bold-kw  { font-weight: bold; }   /* 太字 */
.bold-num { font-weight: 700; }    /* = bold と同義 */
/* 100〜900の範囲で100刻みの数値スケール */
.w100 { font-weight: 100; } /* Thin (極細) */
.w300 { font-weight: 300; } /* Light (細字) */
.w400 { font-weight: 400; } /* Normal (標準) */
.w700 { font-weight: 700; } /* Bold (太字) */
.w900 { font-weight: 900; } /* Black (極太) */
/* 親要素に対する相対的な太さ変更 */
.parent { font-weight: 400; }
.bolder  { font-weight: bolder; }  /* 親より1段階太く */
.lighter { font-weight: lighter; } /* 親より1段階細く */
SECTION 2.5

行の高さ/ line-height

line-height で「文字高＋上下余白」の行高を設定。normal、%、単位なし数値の指定法と、子要素に継承される際の計算規則（1.5 vs 150%）が重要。

プロパティ 初期値 適用要素 継承
line-height normal 全要素 継承される（※継承の挙動に注意） 
.box1 { line-height: normal; } /* 自動適正値 (約1.2) */
.box2 { line-height: 180%; }   /* パーセンテージ指定 */
.box3 { line-height: 1.8; }    /* 単位なし数値（★推奨） */
/* ★超高頻出考点：親(24px)・子(12px) の場合 */
/* 1. 単位なし (1.5): 倍率を継承！ */
.parent-num { font-size: 24px; line-height: 1.5; }
.child-num  { font-size: 12px; } /* 子で 12px × 1.5 = 18px 再計算 */

/* 2. パーセンテージ (150%): 計算済絶対値を固定継承！ */
.parent-pct { font-size: 24px; line-height: 150%; }
.child-pct  { font-size: 12px; } /* 親の 36px (24×1.5) を固定継承 */
SECTION 2.6

フォントを一括指定する/ font

font プロパティで style, weight, size, line-height, family を一括指定。size と family が必須項目であり、厳密な順序規則が存在する。

プロパティ 初期値 適用要素 継承
font (一括指定) 個々のプロパティ参照 全要素 継承される 
/* ★必須項目ルール：font-size と font-family が必須！ */
p.valid {
  font: 16px/1.5 sans-serif;  /* ○ 有効 */
}
p.invalid {
  font: bold 16px;            /* × 無効 (family が欠落) */
}
/* 記述順序ルール：
   1. style/weight は size の前
   2. line-height は size の直後に / 区切り
   3. family は必ず最後 */
p {
  font: italic bold 16px/1.6 "Georgia", serif;
}
SECTION 2.7.2

相対長さの指定/ Relative Length

基準に対する長さの表現。親要素基準（em）、ルート基準（rem）、文字幅・高（ch, ex, lh）、ビューポート基準（vw, vh, vmin, vmax）がある。

単位 基準（Reference） 説明
em 親要素の font-size 親要素の文字サイズに対する比率 (1.0 ＝ 同じ長さ)
rem ルート要素 (html) の font-size ルート要素の文字サイズに対する比率
ex その要素の「x」の高さ 小文字「x」の高さに対する比率
ch その要素の「0」の幅 数字「0」の幅に対する比率
lh その要素の line-height その要素の行の高さと同じ値を指定
vw / vh ビューポートの幅 / 高さ ビューポートの幅 / 高さに対する比率 (1〜100)
vmin / vmax ビューポートの小 / 大の辺 幅と高さのうち小さい方(vmin) / 大きい方(vmax) に対する比率 
.parent { font-size: 20px; }
.child-em  { font-size: 1.5em; } /* 親(20px)の1.5倍 = 30px */
.child-rem { font-size: 1.5rem; } /* ルート(16px)の1.5倍 = 24px */
/* 数字「0」の幅基準。10ch ＝ 約10文字分の幅 */
.box {
  width: 10ch;
  border: 1px solid #111;
  overflow: hidden;
}
/* ビューポートの幅 80% / 高さ 40% */
.box {
  width: 80vw;
  height: 40vh;
  background: #e2e2e2;
}
SECTION 3.1 & 3.4

テキストの線装飾と一括指定/ text-decoration-line & text-decoration

text-decoration-line で上線・下線・取り消し線を装飾（複数指定可）。text-decoration で線種・色の属性を一括指定（順不同）できる。

プロパティ 初期値 適用要素 継承
text-decoration-line none 全要素 継承されない
text-decoration (一括指定) 個々に準ずる 全要素 継承されない 
p {
  text-decoration-line: underline;
}
/* 半角スペースで区切り、複数指定が可能 */
p {
  text-decoration-line: underline overline;
}
p {
  text-decoration-line: line-through;
}
/* 一括指定：[line] [style] [color] （順不同） */
p {
  text-decoration: underline wavy #d02020;
}
SECTION 3.5

テキストに影をつける/ text-shadow

text-shadow で文字に影を付与。指定順は offset-x offset-y blur-radius color。カンマ区切りで多重影（Multiple Shadows）を重ねることも可能。

プロパティ 初期値 適用要素 継承
text-shadow none 全要素 継承される 
/* 右4px 下4px ぼかし3px 半透明青影 */
h1 {
  text-shadow: 4px 4px 3px rgba(32, 96, 208, 0.4);
}
/* カンマ区切りで複数の影を指定（ネオン発光効果） */
h1 {
  color: #fff;
  text-shadow: 0 0 5px #ff3366, 0 0 10px #ff3366, 0 0 20px #ff3366;
}
SECTION 4.2

要素の内容を書き換える/ content Property & Pseudo-elements

content プロパティは擬似要素（::before / ::after）と組み合わせて文字や画像を動的に挿入。文字列、url() 画像、attr() 属性値の埋め込みに対応する。

プロパティ 初期値 適用要素 継承
content normal ::before / ::after 擬似要素 継承されない 
/* 擬似要素 ::before / ::after には content が必須！ */
.note::before {
  content: "【重要】 ";
  color: #d02020;
  font-weight: bold;
}
.note::after {
  content: " (※補足説明)";
  color: #666;
  font-size: 12px;
}
/* 1. 文字列指定 */
.badge::before { content: "★ "; color: gold; }

/* 2. attr() による HTML 属性値 (href 等) の動的埋め込み */
a::after {
  content: " (" attr(href) ")";
  font-size: 11px;
  color: #666;
}
