SECTION 1.1.1 🔴

1.1.1　ボックスモデルの基本構造/ Box Model Structure

すべての HTML 要素はコンテンツ・パディング・ボーダー・マージンの 4 領域で構成される。

.box {
  width: 200px; height: 60px;
  background: #e3f2fd; /* コンテンツ領域 */
}
.box {
  width: 200px;
  background: #e3f2fd;
  padding: 20px;        /* 内側余白 */
  background-clip: content-box;
}
.box {
  width: 200px;
  padding: 10px;
  border: 5px solid #d02020; /* 境界枠線 */
}
.box {
  width: 200px;
  border: 2px solid #333;
  margin: 25px;         /* 外側余白 */
}
SECTION 1.1.2 🔴

1.1.2　ボックスの種類/ display: block | inline | inline-block

display プロパティで幅・高さの指定可否、要素の並び、上下余白の適用範囲が決まる。

.item {
  display: block;
  width: 180px; height: 40px;
  margin: 8px 0;
}
.item {
  display: inline;
  width: 180px; height: 40px; /* 無視される */
  margin: 20px 8px;          /* 上下マージン無視 */
}
.item {
  display: inline-block;
  width: 140px; height: 50px;
  margin: 6px;
}
項目 inline block inline-block
幅・高さの指定 不可（無視される） 可能 可能
横幅の初期値 内容の幅依存 親要素の幅（100%） 内容の幅依存
他要素との並び 横に並ぶ 前後に改行（縦積み） 横に並ぶ
上下余白 左右のみ（上下無視） 上下左右すべて可能 上下左右すべて可能
代表的なデフォルト要素 span, a, strong, img div, p, h1-h6, ul button, input
SECTION 1.2.1 🔴

1.2.1　幅と高さの指定とキーワード/ width, height, min/max & intrinsic sizing

コンテンツの幅・高さを指定する。min/max による上限下限設定、内在的サイズ指定。キーワード（min-content, max-content, fit-content）。

.box {
  width: 50%;
  height: 60px;
  background: #e3f2fd;
}
.box {
  width: 100%;
  min-width: 180px;
  max-width: 280px;
  background: #fff3e0;
}
.box {
  width: min-content;
  background: #e8f5e9;
  border: 1px solid #2e7d32;
}
.box {
  width: max-content;
  background: #f3e5f5;
  border: 1px solid #7b1fa2;
}
.box {
  width: fit-content;
  background: #e0f7fa;
  border: 1px solid #0097a7;
}
SECTION 1.3.1 🔴

1.3.1　ボーダーの指定/ border-style, color & width

border-[方向] または border 一括指定。スタイル（線種）・太さ・色を設定する。

.box1 { border: 3px solid #111; }
.box2 { border: 6px double #d02020; }
.box1 { border: 3px dotted #1976d2; }
.box2 { border: 3px dashed #2e7d32; }
.g { border: 6px groove #999; }
.r { border: 6px ridge #999; }
.i { border: 6px inset #999; }
.o { border: 6px outset #999; }
p {
  border-top: 4px solid red;
  border-bottom: thick #00cccc dotted;
  border-left: dashed thin green;
  border-right: 8px solid purple;
}
SECTION 1.3.2 🟡

1.3.2　個別にボーダーの設定/ border-style, border-color & border-width mapping

border-style / border-color / border-width に指定する値の個数（1〜4個）による時計回り（上→右→下→左）の方向マッピング規則と方向個別指定。

/* 1個: 全方向（上右下左） */
border-style: solid;
/* 2個: 上下 左右 */
border-width: 10px 20px;
/* 3個: 上 左右 下 */
border-style: dotted double solid;
/* 4個: 上 右 下 左（時計回り） */
border-color: red blue green orange;
指定個数 上 (Top) 右 (Right) 下 (Bottom) 左 (Left)
1個 1番目 1番目 1番目 1番目
2個 1番目 2番目 1番目 2番目
3個 1番目 2番目 3番目 2番目
4個 1番目 2番目 3番目 4番目 
p {
  border-style: solid;
  /* 方向と種類を両方指定 */
  border-top-width: thin;
  border-bottom-width: medium;
  border-left-width: thick;
  border-right-color: #d02020;
}
SECTION 1.3.3 🔴

1.3.3　ボーダーの角を丸くする/ border-radius & corner properties

border-radius でボックスの角を丸く整形する。1〜4値の角マッピング、50% 指定による円形・楕円形作成、および頂角個別指定。

/* 1個: 4角すべて */
border-radius: 12px;

/* 2個: [左上&右下] [右上&左下] */
border-radius: 20px 5px;

/* 3個: [左上] [右上&左下] [右下] */
border-radius: 20px 10px 0;

/* 4個: 左上 右上 右下 左下（時計回り） */
border-radius: 20px 15px 10px 5px;
指定個数 左上 (Top-Left) 右上 (Top-Right) 右下 (Bottom-Right) 左下 (Bottom-Left)
1個 1番目 1番目 1番目 1番目
2個 1番目 2番目 1番目 2番目
3個 1番目 2番目 3番目 2番目
4個 1番目 2番目 3番目 4番目 
/* 正方形要素 + 50% = 完全な正円 */
.circle {
  width: 80px; height: 80px;
  border-radius: 50%;
}

/* 長方形要素 + 50% = 楕円 (Ellipse) */
.ellipse {
  width: 140px; height: 70px;
  border-radius: 50%;
}
.card-box {
  /* 各頂角を個別にプロパティ指定 */
  border-top-left-radius: 20px;
  border-top-right-radius: 0;
  border-bottom-right-radius: 20px;
  border-bottom-left-radius: 0;
  border: 2px solid #111;
}
SECTION 1.3.4 🟡

1.3.4　テーブルの罫線/ border-collapse: separate vs collapse

table 要素の枠線表示方法を制御する。HTML の border 属性は非推奨・廃止のため CSS の border と border-collapse を使用する。

/* separate: 各セルが独立したボーダーを持つ（初期値 / 二重線） */
table.sep {
  border-collapse: separate;
}

/* collapse: 隣接するセルのボーダーが結合・共有される（1本線） */
table.col {
  border-collapse: collapse;
}

table, td, th {
  border: 2px solid #333;
}
SECTION 1.4.1 🔴

1.4.1　パディングの設定/ padding shorthand & percentage

コンテンツとボーダーの間の内側余白。1〜4個の値による一括指定規則と % 指定の基準。

/* 1個: 全方向 */      padding: 15px;
/* 2個: 上下 左右 */   padding: 10px 30px;
/* 3個: 上 左右 下 */  padding: 10px 30px 20px;
/* 4個: 上 右 下 左 */ padding: 5px 25px 15px 5px;
.box {
  /* 上下パディングの % も親要素の「幅」が基準となる */
  padding: 10%;
  border: 1px solid #1976d2;
  background: #e3f2fd;
}
SECTION 1.4.2 🔴

1.4.2　マージンの設定と相殺/ margin, auto centering & collapsing

ボーダーの外側の余白。auto による中央揃え、隣接ブロック要素の「マージンの相殺」。

.box {
  width: 60%;
  margin-left: auto;
  margin-right: auto;
  /* または margin: 0 auto; */
}
.elem1 { margin-bottom: 30px; }
.elem2 { margin-top: 20px; }
/* 実際の余白は 30 + 20 = 50px ではなく */
/* 大きい方の【30px】に相殺される */
SECTION 1.5.1 / 1.5.2 🔴

1.5.1 / 1.5.2　要素サイズの計算と box-sizing/ content-box vs border-box

通常計算（content-box）は幅＋余白＋枠線が全体の幅。border-box を使うと指定サイズ内にすべてが収まる。

.box {
  box-sizing: content-box;
  width: 200px;
  padding: 15px;
  border: 5px solid #d02020;
  /* 全体幅 = 200 + 30 + 10 = 240px */
}
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 15px;
  border: 5px solid #2e7d32;
  /* 全体幅 = 指定通りの 200px */
}
/* 4等分(width: 25%)に border を付ける場合 */
.col {
  display: inline-block;
  width: 25%;
  border: 2px solid #333;
  box-sizing: border-box; /* これがないと改行される */
}
SECTION 1.5.3 🔴

1.5.3　CSS関数 calc()/ calc() function & whitespace rules

CSS 内で四則演算（+ - * /）を行い、異なる単位（% と px 等）を混在させた動的なサイズ計算を可能にするプロパティ関数。

/* 横並び4等分でマージン 10px を差し引いた幅計算 */
.box {
  width: calc(25% - 10px);
  margin-right: 10px;
  display: inline-block;
  box-sizing: border-box;
}

/* 親要素から 40px 引いた幅を動的に設定 */
.full-minus {
  width: calc(100% - 40px);
  margin: 0 auto;
}
/* ✅ 正しい構文: + や - の前後に半角スペースを必ず開ける */
width: calc(100% - 20px);  /* 正常に計算される */
font-size: calc(2em + 4px); /* 正常に計算される */

/* ❌ 構文エラー (Invalid): スペースがないと負の数や識別子と見なされる */
width: calc(100%-20px);   /* ❌ 無効（適用されない） */
font-size: calc(2em+4px);  /* ❌ 無効（適用されない） */

/* ※ 乗算(*) や 除算(/) はスペースなしでも構文上動作するが、
   統一して前後にスペースを入れるのが推奨規約 */
SECTION 1.6.1 🟡

1.6.1　box-shadow プロパティ/ box-shadow syntax & parameter order

要素にドロップシャドウ（影）を付与する。水平オフセット・垂直オフセット・ぼかし半径・広がり・色の指定順序。

/* 構文: box-shadow: 水平オフセット 垂直オフセット ぼかし半径 色; */

/* 1. 基本（水平10px, 垂直10px, ぼかしなし, 色初期値/currentColor） */
box-shadow: 10px 10px;

/* 2. ぼかし付き（水平5px, 垂直5px, ぼかし8px, 黒半透明） */
box-shadow: 5px 5px 8px rgba(0, 0, 0, 0.3);

/* 3. 影の削除 */
box-shadow: none;
