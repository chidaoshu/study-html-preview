SECTION 3.1 🔴

見出しを指定する/ Heading (h1–h6)

h1〜h6 の 6 段階。数値が小さいほど大きな見出しを表す。カテゴリー：フロー / ヘディング / パルパブル

<h1>大見出しサンプル（h1）</h1>
<h2>中見出しサンプル（h2）</h2>
<h3>小見出しサンプル（h3）</h3>
<h1>h1 見出し (最大)</h1>
<h2>h2 見出し</h2>
<h3>h3 見出し</h3>
<h4>h4 見出し</h4>
<h5>h5 見出し</h5>
<h6>h6 見出し (最小)</h6>
SECTION 3.2.1 🔴

段落で区切る/ Paragraph (p)

文章を意味のまとまり（段落）にまとめる。段落前後には標準のマージンが生じる。カテゴリー：フロー / パルパブル

<p>段落サンプルです。文章を意味のまとまりでまとめます。</p>
<p>1 行目の段落です。</p>
<p>2 行目の段落です。段落間に余白が入ります。</p>
SECTION 3.2.2 / 3.2.3 🟡

改行とテーマの区切り/ Line Break & Horizontal Rule (br & hr)

段落内の改行（br）とテーマ・話題の切り替え（hr）。br は内容を持たない空要素であり、余白目的の連続使用は非推奨。hr は意味的な区切りを表す。カテゴリー：フロー / フレージング

<p>
  1 行目の文章<br>
  2 行目の文章（同一段落内での改行）
</p>
<p>前半の話題についての段落です。</p>
<hr>
<p>後半の新しい話題についての段落です。</p>
SECTION 3.3.1 / 3.3.2 🟡

他のサイトの文章を引用する/ Quotation (blockquote & q)

長文のブロック引用（blockquote）とインラインの短文引用（q）。cite 属性で引用元 URL を指定できる。q 要素はブラウザが自動的に引用符（「」や“”）を付与する。カテゴリー：フロー / フレージング

<blockquote cite="https://ja.wikipedia.org/wiki/HyperText_Markup_Language">
  HTML は、ウェブページを記述するためのマークアップ言語です。
  文書の構造や意味を記述する役割を持ちます。
</blockquote>
<p>
  デカルトは <q cite="https://example.com">我思う、ゆえに我あり</q> という言葉を残した。
</p>
SECTION 3.4.1 🔴

重要な部分を強調する/ Importance (strong)

文書内で重要な部分を強調する。ブラウザでは一般に太字（Bold）で表示される。カテゴリー：フロー / フレージング / パルパブル

<p>
  <strong>警告</strong> まず初めに電源を OFF にしてください。
</p>
<p>
  レポートの提出期限は <strong>本日 17 時厳守</strong> です。
</p>
SECTION 3.4.2 🟡

アクセントをつける/ Stress Emphasis (em)

文脈上の強勢（アクセント）を表す。em で囲む位置によって文章のニュアンスが変化する。一般に斜体（Italic）で表示される。カテゴリー：フロー / フレージング / パルパブル

<p>
  これは <strong>重要な強調（太字）</strong> です。<br>
  これは <em>強勢アクセント（斜体）</em> です。
</p>
<!-- 主語を強調（他ではなく猫が可愛い） -->
<p><em>Cats</em> are cute animals.</p>

<!-- 述語を強調（可愛くないのではなく可愛い） -->
<p>Cats are <em>cute</em> animals.</p>
SECTION 3.5.1 🔴

リストの種別を指定する/ List Types (ol & ul)

順序付きリスト（ol = Ordered List）と順序なしリスト（ul = Unordered List）。カテゴリー：フロー

<ul>
  <li>順序なしリスト 1</li>
  <li>順序なしリスト 2</li>
  <li>順序なしリスト 3</li>
</ul>
<ol>
  <li>順序付きリスト 1</li>
  <li>順序付きリスト 2</li>
  <li>順序付きリスト 3</li>
</ol>
SECTION 3.5.1 / 3.5.2 🔴

ol と li の属性制御/ List Attributes (type, start, reversed, value)

ol の type（1, a, A, i, I）・start（開始番号）・reversed（降順）、および li の value（個別番号指定）。

<ol type="a">
  <li>英語小文字項目</li>
  <li>英語小文字項目</li>
</ol>
<ol type="A">
  <li>英語大文字項目</li>
  <li>英語大文字項目</li>
</ol>
<ol type="i">
  <li>ローマ数字小文字</li>
  <li>ローマ数字小文字</li>
</ol>
<ol type="I">
  <li>ローマ数字大文字</li>
  <li>ローマ数字大文字</li>
</ol>
<ol start="5">
  <li>5 番から開始</li>
  <li>6 番目</li>
  <li>7 番目</li>
</ol>
<ol reversed>
  <li>カウントダウン 3</li>
  <li>カウントダウン 2</li>
  <li>カウントダウン 1</li>
</ol>
<ol>
  <li>1 番目の項目</li>
  <li value="10">途中で 10 番に変更</li>
  <li>11 番目の項目</li>
</ol>
SECTION 3.6 🟡

説明リストを作成する/ Description List (dl, dt, dd)

用語（dt = Definition Term）とその説明（dd = Definition Description）を組にしてリスト（dl = Description List）化する。1対1・1対多・多対1の構成が可能。カテゴリー：フロー

<dl>
  <dt>HTML</dt>
  <dd>Web ページを記述するためのマークアップ言語です。</dd>
  <dt>CSS</dt>
  <dd>Web ページのデザイン、レイアウトを指定するための言語です。</dd>
</dl>
<dl>
  <dt>タイガース</dt>
  <dd>阪神タイガース。日本のプロ野球チーム</dd>
  <dd>レスター・タイガース。イングランドのプロラグビーチーム</dd>
</dl>
<dl>
  <dt>AI</dt>
  <dt>人工知能</dt>
  <dd>人が実現するさまざまな知覚や知性を人工的に再現するもの</dd>
</dl>
SECTION 3.7 🟡

折りたたみ文書を作成する/ Collapsible Content (details & summary)

内容の表示/非表示を切り替えられるインタラクティブ要素。summary 要素で要約・見出しを指定し、open 属性でデフォルト展開状態に設定可能。カテゴリー：フロー / インタラクティブ

<details>
  <summary>4 月のコンビニアイスランキング</summary>
  <ol>
    <li>パピコ チョココーヒー</li>
    <li>ハーゲンダッツ クリーミーコーン 抹茶マカデミア</li>
    <li>FUTABA サクレ パイン カップ</li>
  </ol>
</details>
<details open>
  <summary>デフォルトで展開されているアコーディオン</summary>
  <p>open 属性を指定すると、ページ読み込み時に最初から開いた状態になります。</p>
</details>
SECTION 3.8 🟡

補足説明と連絡先を示す/ Fine Print & Contact Info (small & address)

免責事項や著作権表示等の補足説明（small）と、著者・組織への連絡手段（address）。address 内のテキストはデフォルトで斜体（Italic）表示される。カテゴリー：フロー / フレージング
