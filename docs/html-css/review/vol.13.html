SECTION 1.1

フレックスボックスの構成と特徴/ Flexbox Overview & Advantages

親要素（Flex Container）と直下の子要素（Flex Item）で構成される。Float / Inline-Block と対比した 3 つの利点を実描画で比較する。

/* Float (高さ不揃い) vs Flexbox (高さ自動揃え) */
.float-item { float: left; }

.flex-container {
  display: flex; /* 最も高いアイテムに自動で並ぶ */
}
/* HTML記述順を変更せず、orderプロパティで表示順を制御 */
.item-1 { order: 2; }
.item-2 { order: 3; }
.item-3 { order: 4; }
.item-4 { order: 1; } /* HTML上は4番目だが先頭に表示 */
.container {
  display: flex;
  justify-content: space-around; /* 均等な余白を簡単に割り振る */
}
SECTION 1.2.1

フレックスコンテナの指定/ display: flex vs inline-flex

display プロパティにより親要素をフレックスコンテナ化する。直下の子要素のみがフレックスアイテムとなる。

プロパティ 値 振る舞い
display flex コンテナがブロックレベル要素（Block-level Element）として振舞う
display inline-flex コンテナがインライン要素（Inline Element）として振舞う 
.container {
  display: flex; /* ブロックレベル要素化（改行して全幅を占有） */
}
.item {
  background: #eaf2ff;
  padding: 10px;
  margin-right: 8px;
}
.other {
  background: #ffebe6; /* フレックスアイテム内の要素（非アイテム） */
}
.container {
  display: inline-flex; /* インライン要素化（周囲のテキストと同じ行に並ぶ） */
}
.item {
  background: #eaf2ff;
  padding: 10px;
  margin-right: 8px;
}
SECTION 1.2.2

フレックスアイテムの方向と軸/ flex-direction & Main/Cross Axis

flex-direction プロパティで主軸（Main Axis）の方向を指定する。主軸と直交する軸を交差軸（Cross Axis）と呼ぶ。

プロパティ 初期値 適用要素 継承
flex-direction row フレックスコンテナ なし 
.container {
  display: flex;
  flex-direction: row; /* 左から右へ順に並べる（初期値） */
}
.container {
  display: flex;
  flex-direction: row-reverse; /* 右から左へ逆順に並べる */
}
.container {
  display: flex;
  flex-direction: column; /* 上から下へ縦方向に並べる */
}
.container {
  display: flex;
  flex-direction: column-reverse; /* 下から上へ縦方向逆順に並べる */
}
SECTION 1.2.2

フレックスアイテムの折り返し/ flex-wrap

コンテナ幅を超えた場合の折り返し動態を指定する。初期値 nowrap では要素がコンテナ境界を突き抜けて配置される。

プロパティ 初期値 適用要素 継承
flex-wrap nowrap フレックスコンテナ なし 
.container {
  display: flex;
  flex-wrap: nowrap; /* 折り返さない（初期値：枠を突き抜ける） */
  width: 250px;
}
.container {
  display: flex;
  flex-wrap: wrap; /* 端に到達すると下の段へ折り返す */
  width: 250px;
}
.container {
  display: flex;
  flex-wrap: wrap-reverse; /* 端に到達すると上の段へ折り返す */
  width: 250px;
}
SECTION 1.2.2

方向と折り返しの短縮指定/ flex-flow shorthand

flex-direction と flex-wrap を 1 つのプロパティでまとめて指定する。

プロパティ 初期値 適用要素 継承
flex-flow row nowrap フレックスコンテナ なし 
/* 個別に指定した場合 */
div {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
}
/* flex-flow でまとめて指定した場合（同等） */
div {
  display: flex;
  flex-flow: row wrap;
}
