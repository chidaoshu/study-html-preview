SECTION 3.5

リストの種別と書式/ ol & ul

同じ li の並びでも、ol / ul と type 属性で描画が変わる。

<ul>
  <li>順序なしリスト 1</li>
  <li>順序なしリスト 2</li>
  <li>順序なしリスト 3</li>
</ul>
<ol>
  <li>順序付きリスト 1</li>
  <li>順序付きリスト 2</li>
  <li>順序付きリスト 3</li>
</ol>
<ol type="a">
  <li>順序付きリスト 1</li>
  <li>順序付きリスト 2</li>
  <li>順序付きリスト 3</li>
</ol>
SECTION 6.2.2

セルを結合する/ colspan & rowspan

結合の向きで描画がどう変わるか。colspan＝横（列方向）、rowspan＝縦（行方向）。

<table border="1">
  <tbody>
    <tr>
      <td>1 列目</td><td>2 列目</td><td>3 列目</td><td>4 列目</td><td>5 列目</td>
    </tr>
    <tr>
      <td>1 列目</td>
      <td colspan="3">2 列目</td>
      <td>5 列目</td>
    </tr>
  </tbody>
</table>
<table border="1">
  <tbody>
    <tr><td>1 行目</td><td>1 行目</td></tr>
    <tr><td>2 行目</td><td rowspan="3">2 行目</td></tr>
    <tr><td>3 行目</td></tr>
    <tr><td>4 行目</td></tr>
    <tr><td>5 行目</td><td>5 行目</td></tr>
  </tbody>
</table>
<table border="1">
  <tbody>
    <tr><td>1 行 1 列</td><td>1 行 2 列</td><td>1 行 3 列</td><td>1 行 4 列</td><td>1 行 5 列</td></tr>
    <tr><td>2 行 1 列</td><td colspan="3" rowspan="3">2 行 2 列</td><td>2 行 5 列</td></tr>
    <tr><td>3 行 1 列</td><td>3 行 5 列</td></tr>
    <tr><td>4 行 1 列</td><td>4 行 5 列</td></tr>
    <tr><td>5 行 1 列</td><td>5 行 2 列</td><td>5 行 3 列</td><td>5 行 4 列</td><td>5 行 5 列</td></tr>
  </tbody>
</table>
SECTION 2.6 ★主役

2.6　結合子/ Combinators

HTML は不変。セレクターだけが変わる。 書式：セレクター1　結合子　セレクター2

.area p { color: blue; }
.area > p { color: blue; }
.mark ~ p { color: blue; }
.mark + p { color: blue; }
