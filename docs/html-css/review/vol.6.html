vol.6 テーブル等を構成する要素 / Table Elements

SECTION 6.1.1 & 6.1.3

テーブルの作成と行要素/ table & tr

表を定義する <table> と行を定義する <tr>。罫線は CSS で指定し、子要素は規定の順序で内包する。

<style>
  table { border-collapse: collapse; }
  th, td { border: 1px solid #444; padding: 6px 12px; }
</style>
<table>
  <tr><th>項目</th><th>状態</th></tr>
  <tr><td>CSS 罫線</td><td>二重線防止（collapse）</td></tr>
</table>
<!-- border 属性は HTML5.2 以降で廃止。CSS を使用する -->
<table border="1">
  <tr><th>項目</th><th>状態</th></tr>
  <tr><td>border="1"</td><td>古式 3D 枠線（非推奨）</td></tr>
</table>
<table border="1">
  <caption>[1] 表題</caption>
  <colgroup><col style="background:#f9f9f9"></colgroup>
  <thead><tr><th>[3] 見出し</th></tr></thead>
  <tbody><tr><td>[4] データ</td></tr></tbody>
  <tfoot><tr><td>[5] 総括</td></tr></tfoot>
</table>
要素名 カテゴリー / Category コンテンツモデル / Content Model 属性 / Attributes
table フロー・コンテンツ
パルパブル・コンテンツ		 caption → colgroup → thead → tbody（または tr） → tfoot の順序 グローバル属性
（border="1" は廃止・非推奨）
tr なし 0個以上の th・td 要素 グローバル属性
SECTION 6.1.2

表の分類/ thead, tbody & tfoot

表の構造をヘッダー（<thead>）、本体（<tbody>）、フッター（<tfoot>）に論理分割し、視認性とアクセシビリティを向上させる。

<table border="1">
  <thead>
    <tr><th>商品名</th><th>単価</th><th>数量</th></tr>
  </thead>
  <tbody>
    <tr><td>ノートPC</td><td>¥120,000</td><td>1</td></tr>
    <tr><td>マウス</td><td>¥3,500</td><td>2</td></tr>
  </tbody>
  <tfoot>
    <tr><th>合計</th><td colspan="2">¥127,000</td></tr>
  </tfoot>
</table>
<style>
  thead { background: #333; color: #fff; }
  tbody tr:nth-child(even) { background: #f9f9f9; }
  tfoot { font-weight: bold; background: #eef3f0; }
</style>
<table>
  <thead><tr><th>月</th><th>売上</th></tr></thead>
  <tbody>
    <tr><td>1月</td><td>¥500,000</td></tr>
    <tr><td>2月</td><td>¥620,000</td></tr>
    <tr><td>3月</td><td>¥580,000</td></tr>
  </tbody>
  <tfoot><tr><td>合計</td><td>¥1,700,000</td></tr></tfoot>
</table>
要素名 カテゴリー / Category 役割と特徴 / Role & Features
thead 表のヘッダーグループ（Header Group） 表の見出し行群をまとめる。table 内に 0 個または 1 個配置可能。
tbody 表のボディグループ（Body Group） 表の本体データ行群をまとめる。table 内に 0 個以上配置可能。
tfoot 表のフッターグループ（Footer Group） 表の要約・合計行群をまとめる。table 内に 0 個または 1 個配置可能。
SECTION 6.1.4

列・セルの作成/ td & th

データセル（<td>）とヘッダーセル（<th>）。読み上げ支援属性（scope, headers, abbr）でセルの対象を明示する。

<table border="1">
  <thead>
    <tr>
      <th>科目（th: 太字・中央）</th>
      <th>得点（th: 太字・中央）</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML&amp;CSS（td: 標準・左）</td>
      <td>100点（td: 標準・左）</td>
    </tr>
  </tbody>
</table>
<table border="1">
  <thead>
    <tr>
      <th scope="col">科目</th>
      <th scope="col">得点</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">HTML&amp;CSS</th>
      <td>100 点</td>
    </tr>
  </tbody>
</table>
<table border="1">
  <thead>
    <tr>
      <th id="subj" abbr="科目">Webプログラミング基礎</th>
      <th id="score" abbr="点数">期末評価得点</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td headers="subj">HTML&amp;CSS</td>
      <td headers="score">100 点</td>
    </tr>
  </tbody>
</table>
要素 / 属性 種別・仕様 詳細情報
td データセル（Data Cell） カテゴリー: セクショニング・ルート / コンテンツモデル: フロー・コンテンツ
th ヘッダーセル（Header Cell） デフォルトで太字・中央揃え表示。見出し情報を表す。
colspan="N" セル結合（列方向） 指定したセルから右方向に N 列分結合する。
rowspan="N" セル結合（行方向） 指定したセルから下方向に N 行分結合する。
scope 見出し対象範囲（th 専用） 対象範囲（col / row / colgroup / rowgroup）を指定（音声読み上げ用）。
headers 関連見出し ID 関連する th の id 属性値を指定（音声ブラウザ用）。
abbr 代替ラベル（th 専用） 見出し内容の簡略化したテキストラベルを指定（音声ブラウザ用）。
SECTION 6.2.1

表題をつける/ caption

テーブルのタイトルや概要を示す <caption> 要素。必ず <table> の直下（最初の要素）に配置し、CSS の caption-side で表示位置を調整する。

<table border="1">
  <caption>2024年度 履修科目一覧</caption>
  <thead>
    <tr><th>科目</th><th>単位</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML&amp;CSS 演習</td><td>2</td></tr>
  </tbody>
</table>
<style>
  /* 上部配置 (デフォルト) */
  .cap-top caption { caption-side: top; }
  /* 下部配置 */
  .cap-bottom caption { caption-side: bottom; text-align: right; }
</style>

<table class="cap-bottom" border="1">
  <caption>※注記：2024年4月現在のデータです</caption>
  <thead><tr><th>項目</th><th>数値</th></tr></thead>
  <tbody><tr><td>売上</td><td>100万</td></tr></tbody>
</table>
要素 / CSSプロパティ 配置規則 / 値 詳細情報
caption table の最初の直下子要素 表のタイトルや説明文を定義。表内で 1 つのみ配置可能。
caption-side top (初期値) / bottom CSS プロパティ。caption の表示位置をテーブルの上部または下部に切り替える。
SECTION 6.2.2

セルを結合する/ colspan & rowspan

横方向（列）結合の colspan、縦方向（行）結合の rowspan、および両方の組み合わせ。

<table border="1">
  <tbody>
    <tr>
      <td>1 列目</td><td>2 列目</td><td>3 列目</td><td>4 列目</td><td>5 列目</td>
    </tr>
    <tr>
      <td>1 列目</td>
      <td colspan="3">2〜4 列目を結合 (3列分)</td>
      <td>5 列目</td>
    </tr>
  </tbody>
</table>
<table border="1">
  <tbody>
    <tr><td>1 行目</td><td>1 行目</td></tr>
    <tr><td>2 行目</td><td rowspan="3">2〜4 行目を結合 (3行分)</td></tr>
    <tr><td>3 行目</td></tr>
    <tr><td>4 行目</td></tr>
    <tr><td>5 行目</td><td>5 行目</td></tr>
  </tbody>
</table>
<table border="1">
  <tbody>
    <tr><td>1行1列</td><td>1行2列</td><td>1行3列</td><td>1行4列</td><td>1行5列</td></tr>
    <tr><td>2行1列</td><td colspan="3" rowspan="3">3列×3行を結合</td><td>2行5列</td></tr>
    <tr><td>3行1列</td><td>3行5列</td></tr>
    <tr><td>4行1列</td><td>4行5列</td></tr>
    <tr><td>5行1列</td><td>5行2列</td><td>5行3列</td><td>5行4列</td><td>5行5列</td></tr>
  </tbody>
</table>
SECTION 6.2.3

列のグループ化/ colgroup & col

縦方向の列（Column）をグループ化してまとめて CSS スタイルを適用する <colgroup> と <col> 要素。

<table border="1">
  <colgroup span="2" style="background: #ffebee;"></colgroup>
  <colgroup span="1" style="background: #e3f2fd;"></colgroup>
  <thead>
    <tr><th>列 1</th><th>列 2</th><th>列 3</th></tr>
  </thead>
  <tbody>
    <tr><td>データ A</td><td>データ B</td><td>データ C</td></tr>
    <tr><td>データ D</td><td>データ E</td><td>データ F</td></tr>
  </tbody>
</table>
<table border="1">
  <colgroup>
    <col style="width: 30%; background: #fdf2f2;">
    <col style="width: 50%; background: #ffffff;">
    <col style="width: 20%; background: #eef3f0;">
  </colgroup>
  <thead>
    <tr><th>分類</th><th>詳細</th><th>備考</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML</td><td>マークアップ言語</td><td>必須</td></tr>
    <tr><td>CSS</td><td>スタイルシート</td><td>必須</td></tr>
  </tbody>
</table>
要素 / 属性 種別・仕様 詳細情報
colgroup 列グループ要素（Column Group） 表の列を論理的にグループ化する。span 属性で列数を指定可能。
col 空要素（Void Element） colgroup 内で個別の列のスタイルを定義する。終了タグ不可。
適用可能 CSS 制限あり background, width, border, visibility のみ指定可能。
