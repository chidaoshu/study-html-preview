SECTION 2.1.2

背景画像の設定 / background-image

初期値none（なし）適用要素全要素継承なし
p {
  background-image: none;
}
p {
  background-image: url("brick.png");
}
p {
  /* カンマ区切りで複数指定（先頭が最も上） */
  background-image: url("icon.png"),
                    url("pattern.png");
}
SECTION 2.1.3

画像ファイルの指定方法 / url() 関数と相対パス

構文url("画像ファイルのURL")適用対象CSS画像関数基準パスCSSファイルのあるディレクトリ
/* 相対パス（パスの基準は「CSSファイル」があるディレクトリ） */
p {
  background-image: url("../images/pattern.png");
}

/* 外部URL（絶対パス）の指定 */
h1 {
  background-image: url("https://example.com/assets/logo.svg");
}

SECTION 2.2.2

背景画像の固定・スクロール設定 / background-attachment

初期値scroll適用要素全要素継承なし
/* scroll (初期値): 要素位置に固定（内容スクロール時に動かない） */
.box-scroll { background-attachment: scroll; }

/* fixed: ビューポート（画面）に対して固定 */
.box-fixed { background-attachment: fixed; }

/* local: 要素の内容とともに背景もスクロールする */
.box-local { background-attachment: local; }

SECTION 2.3.1

背景の範囲を指定する / background-clip 🔴高頻度

初期値border-box適用要素全要素継承なし
p {
  border: 10px dashed #333;
  padding: 16px;
  background-color: #e0e7ff;
}

/* border-box (初期値): ボーダー領域まで背景を描画 */
.box1 { background-clip: border-box; }

/* padding-box: パディング領域まで背景を描画 */
.box2 { background-clip: padding-box; }

/* content-box: コンテンツ領域のみ背景を描画 */
.box3 { background-clip: content-box; }
h1 {
  background-image: linear-gradient(45deg, #d02020, #2070d0);
  /* テキストの形に背景画像を切り抜く（Chrome等は-webkit-必須） */
  -webkit-background-clip: text;
  background-clip: text;
  /* テキスト文字自体を透明化して背景を浮き上がらせる */
  color: transparent;
}
SECTION 2.3.2

背景を一括指定する / background

初期値個々のプロパティに基づく適用要素全要素継承なし
p {
  padding: 20px;
  border: 1px solid;
  background: lightblue content-box;
}
p {
  /* size を書く場合は position の直後に "/" で繋ぐ */
  background: url("ball.png")
              no-repeat 10px 20px / 100px 80px;
}
SECTION A.2.1

線形グラデーション / linear-gradient() 🔴高頻度

構文linear-gradient([方向/角度], 開始色 [位置], 終了色)適用要素全要素 (画像関数)既定方向to bottom (180deg)
/* キーワード「to」+ 方向（to right, to bottom left など） */
.box1 {
  background-image: linear-gradient(to right, #d02020, #2070d0);
}
.box2 {
  background-image: linear-gradient(to bottom left, #ff9900, #9900ff);
}
/* 角度指定 deg（時計回り: 0deg=上向き, 90deg=右向き） */
.box1 {
  background-image: linear-gradient(45deg, #d02020, #e0e7ff);
}

/* ターン指定 turn（1turn = 360deg, 0.25turn = 90deg = to right） */
.box2 {
  background-image: linear-gradient(0.25turn, #111111, #d02020);
}
/* 色階位置（カラーストップ）: 赤が10%位置、青が100%位置 */
div {
  background-image: linear-gradient(.25turn, red 10%, blue);
}

/* 3色以上の経由点指定 */
div {
  background-image: linear-gradient(to right, red 0%, yellow 50%, blue 100%);
}
