ボックスモデルの概要

1.1.1

ボックスの基本構造

🔴 重要

ボックスモデル（box model） は、HTML の各要素が持つ領域で、外側から マージン（margin）・ボーダー（border）・パディング（padding）・コンテンツ（content） の4層で構成されます。

1.1.2

ボックスの種類・display プロパティ

🔴 重要

display はボックスの種類（block / inline / inline-block など）を切り替えるプロパティです。

プロパティ値
block, inline, inline-block, その他
初期値
inline
適用要素
全要素
継承
継承されない
display

1.5.1

要素サイズの計算

🔴 重要

要素の幅・高さは border-width + padding + width（height）+ padding + border-width で計算されます。

1.5.2

要素サイズの計算方法を変更する — box-sizing

🔴 重要

box-sizing は width・height がコンテンツのみを指すか（content-box）、padding と border も含むか（border-box）を切り替えます。

プロパティ値
content-box、border-box、他
初期値
content-box
適用要素
width, height が設定可能な全要素
継承
継承されない
