3.3.2

要素の回り込みを解除する（clear）

🟡 理解

clear（Clear）は、指定した方向の float による回り込みを解除するプロパティです。

プロパティ値
キーワード
初期値
none
適用要素
全要素
継承
継承されない
clear

clear : プロパティ値;

    clear : both;

3.4

その他のプロパティ

3.4.1

要素の重なり順を指定する（z-index）

🟡 理解

z-index（Stacking Order）は、位置指定要素どうしが重なるときの前後関係を指定します。

プロパティ値
整数値、キーワード（auto）
初期値
auto
適用要素
位置指定要素（position が static 以外）
継承
継承されない
親の z-index
基本書式・例1
z-index : プロパティ値;

div {
    position: absolute;
    top : 40px ;
    left : 50px ;
    background-color: lightcoral;
    z-index: -1 ;
}
親の階層
親 auto と親 0 の子の位置を LAB で切り替えます。
3.4.2

要素を透過する（opacity）

⚪ 参考

opacity（Opacity）は、要素の不透明度を 0.0 から 1.0 の範囲で指定します。

プロパティ値
0.0 以上〜1.0 以下
初期値
1.0
適用要素
全要素
継承
継承されない
opacity
基本書式・例1
opacity : プロパティ値;

div {
    position : relative ;
    top : 50px ;
    left : 100px ;
    opacity : 0.5 ;
}
透過結果
背後の模様は上のスライダーで見え方が変わります。

「position:absolute、position:relative」のサンプル

⚪ 参考

absolute（Absolute）は、relative（Relative）を指定した親要素を基準に配置できます。

absolute-sample.html（原文コード）
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>absolute sample</title>
  <link rel="stylesheet" href="absolute-sample.css">
</head>
<body>
  <header>
    <video src="videos/sky.mp4" autoplay muted loop></video>
    <div class="header">
      <h1>夜景を見に行こう！</h1>
      <div class="box">
        <p class="explain">
          日本各地には素敵な夜景を見られるスポットがたくさんあります。<br>
          このサイトではそんな場所を紹介しています。
        </p>
      </div>
      <div class="link">
        <a href="#">Go!</a>
      </div>
    </div>
  </header>
</body>
</html>
absolute-sample.css（原文コード）
@import
url('https://fonts.googleapis.com/css2?family=Murecho&display=swap');

body {
    margin: 0px ;
}

/* 見出し */
header {
    position: relative;
    width: 100vw;
    height: 100vh ;
    overflow: hidden;  /* スクロールバーを非表示にします */
}
.header {
    position: absolute ;
    width: fit-content ;
    top: 15% ;
    left: 50% ;
    transform: translateX(-50%) ;  /* 要素の位置をX方向に50%動かします */
    color: rgb(251, 251, 106) ;
}
.header > h1 {
    font-size: 5em ;
    border-bottom: 10px solid yellow ;
    padding : 0px 40px ;
    font-family: 'Murecho', sans-serif;
}
.header > h1::before, .header > h1::after {
    content: "★" ;
}
/* 説明文。鍵かっこ風 */
.box {
    position: relative;
    padding: 1em ;
}
.box::before, .box::after {
    content:'';
    position: absolute;
    width: 20px;
    height: 30px;
}

    border-left: solid 2px white;
    border-top: solid 2px white;
    top:0;
    left: 0;
}

    right: 0;

    padding: 0 ;

「position: fixed」のサンプル

⚪ 参考

fixed（Fixed）は、ウィンドウの左上を基準にし、スクロールしても同じ位置に残ります。

fixed-sample.html（原文コード）
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>fixed sample</title>
  <link rel="stylesheet" href="fixed-sample.css">
</head>
<body>
  <header>
    <h1>注文の多い料理店</h1>
    <nav>
      <ul>
        <li><a href="#">ドリンク</a></li>
        <li><a href="#">麺類</a></li>
        <li><a href="#">ごはん</a></li>
        <li><a href="#">サービス</a></li>
      </ul>
    </nav>
  </header>
  <main>
    ここにコンテンツを表示します。
  </main>
</body>
</html>
fixed-sample.css（原文コード）
/* ヘッダー全体の設定 */
header {
    box-sizing: border-box ;
    position: fixed ;
    top: 0 ;
    width: calc(100% - 40px);
    height: 200px ;
    padding-bottom: 20px ;
    margin : 0px 20px ;
    text-align: center ;
    background-color: white ;
}
/* 見出し要素 */
h1 {
    position: relative ;
    display: inline-block;
    padding: 0 125px ;
}
h1::before, h1::after {
    display: inline-block ;
    position: absolute ;
    content: "" ;
    border : 3px solid lightskyblue ;
    background-color: lightskyblue ;
    width: 100px ;
    height: 1px ;
    top: 40%;
}
h1::before {
    margin-right: 20px ;
    left: 0px ;
}
h1::after {
    margin-left: 20px ;
    right: 0px ;
}
/* メニュー */
ul {
    margin : 0 ;
    padding: 0 ;
    text-align: center ;
}
li {
    width: calc(24% - 20px);
    display: inline-block ;
    border-bottom: 2px solid black ;
    margin-right: 20px ;
}
li:last-child {
    margin-right: 0px ;
}
li:hover {
    font-weight: 700 ;
    font-size: 1.2em ;
    border-bottom: 4px solid red ;
}
a {
    box-sizing: border-box ;
    display: block ;
    width: 100% ;
    padding: 20px ;
    text-decoration: none ;
}

A.4

「z-index」「opacity」のサンプル

⚪ 参考

relative・absolute・z-index・opacityを組み合わせ、ホバーでドロップダウンを表示します。

dropdown-sample.html（原文コード）
<body>
  <nav class="main-nav">
    <ul>
      <li class="dropdown">
        <a href="#">メニュー</a>
        <ul class="dropdown-menu">
          <a href="#">ご飯もの</a>
          <a href="#">麺類</a>
          <a href="#">サラダ</a>
          <a href="#">デザート</a>
          <a href="#">ドリンク</a>
        </ul>
      </li>
    </ul>
  </nav>
</body>
dropdown-sample.css（原文コード）
.main-nav {
    padding: 10px 0;
    position: relative;
    z-index: 10;
}
.main-nav ul {
    list-style: none;  /* リストのデフォルトスタイルを削除 */
    margin: 0;
    padding: 0;
    display: inline-block; /* 横並び */
}
.main-nav li {
    position: relative; /* ドロップダウンメニューの基準点 */
}
.main-nav a {
    display: block; /* a要素をブロック要素にする */
    padding: 10px 20px;
    color: white;
    background-color: #444;
    text-decoration: none; /* リンクの下線を削除 */
}
.main-nav a:hover {
    background-color: #555;
}
.dropdown-menu {
    list-style: none;
    margin: 0;
    padding: 0;
    position: absolute; /* 親要素（li）を基準に配置 */
    top: 100%;
    left: 0;
    background-color: #444;
    min-width: 160px;
    opacity: 0;
    visibility: hidden;
    z-index: 20;
}
.dropdown-menu li {
    width: 100%;
}
.dropdown-menu a {
    color: white;
    padding: 12px 16px;
    text-decoration: none;
    display: block;
    text-align: left;
}
.dropdown-menu a:hover {
    background-color: #666;
}
.dropdown:hover .dropdown-menu {
    opacity: 1.0;
    visibility: visible;
}
