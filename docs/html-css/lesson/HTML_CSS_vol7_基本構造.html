7.1

基本構造を示す要素

基本構造を示す要素（structural elements）は、文書全体の構造や各部位の役割を明示し、検索エンジンへ正しく伝えるための要素群です。

7.1.1

header 要素

🔴 重要

header 要素（header element）は、Web ページや各セクションの冒頭に配置し、タイトル・ロゴ・ナビゲーションなどを記述する要素です。

カテゴリー
フロー・コンテンツ（Flow Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ（但し header・footer 要素は含みません）
属性
グローバル属性（Global Attributes）
HTML
7.1.2

main 要素

🔴 重要

main 要素（main element）は、文書や body 要素内の中心的な主題に直接関連する主要コンテンツの範囲を表す要素です。

カテゴリー
フロー・コンテンツ（Flow Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ
属性
グローバル属性（Global Attributes）
HTML
7.1.3

footer 要素

🔴 重要

footer 要素（footer element）は、Web ページ全体または各セクションの末尾に配置し、著作権表示や関連情報を記述する要素です。

カテゴリー
フロー・コンテンツ（Flow Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ（但し header・footer 要素は含みません）
属性
グローバル属性（Global Attributes）
HTML

⚪ 参考

基本構造の組み立ては、header・main・footer を組み合わせて Web ページ全体の骨組みを構築する実践例です。

7.2

セクションを表す要素

セクション（section）は、見出しとその内容のまとまりであり、持つ意味に応じて 4 つの要素に分類されます。

7.2.1

section 要素

🔴 重要

section 要素（section element）は、文書内の一般的な章・節・項などのセクションを表し、通常は内部に見出しを含めます。

カテゴリー
フロー・コンテンツ（Flow Content）、セクショニング・コンテンツ（Sectioning Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ
属性
グローバル属性（Global Attributes）
HTML
7.2.2

article 要素

🔴 重要

article 要素（article element）は、ブログ記事やニュースのように単体で独立・自己完結しているセクションを表す要素です。

カテゴリー
フロー・コンテンツ（Flow Content）、セクショニング・コンテンツ（Sectioning Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ（main 要素は除く）
属性
グローバル属性（Global Attributes）
HTML
7.2.3

aside 要素

🟡 理解

aside 要素（aside element）は、主要コンテンツに関連しつつも切り離せる補足記事やサイドバーを表す要素です。

カテゴリー
フロー・コンテンツ（Flow Content）、セクショニング・コンテンツ（Sectioning Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ（main 要素は除く）
属性
グローバル属性（Global Attributes）
HTML
7.2.4

nav 要素

🔴 重要

nav 要素（nav element）は、現在のページ内や他ページへの主要なナビゲーションリンク群をまとめるセクションです。

カテゴリー
フロー・コンテンツ（Flow Content）、セクショニング・コンテンツ（Sectioning Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ（main 要素は除く）
属性
グローバル属性（Global Attributes）
HTML
7.3

特別な意味を持たない要素

特別な意味を持たない要素（generic elements）は、固有の意味を持たず、スタイル適用やグループ化のために使用される要素です。

7.3.1

div 要素

🔴 重要

div 要素（div element）は、ブロックレベルの汎用コンテナとして、複数の要素をグループ化しスタイルやレイアウトを適用する要素です。

カテゴリー
フロー・コンテンツ（Flow Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フロー・コンテンツ、他
属性
グローバル属性（Global Attributes）
HTML
7.3.2

span 要素

🟡 理解

span 要素（span element）は、インラインの汎用コンテナとして、テキストの一部をグループ化しスタイルを適用する要素です。

カテゴリー
フロー・コンテンツ（Flow Content）、フレージング・コンテンツ（Phrasing Content）、パルパブル・コンテンツ（Palpable Content）
コンテンツモデル
フレージング・コンテンツ、他
属性
グローバル属性（Global Attributes）
