1.1

CSS とは

🔴 試験重要

CSS（Cascading Style Sheets）は、Web ページのレイアウト（layout）と装飾を定義する言語です。

color
基本書式の読み方
セレクターが対象を選び、プロパティが種類、値が設定内容を表します。「プロパティ: 値;」が宣言で、{ } 内のまとまりが宣言ブロックです。CSS のコメントは /* */ で書き、// は使えません。空白や改行はコードの見た目を変えますが、意味は変えません。

2.2.3

その他の疑似クラス

🟡 理解でOK

その他の疑似クラス（other pseudo-classes）は、リンクの状態や子要素の順番など、特定の条件に一致する要素を対象にします。

子要素 / 要素型
分類文法教材の説明
リンク:activeマウスのボタンが押されている状態を示します。
リンク:visitedリンク先をすでにクリック済みの a 要素を示します。
リンク:linkリンク先をまだクリックしていない状態の a 要素を示します。
子要素:nth-last-child(引数)引数で指定した番号の子要素を最後から数えます。
子要素:nth-last-of-type(引数)指定した要素だけを対象に、最後から番号を数えます。
その他:not(引数)引数で指定したセレクターに一致しない要素を示します。
その他:is(引数)引数で指定したセレクターのいずれかに一致する要素を示します。
その他:has(引数)該当する要素が 1 つ以上ある先祖要素を示します。

2.6.1

子孫結合子（半角スペース）

🔴 試験重要

子孫結合子（descendant combinator）は、左側の要素の中にあるすべての子孫から、右側のセレクターに一致する要素を対象にします。

combinator
2.6.2

子結合子（>）

🔴 試験重要

子結合子（child combinator）は、左側の要素の直下にある子要素だけを対象にし、孫以下の要素は対象にしません。

combinator
2.6.3

後続兄弟結合子（~）

🔴 試験重要

後続兄弟結合子（subsequent-sibling combinator）は、左側の要素より後にある同じ親の兄弟要素から対象を選びます。

combinator
2.6.4

次兄弟結合子（+）

🔴 試験重要

次兄弟結合子（next-sibling combinator）は、左側の要素の直後にある一つの兄弟要素だけを対象にします。

combinator

ファビコンの作成と表示

⚪

ファビコン（favicon / favorite icon）は、ブラウザのタブやアドレスバーに表示されるページのアイコンです。

HTML（head 要素内）
<link rel="icon" href="ファビコンファイルまでのパス">
指定の役割
rel="icon"：文書のアイコンを指定 href：ファビコンファイルまでのパス このページ自身には data URI を設定
表示場所：favicon はブラウザのタブやアドレスバーに表示されるため、iframe 内には表示されません。このページ自身には data URI の favicon を設定しているので、存在しない外部ファイルの 404 は発生しません。
