グリッドレイアウトとは

🟡 理解

グリッドレイアウト（grid layout）は、水平と垂直の2次元で区切り、部品を指定位置に配置する方式です。

display

グリッドレイアウトの構成物

🟡 理解

構成物（grid parts）は、コンテナ、アイテム、ライン、セル、エリア、トラック、ギャップです。
