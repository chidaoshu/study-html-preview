1.2

色の指定

色の指定（Color Specification）は、RGB（加法混合）や HSL などのカラーモデルを用いてデジタル上の色を表現する仕組みです。

カラーモデル 概要と仕組み 主な用途
RGB カラーモデル 赤(Red)・緑(Green)・青(Blue) の三原色を混ぜて表現する加法混合 ディスプレイ、デジタルカメラ等
HSL カラーモデル 色相(Hue)・彩度(Saturation)・輝度(Lightness) の3要素で表現 直感的な色の調整
1.2.1

🔴 重要

数値による色指定（Hexadecimal Color Specification）は、「#」に続けて RGB の各成分を 16 進数（0〜F）で指定する方法です。

color

2.7

長さの指定

長さの指定（Length Units）は、CSS でサイズや間隔を定義するための単位であり、「絶対長さ」と「相対長さ」に大別されます。

分類 特徴 主な単位
絶対長さ（Absolute Length） 他の要素の長さに関係なく常に同じ長さを表現する px, cm, mm, in, pt, pc, Q
相対長さ（Relative Length） 要素のフォントサイズやビューポート（画面領域）に対する比率で表現する em, rem, vw, vh, vmin, vmax, lh, ex, ch
2.7.1

絶対長さ（Absolute Length）

🟡 理解

絶対長さ（Absolute Length）は、画面サイズや他要素に関係なく常に固定の長さを表現する単位です。

width / font-size
単位 説明
cm センチメートルを表します。
mm ミリメートルを表します。
Q quarter-millimeters の略で、1 Q = 0.25 mm を表します。
in inches の略で、1 in = 25.4 mm を表します。
pc pica（パイカ）の略で、1 pc = 1/6 in を表します。
pt point（ポイント）の略で、1 pt = 1/72 in を表します。
px pixel（ピクセル）の略称です。1 px = 1/96 in を表します。
