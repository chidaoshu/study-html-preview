3.5.3トップ N の表示（12c 以降）重要

ROWS ONLY は同順位が複数いても n 件しか表示されない ／ WITH TIES なら同順位をすべて表示できる ／ スキップする行数は同順位を考慮できない
emp を sal 順に n 件 ／ 3000 が 2 人・1250 が 2 人 
SELECT ename, sal, deptno FROM emp
ORDER BY sal FETCH FIRST 5 ROWS ONLY;
