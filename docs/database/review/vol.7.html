3.16.1複数の表から必要なデータを取り出す重要

3.16.4結合の種類重要

結合には、分類の方法によって、次のような種類があります。
種類説明結合条件の例
等価結合結合条件が＝で結ばれたものemp.deptno = dept.deptno
非等価結合結合条件が＝でなく、幅のある条件emp.sal BETWEEN salgrade.losal AND salgrade.hisal
自然結合同名・同データ型の列を自然に結合条件列とみなす。結合条件列の一方が削除されるNATURAL JOIN／JOIN ～ USING（列名）
結果の戻し方による分類
種類説明JOIN句の書き方
デカルト積結合条件のない結合。2つの表の全行を結合するFROM emp CROSS JOIN dept
内部結合結合条件を満たす行のみを返すFROM emp INNER JOIN dept
外部結合結合条件を満たす対応するデータが他方に無い行も返すFROM emp LEFT OUTER JOIN dept（RIGHT／FULL OUTER JOIN）
特殊な結合
種類説明JOIN句の書き方
自己結合表の別名を利用し、1つの表を自分自身と結合するFROM emp e JOIN emp m ON e.mgr = m.empno

3.17.4表名による修飾重要

結合に使用する表の中に同じ名前の列がある場合、どちらの表の列なのかという情報を、オラクルサーバに示す必要があります。これを、「表名により修飾する」といい、「表名.列名」のように列名の前に表名を付けて表記します。
同じ名前の列の場合、一般的には、表名で修飾しなければエラーとなる
emp.deptno = dept.deptno を deptno = deptno と書くと？

ON deptno = deptno;

3.19.4選択条件の追加重要

句の順番は以下の通りです： 1. SELECT ／ 2. FROM（JOIN等） ／ 3. WHERE ／ 4. GROUP BY ／ 5. HAVING ／ 6. ORDER BY
ON句やUSING句はFROM句に付随しているため、FROM句のあとに指定します。WHERE句のあとにON句のみ続ける書き方はできません。
結合条件と選択条件をANDでつなぐ場合、どちらを先に指定しなければならないというルールはありません。
emp / dept, empno > 7800 の絞り込み 
SELECT ename, deptno, dname
FROM emp JOIN dept USING(deptno)
WHERE empno > 7800;
結合条件はUSING句、選択条件はWHERE句
