3.6.1関数とは?

SQL 関数の引数は 列名やリテラル値 ／ 戻り値として結果をひとつ返す
関数概念引数（入力）処理・働き戻り値（出力）
multiply(a, b)a, b（例：2, 50）2 値を掛け合わせる（内部処理は隠蔽）z（例：100）
SQL 関数列名 や リテラル値（() 内に カンマ区切り）各行またはグループごとの処理計算・変換結果

3.6.2SQL 関数の種類必修

単一行関数は 1 行ごとに処理し 1 行ごとに結果を返す ／ グループ関数はグループごとに集計
関数の種類処理単位戻り値の行数主な用途・例
単一行関数SQL により戻される行の 1 行ごと各行に対して 1 行ずつLOWER, UPPER, SUBSTR, ROUND 等
グループ関数表全体 または 小グループごとグループごとに 1 行（集計）SUM, AVG, COUNT, MAX, MIN 等
単一行関数はリテラルを直接引数に指定でき dual 表で確認できる
dual 表のデータ構造確認 ／ 1 行 1 列のダミー表 
SELECT * FROM ⟦dual⟧;
DUMMY 列に 1 行のダミーデータ（'X'）を保持するシステム表

3.7.1文字関数の種類必修

文字関数は文字を引数に受け取り 文字や数値を戻す
関数説明戻り値の型
LOWER(s)すべて小文字に変換する文字
UPPER(s)すべて大文字に変換する文字
INITCAP(s)単語ごとに先頭を大文字、残りを小文字に変換する（記号区切り）文字
LPAD(s, n, c)指定桁数に満たない場合、左側に指定文字を埋める文字
RPAD(s, n, c)指定桁数に満たない場合、右側に指定文字を埋める文字
TRIM(c FROM s)文字列の前後から指定文字（1字のみ）を取り除く文字
REPLACE(s, o, n)文字列中の旧字 o を新字 n に置き換える（省略で削除）文字
CONCAT(s1, s2)文字列1と文字列2を結合する（s1 || s2 と同じ）文字
SUBSTR(s, m, n)s の m 文字目から n 文字分を抽出する（n 省略で最後まで）文字
INSTR(s, f, m, n)s 中で検索文字 f が現れる位置を返す（m:開始位置, n:出現回数）数値
LENGTH(s)文字列の文字数を返す（2バイト文字も1文字）数値
LENGTHB(s)文字列のバイト数を返す（2バイト文字は2字）数値

3.7.2LOWER、UPPER、INITCAP

LPAD・RPAD は指定桁数に満たない場合に文字を埋め込む ／ 指定桁数を超えた場合は左から切り取る

3.7.4TRIM 関数

TRIM は文字列の前後から指定文字を取り除く ／ 指定文字に文字列は使用不可（1字のみ）

SELECT TRIM('-' FROM '---SC--OTT---') FROM dual;SC--OTT
SELECT TRIM(LEADING '-' FROM '---SCOTT---') FROM dual;SCOTT---
SELECT TRIM(TRAILING '-' FROM '---SCOTT---') FROM dual;---SCOTT
SELECT TRIM(BOTH '-' FROM '---SCOTT---') FROM dual;SCOTT
SELECT TRIM('　SCOTT　') FROM dual;SCOTT

3.7.5REPLACE

REPLACE は文字列中の文字を置換する ／ 新字を省略すると旧字を取り除く
SELECT REPLACE('ANZAI','A','O') FROM dual;ONZOI
SELECT REPLACE('ANZAI','ZA','ZO') FROM dual;ANZOI
SELECT REPLACE('ANZAI','A') FROM dual;NZI

3.7.6CONCAT

CONCAT は 2 つの文字列を結合する ／ || 演算子と同じ働き

SELECT CONCAT( CONCAT(first_name,' '),last_name) FROM person;Elizabeth Bates

3.7.7LENGTH、LENGTHB

LENGTH は文字数（全角も1文字）を返し LENGTHB はバイト数を返す ／ NULL は NULL

3.7.8INSTR、INSTRB

3.10.2RR 日付書式

0〜49（例：2022年）同じ世紀（上2桁が同じ）前の世紀（100 年前）
50〜99（例：1999年）次の世紀（100 年後）同じ世紀（上2桁が同じ）
RR 書式による世紀の補完 ／ 2000 年問題対応書式

3.11.4MONTHS_BETWEEN

MONTHS_BETWEEN は2つの日付の差を月数で戻します ／ 2つの日にちが同じ場合 ／ 2つとも月末日の場合
MONTHS_BETWEEN 月数差計算 ／ 端数は小数（30日/月計算） 
SELECT MONTHS_BETWEEN(SYSDATE, TO_DATE('11-01-01')) 年初からの経過月 FROM dual;
割り切れない場合は、ひと月を 30 日として計算し、端数を小数で返します
年初からの経過月
6.16129032
 
SELECT MONTHS_BETWEEN(TO_DATE('11-07-01'), TO_DATE('11-01-01')) 月数 FROM dual;
2つの日にちが同じ場合は整数が返る
月数
6
 
SELECT MONTHS_BETWEEN(TO_DATE('11-06-30'), TO_DATE('11-02-28')) 月数 FROM dual;
2つとも月末日の場合も整数が返る
月数
4

3.11.5ADD_MONTHS

ADD_MONTHS は日付に、数値で指定した月数を足して、日付を返します ／ 月末日の場合
ADD_MONTHS 月数加算・減算 ／ 月末日の特殊処理 
SELECT ADD_MONTHS (SYSDATE,3) "3 ヶ月後" FROM dual;
第 2 引数に正の数を指定して月数を加算
3 ヶ月後
11-10-06
 
SELECT ADD_MONTHS (SYSDATE,-3) "3 ヶ月前" FROM dual;
第 2 引数に負の数を指定すると、月数を減算した日付を戻します
3 ヶ月前
11-04-06
 
SELECT ADD_MONTHS(TO_DATE('11-07-31'), 2) 月末日の例 FROM dual;
第1引数の日付が月末日だった場合は、n ヶ月後の月末日を返します
月末日の例
11-09-30

3.11.6NEXT_DAY、LAST_DAY

NEXT_DAY は次に訪れる指定曜日の日付を返す関数です ／ LAST_DAY は月末日を求める関数です
NEXT_DAY / LAST_DAY 日付算出 ／ 曜日指定と月末算出 
SELECT NEXT_DAY(SYSDATE,'月') 次の月曜 FROM dual;
第1引数に指定した日付よりも後で、第2引数の曜日の日付を返します
次の月曜
11-07-11
 
SELECT LAST_DAY(SYSDATE) 月末日 FROM dual;
第１引数と同じ月の月末日が返ります
月末日
11-07-31

3.11.7ROUND、TRUNC

ROUND 関数、TRUNC 関数によって、日付データの四捨五入、切り捨てができます
11:59:59 (午前捨)12:00:00 (午後入)
11-07-06 11:59:59 → 06 00:00:00
11-07-06 12:00:00 → 07 00:00:00
ROUND(d, 'DD') → 正午（午後 12 時）を基準に翌日 00:00:00 へ繰り上がり
日付の ROUND（四捨五入） ／ DD, AM/PM, MM, YY 単位 
ALTER SESSION SET nls_date_format = 'RR-MM-DD HH24:MI:SS';
-- 例 1) SELECT ROUND(TO_DATE('11-07-06 11:59:59'), 'DD') DD FROM dual;
-- 例 2) SELECT ROUND(TO_DATE('11-07-06 12:00:00'), 'DD') DD FROM dual;
-- 例 3) SELECT ROUND(TO_DATE('11-07-06 15:00:00')) 省略 FROM dual;
時間は正午を基準に四捨五入（午前捨午後入）
DD
11-07-06 00:00:00
11-07-07 00:00:00
11-07-07 00:00:00
 
ALTER SESSION SET nls_date_format = 'RR-MM-DD AMHH12:MI:SS';
-- 例 4) SELECT ROUND(TO_DATE('11-07-06 午前 12:00:00'), 'DD') 午前 FROM dual;
-- 例 5) SELECT ROUND(TO_DATE('11-07-06 午後 12:00:00'), 'DD') 午後 FROM dual;
12 時間表記：午前 12 時＝深夜 0 時、午後 12 時＝正午
午前 / 午後
11-07-06 午前 12:00:00
11-07-07 午前 12:00:00
 
ALTER SESSION SET nls_date_format = 'RR-MM-DD HH24:MI:SS';
-- 例 6) SELECT ROUND(TO_DATE('11-07-15 23:59:59'), 'MM') MM FROM dual;
-- 例 7) SELECT ROUND(TO_DATE('11-07-16 00:00:00'), 'MM') MM FROM dual;
-- 例 8) SELECT ROUND(TO_DATE('11-06-30 23:59:59'), 'YY') YY FROM dual;
-- 例 9) SELECT ROUND(TO_DATE('11-07-01 00:00:00'), 'YY') Y FROM dual;
MM は 15 捨 16 入、YY は 6 月捨 7 月入
MM / YY
11-07-01 00:00:00
11-08-01 00:00:00
11-01-01 00:00:00
12-01-01 00:00:00
日付の TRUNC（切り捨て） ／ DD（時間切捨て）, MM（日切捨て）, YY（月切捨て） 
-- 例 1) SELECT TRUNC(TO_DATE('11-07-06 20:00:00'), 'DD') 午後 FROM dual;
DD での切り捨て ／ 時間部分を切り捨て年月日（00:00:00）を返す
午後
11-07-06 00:00:00
 
-- 例 2) SELECT TRUNC(TO_DATE('11-07-20 20:00:00'), 'MM') 月 FROM dual;
MM での切り捨て ／ 日以下を切り捨て当月 1 日（00:00:00）を返す
月
11-07-01 00:00:00
 
-- 例 3) SELECT TRUNC(TO_DATE('11-10-06 20:00:00'), 'YY') 年 FROM dual;
YY での切り捨て ／ 月以下を切り捨て当年 1 月 1 日（00:00:00）を返す
年
11-01-01 00:00:00
