1.2.1SQL とは？必修

SQL は非手続き型言語で処理手順はオプティマイザが決定 ／ 標準 SQL 規格（SQL:1999・SQL:2016）
行の追加（INSERT）
INSERT INTO 商品表 VALUES ('S6', 'Java入門', 2500, 8);
行の変更（UPDATE）
UPDATE 商品表 SET 在庫 = 3 WHERE 商品ID = 'S6';
行の抽出（SELECT）
SELECT 商品ID, 商品名, 単価 FROM 商品表 WHERE 商品ID = 'S6';
行の削除（DELETE）
DELETE FROM 商品表 WHERE 商品ID = 'S6';
項目内容
名称由来もともとは「SEQUEL」（シーケル：Structured English Query Language）という名称に由来しますが、登録商標上の問題が発生したため「SQL」と改名され、現在に至っています。
言語分類非手続き型言語（Non-procedural language）— 処理手順は DBMS のオプティマイザ（Optimizer）が自動決定
標準規格標準 SQL 規格（Standard SQL）— ANSI, ISO, JIS により標準化（SQL:1999, SQL:2016）

1.2.2SQL の種類必修

DDL（データ定義言語）・DML（データ操作言語）・DCL（データ制御言語）・TCL（トランザクション制御言語）の 4 種に分類
DDL（Data Definition Language / データ定義言語）
スキーマ（Schema）やオブジェクトを定義する文：CREATE DROP ALTER RENAME など
DML（Data Manipulation Language / データ操作言語）
データを操作する文：SELECT INSERT DELETE UPDATE など
DCL（Data Control Language / データ制御言語）
権限を制御する文：GRANT REVOKE など
TCL（Transaction Control Language / トランザクション制御言語）
トランザクションを制御する文：COMMIT ROLLBACK SAVEPOINT など
階層構成オブジェクト
データベース各ユーザーのスキーマ（Schema）
スキーマ（Schema）テーブル（Table）、ビュー（View）、索引（Index）、その他オブジェクト

1.2.3SQL の文と句応用

文（Statement）は命令全体、句（Clause）は文を構成する各パーツ
区分定義該当する命令・パーツ
文（Statement）データを抽出・操作・定義する命令全体CREATE 文、DROP 文、ALTER 文 (DDL)
SELECT 文、INSERT 文、DELETE 文、UPDATE 文 (DML) など
句（Clause）文を構成する各パーツSELECT 句、FROM 句、WHERE 句、ORDER BY 句、HAVING 句 など
構成パーツ（句）役割指定内容例（SELECT 文の構造）
SELECT 句列の指定SELECT 商品コード, 商品名
FROM 句表の指定FROM 商品台帳
WHERE 句行の絞り込みWHERE 商品コード LIKE 'ABC%'

1.2.4関数の利用応用

単一行関数とグループ関数に分類 ／ 関数は SELECT 句・WHERE 句・HAVING 句など様々な句で使用できる
関数分類処理の特徴
単一行関数（Single-row function）1 行ごとに処理を実行して結果を返す
グループ関数（Group function）複数行をまとめて集計処理し結果を返す

1.2.5Java 等のプログラムと DB の関係応用

Java 等のプログラムに SQL を埋め込んで利用 ／ HTML・Java・SQL が連携してシステムを構成
システム階層役割使用言語・技術
画面（フロントエンド）画面の作成と表示（入力・結果表示）HTML, CSS
AP サーバー（ロジック）システム全体の制御・Java 実行環境Java（SQL 文を埋め込んで実行）
DB サーバー（DBMS）データの検索・登録・更新・削除SQL, RDBMS（Oracle 等）
■ Java コード内での SQL 埋め込み例 (JDBC)

           + text.getText() + "%' ORDER BY itemid";
ResultSet rs = stmt.executeQuery(sql);

1-3主な RDBMS 製品応用

現在主流となっている RDBMS 製品（Oracle・SQL Server・DB2・MySQL・PostgreSQL・Access・SQLite）
製品名ベンダー対応 OS特徴
OracleOracleUNIX, Linux, Windows市場でのシェアは No.1 です。大規模なシステムでの利用実績が豊富で、学習対象という点でも、一般的によく取り上げられる RDBMS です。参考書籍や情報も豊富です。
SQL Server (MSDE)MicrosoftWindowsコストと性能のバランスが優れています。Microsoft の .NET 技術との親和性が高く、両者を組み合わせたシステム開発に適しています。
DB2IBMUNIX, Linux, Windows, OS/400 などOracle と並び、歴史と実績があります。ただし、参考書籍や情報に乏しい傾向があり近年はシェアが縮小しつつあります。
MySQLMySQL AB ※ただし、現在は Oracle 社から配布 (オープンソース / Open source)UNIX, Linux, Windows などスウェーデンの MySQL AB 社が開発した RDBMS です。オープンソースであり動作が軽快なため、小・中規模な Web 系システムでの実績が多い。現在は Oracle 社がサポートしており、シェアは Oracle データベースに匹敵する勢いで増加しています。Ver. 5.0 以降ではストアドプロシージャ（Stored procedure）、ビュー（View）、トリガー（Trigger）が実装され機能が充実してきている。
PostgreSQLPostgreSQL プロジェクトのメンバー (オープンソース / Open source)UNIX, Linux, Windowsオープンソースの RDBMS で、ストアドプログラム作成機能も備えた本格的な製品。Oracle と同様、マルチバージョニング（Multi-versioning）による同時実行制御を採用しています。近年、Oracle がライセンス料を引き上げたことにより、オープンソースに人気が集まり新規システムでの採用が増加しています。
Access (Jet Database Engine)MicrosoftWindowsAccess のフォームなどと一緒に利用できるため, システム全体の構築が比較的容易です。ただし、ネットワークを利用したシステムの構築には適しておりません。初心者向きと言えますが、RDBMS 特有のメカニズムなどを学習するのにも適しておりません。
SQLiteパブリックドメイン（Public domain）Windows, Mac, Linux, Android, iOS などサーバとしてではなくアプリケーションに組み込んで使用されることを目的とした軽量なデータベースライブラリ。データの保存には単一のファイルを利用する。Android アプリケーションなどから利用することができる。
