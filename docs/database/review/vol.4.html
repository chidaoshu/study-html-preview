MOJI
I'm boy
 
SELECT q'⟦0⟧I'm boy⟦0⟧' AS moji FROM dual;
数字 0 をデリミタに使用
MOJI
I'm boy
 
SELECT q'⟦<⟧I'm boy⟦>⟧' AS moji FROM dual;
カッコは左右対の記号を使用する
MOJI
I'm boy

シングルクォーテーションを 2 回重ねる方法

SELECT q'II'm boyI' AS moji FROM dual;

3.4.8特殊な比較演算子 - LIKE 演算子重要

◆ ワイルドカードによる文字列のパターンマッチング
文字意味
_ (アンダースコア)任意の一文字を示す
% (パーセント)任意の 0 文字以上の数の文字を示す
◆ ワイルドカードの使用例

WHERE ename LIKE ⟦'%A%'⟧
