3.13.1一般関数の種類必修

一般関数は主に NULL 値を変換する処理を中心に、ユーティリティとしての機能を持つ関数
関数 / 式説明戻り値のデータ型
NVL(値1, 値2)値1 が NULL でない場合は値1、NULL の場合は値2 を返す。第1引数のデータ型（引数の型を合わせる）
NVL2(値1, 値2, 値3)値1 が NULL でない場合は値2、NULL の場合は値3 を返す。第2引数のデータ型（第2・第3引数の型を合わせる）
COALESCE(値1, 値2, …)引数リストの中で最初の非 NULL 値を返す。すべて NULL なら NULL。第1引数のデータ型（すべての引数の型を合わせる）
NULLIF(値1, 値2)値1 と値2 が等しい場合は NULL、等しくない場合は値1 を返す。第1引数のデータ型（引数の型を合わせる）
CASE 式条件に応じた値を返す (WHEN 条件 THEN 値 [ELSE デフォルト] END)。最初に指定する THEN 式のデータ型に合わせる

3.14.1グループ関数の特徴必修

グループ関数は行のグループに対してひとつの結果を返す ／ SELECT 句、HAVING 句、ORDER BY 句でのみ使用可能
特徴詳細ルール
処理対象行のグループに対してひとつの結果を返す（集合関数）
使用可能な句SELECT 句、HAVING 句、ORDER BY 句でのみ使用可能（WHERE 句では不可）
ネストの制限グループ関数同士は第 2 レベルまでネスト可能 (例: MAX(AVG(sal)))
単一列との共存GROUP BY 句で指定されていない単一列とは一緒に選択できない

3.14.2グループ関数の種類必修

グループ関数の計算結果には通常 NULL 値は含まれない ／ COUNT(*) のみ NULL 値を含んだ行数が返る
関数説明引数にとれるデータ型
AVG平均値を戻す数値のみ (NUMBER)
SUM合計値を戻す数値のみ (NUMBER)
COUNT行数を返す文字・数値・日付 (CHAR, VARCHAR2, NUMBER, DATE)
MAX最大値を戻す文字・数値・日付 (CHAR, VARCHAR2, NUMBER, DATE)
MIN最小値を戻す文字・数値・日付 (CHAR, VARCHAR2, NUMBER, DATE)

3.14.3AVG、SUM 関数標準

AVG は平均・SUM は合計を返す ／ 引数は数値型のみ ／ NULL 値は自動的に無視される

3.15.4句の順番必修

処理順: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY ／ WHERE 句は GROUP BY 句より先
順序句内部処理内容
1FROM 句対象表の特定および結合の実行
2WHERE 句グループ化前に行単位での絞り込み（グループ関数不可）
3GROUP BY 句残った行を小グループにグループ化
4HAVING 句グループ化された行・集計結果に対する絞り込み
5SELECT 句列の取り出し、式・単一行関数・グループ関数の評価
6ORDER BY 句最終結果の並べ替え（列別名の利用が可能）

3.15.5グループ関数と GROUP BY 句によって戻される行数標準

グループ関数のネストは第 2 レベルまで ／ ネストする場合は必ず GROUP BY 句を伴う
構文パターン返される行数特徴
SELECT AVG(sal) FROM emp;1 行表全体で 1 つの結果を返す
SELECT job, AVG(sal) FROM emp GROUP BY job;複数行 (5行)グループごとに 1 つの結果を返す
SELECT MAX(AVG(sal)) FROM emp GROUP BY job;1 行ネスト時は GROUP BY が必須で最終結果は 1 行

3.15.6単一行関数とグループ関数の特徴の違い必修

単一行関数とグループ関数の特徴の違い
比較項目単一行関数グループ関数
処理と結果1 行ごとに処理し、1 行ごとに結果を返す行のグループに対して処理し、1 つの結果を返す
使用可能 DML / 句全 DML (SELECT, INSERT, UPDATE, DELETE) で利用可SELECT 文のみ（SELECT, HAVING, ORDER BY 句）
ネスト制限制限なし第 2 レベルまで（グループ関数同士）
引数の数関数ごとに固定常に 1 つだけ
