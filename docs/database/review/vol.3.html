3.1.1SELECT 文の主な句重要

SELECT 句と FROM 句は必須 ／ 記述順を間違えるとエラー
句必須 / 任意指定内容
SELECT 句必須表示する「列名」を指定（複数列はカンマで区切る）
FROM 句必須データが格納されている「表名」を指定
WHERE 句任意必要な行を取り出すための「条件式」を指定
GROUP BY 句任意グループ化する「列名」を指定
HAVING 句任意グループ化された後の行を絞り込む「条件式」を指定
ORDER BY 句任意結果の表示順番を「並べ替えるための列名」を指定

3.2.2射影（SELECT 句）重要

射影 — 表から必要な列（Column）データのみを取り出す ／ キーワード・列名・表名は大文字・小文字は区別しない（ただし、後に説明しますが文字リテラル（Character Literal）については、大文字・小文字を区別します。）
ENAME 列と SAL 列を抽出する（射影） 
SELECT ename, sal FROM emp;

3.2.3選択（WHERE 句）重要

選択 — WHERE 句で指定した条件に一致する行のみ取り出す ／ 列名を左・リテラルを右に記述
empno が 7499 または 7876 の行を抽出する（選択） 
SELECT * FROM emp
WHERE empno = 7499 OR empno = 7876;
WHERE 句の条件に一致する行のみ絞り込む ／ 列名を左、リテラル（値）を右に記述する ／ 条件省略時は全行表示

3.2.4結合（FROM～JOIN 句）重要

結合 — ２つ以上の表をもとに結合条件に基づきデータを取り出す ／ 結果の表を「導出表」と呼ぶ

3.3.1射影 ― projection重要

すべての SELECT 文において、SELECT 句と FROM 句は必須 ／ 単一の表から取り出す場合でも、表名を指定した方が検索の速度が向上します ／ SQL 文の終わりは ;（セミコロン）を打ちます
SELECT 文の基本構造 
SELECT 列名 FROM 表名
SELECT 句と FROM 句はすべての SELECT 文で必須
1 列の抜き出しと表名修飾 
SELECT ⟦ename⟧ FROM emp;
1 つの列を抜き出す
SELECT ⟦emp.ename⟧ FROM emp;
表名.列名 と指定すると検索速度が向上する（複数表指定時は必須）
複数の列を抜き出す 
SELECT empno, ename, sal FROM emp;
カンマ区切りで列リストを指定（SELECT 句に指定した順番に表示される）

3.3.2全データの表示重要

表に格納された全てのデータを表示するには、*（アスタリスク）を使用することができる ／ プログラムに SQL を埋め込む場合はなるべく列名を明記します
* ワイルドカードですべての列を表示する 
SELECT * FROM emp;
CREATE TABLE で定義した順番で全列表示 ／ 行の並び順は挿入順と無関係
全列名を列挙する 
SELECT empno, ename, job, mgr, hiredate, sal, comm, deptno FROM emp;
プログラム埋め込み時はデータ構造変更によるバグを防ぐため列名を明記する

DESCRIBE コマンドで表の構造を確認する
