1.1.1データとデータベース重要

DBMS は整合性（Integrity）の維持・トランザクション（Transaction）処理機能・不正アクセス防止・ログ取得とバックアップ／リカバリ機能を持つ
基本概念・用語定義・試験の問われ方（キー概念）
データベース（Database）大量のデータを一カ所にまとめて蓄え、簡単に検索ができるように整理したもの（紙や Excel ファイルも該当する）。
データ（Data）コンピュータで処理されるデジタル情報。内部的には 0 または 1 のビット（bit）の集まり。
DBMS（データベース管理システム）Oracle や MySQL 等、データベースを専門に管理するシステム。
データベース操作言語データベースを操作するための専用言語（SQL 等）を持つ。
整合性（Integrity）の維持記録されるデータの整合性（Integrity）を維持する機能を持つ。
マルチユーザ & トランザクションMulti-user を前提とし、トランザクション（Transaction）処理機能を持つ。
不正アクセス・改ざん防止権限のない者によるアクセスを防止し、データの改ざんを防ぐ機能を持つ。
障害回復（リカバリ）障害回復のためのログ取得、バックアップ（Backup）やリカバリ（Recovery）機能を持つ。

1.1.2リレーショナル型データベース (RDB)重要

RDB は行と列からなる 2 次元の表形式（テーブル）で表現 ／ E. F. Codd 博士が提唱 ／ NULL は未定義（unknown）であり空白や 0 と異なる
基本用語同義語・試験キーワード
表テーブル（table）、リレーショナル（relation）
行レコード（record）、タプル（tuple: 組）、ロー（row: 行）
列カラム（column）、属性（attribute: アトリビュート）、項目
関連リレーションシップ（relationship）
RDB 核心概念詳細・定義キーワード
提唱者1970年、E. F. コッド（E. F. Codd）博士が提唱。数学の集合演算（Set operations）と関係演算（Relational operations）に基づく。
2 次元表形式（テーブル）データを 行（row） と 列（column） からなる 2 次元の表で表現する。
NULL 値何も格納されていない状態。未定義（unknown）を意味し、空白や 0 とは異なる。
主キー（PK: Primary Key）表の中で各行を唯一に識別するための列。
外部キー（FK: Foreign Key）他の表を参照して表同士を関連づけるための列。

1.1.3リレーショナル型以外のデータベースモデル理解

階層型：木構造（ツリー型）で子レコードはただ 1 つの親レコードしか持てず重複する（代表例 XML） ／ 網型：子レコードは複数の親レコードをもつことができる（言語 NDL）
モデル名データ構造親子関係・データ重複特徴・課題代表例・言語
階層型データベース

（子はただ 1 つの親しか持てない）

網(ネットワーク)型データベース
（Network DB）		 網目状構造 親 多 対 子 多
（子は複数の親を持てる）
レコード重複なし		 複雑な構造を表現可能だが検索経路が複数でき経路選択で処理速度に影響・構造が複雑化 NDL
（Network Database Language）

1.2.1SQL とは？重要

SQL は非手続き型言語で処理手順はオプティマイザが決定 ／ SEQUEL 由来で ANSI・ISO・JIS が標準化（SQL:1999 / SQL:2016）
項目特長・内容キーワード
名称の由来もともと SEQUEL（Structured English Query Language）に由来し、商標問題により SQL（Structured Query Language）に改名。
言語分類非手続き型言語（Non-procedural language）。「こういうデータをください」という命令のみを行い、処理手順は DBMS のオプティマイザ（Optimizer）が自動決定する。
標準 SQL 規格ANSI、ISO、JIS により標準化。完成度の高い SQL:1999 や最新の SQL:2016 などの規格がある。
基本 DML 命令命令文例処理目的
INSERTINSERT INTO 表 VALUES (...)表に新しい行を追加する命令
UPDATEUPDATE 表 SET 列 = 値 WHERE ...表内の指定した行の値を変更する命令
SELECTSELECT 列 FROM 表 WHERE ...表から特定条件の行を抽出（検索）する命令
DELETEDELETE FROM 表 WHERE ...表から指定した行を削除する命令

1.2.2SQL の種類重要

DDL（データ定義言語・スキーマ記述） ／ DML（データ操作言語） ／ DCL（データ制御言語） ／ TCL（トランザクション制御言語）
分類名（略称・和名）目的・役割（キーワード）代表的な SQL 文
DDL
（Data Definition Language / データ定義言語）		 スキーマ（Schema）やデータベースオブジェクト（表・ビュー・索引等）を定義・作成・削除する。 CREATE、DROP、ALTER、RENAME など
DML
（Data Manipulation Language / データ操作言語）		 表の中のデータを操作（検索・挿入・更新・削除）する。 SELECT、INSERT、UPDATE、DELETE など
DCL
（Data Control Language / データ制御言語）		 ユーザー権限やデータアクセス権を制御する。 GRANT（権限付与）、REVOKE（権限取消） など
TCL
（Transaction Control Language / トランザクション制御言語）		 トランザクション（Transaction）処理の確定や取消を制御する。 COMMIT（確定）、ROLLBACK（取消）、SAVEPOINT（保存点） など
階層レベル含まれるオブジェクト・定義要素
データベース（Database）各ユーザーの スキーマ（Schema）
スキーマ（Schema）テーブル（Table）、ビュー（View）、索引（Index）、その他オブジェクト

1.2.3SQL の文と句理解

文（Statement）は命令全体、句（Clause）は文を構成する各パーツ ／ SELECT 句（列の指定）・FROM 句（表の指定）・WHERE 句（行の絞込）
区分定義代表例
文（Statement）データを抽出・操作・定義する命令全体DDL: CREATE 文, DROP 文, ALTER 文
DML: SELECT 文, INSERT 文, UPDATE 文, DELETE 文
句（Clause）文を構成する個々のパーツSELECT 句, FROM 句, WHERE 句, ORDER BY 句, HAVING 句 など
SELECT 文の構成パーツ（句）役割・指定内容キーワード
SELECT 句取得する列の指定
FROM 句対象とする表の指定
WHERE 句対象とする行の絞り込み

1.2.4関数の利用理解

単一行関数（Single-row function）とグループ関数（Group function）に分類 ／ SELECT 句・WHERE 句・HAVING 句などで使用
関数分類処理の特徴・挙動使用可能な主な句
単一行関数
（Single-row function）		1 行ごとに処理を実行し、行ごとに 1 つの結果を返す。SELECT 句、WHERE 句、ORDER BY 句 など
グループ関数
（Group function）		複数行（グループ）をまとめて集計処理し、1 つの結果を返す。SELECT 句、HAVING 句、ORDER BY 句 など

1.2.5Java 等のプログラムと DB の関係理解

SQL は Java などのプログラムに埋め込んで利用 ／ 各言語が連携してシステム全体を構成
システム階層役割使用技術・言語
フロントエンド（画面）ユーザー操作の受け付け・画面の作成と表示HTML, CSS
AP サーバー（ロジック）システム全体の制御・Java 実行環境（プログラム内に SQL を埋め込む）Java（JDBC 等）
DB サーバー（DBMS）SQL 命令に応じてデータの検索・追加・更新・削除を実行SQL, RDBMS（Oracle 等）
■ Java コード内での SQL 埋め込み例 (JDBC)

           + text.getText() + "%' ORDER BY itemid";
ResultSet rs = stmt.executeQuery(sql);
