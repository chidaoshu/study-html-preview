3.6.1関数とは?

SQL 関数の引数は 列名やリテラル値 ／ 戻り値として結果をひとつ返す
関数概念引数（入力）処理・働き戻り値（出力）
multiply(a, b)a, b（例：2, 50）2 値を掛け合わせる（内部処理は隠蔽）z（例：100）
SQL 関数列名 や リテラル値（() 内に カンマ区切り）各行またはグループごとの処理計算・変換結果

3.6.2SQL 関数の種類重要

単一行関数は 1 行ごとに処理し 1 行ごとに結果を返す ／ グループ関数はグループごとに集計
関数の種類処理単位戻り値の行数主な用途・例
単一行関数SQL により戻される行の 1 行ごと各行に対して 1 行ずつLOWER, UPPER, SUBSTR, ROUND 等
グループ関数表全体 または 小グループごとグループごとに 1 行（集計）SUM, AVG, COUNT, MAX, MIN 等
単一行関数はリテラルを直接引数に指定でき dual 表で確認できる
dual 表のデータ構造確認 ／ 1 行 1 列のダミー表 
SELECT * FROM ⟦dual⟧;

3.7.1文字関数の種類重要

文字関数は文字を引数に受け取り 文字や数値を戻す
関数説明戻り値の型
LOWER(s)すべて小文字に変換する文字
UPPER(s)すべて大文字に変換する文字
INITCAP(s)単語ごとに先頭を大文字、残りを小文字に変換する（記号区切り）文字
LPAD(s, n, c)指定桁数に満たない場合、左側に指定文字を埋める文字
RPAD(s, n, c)指定桁数に満たない場合、右側に指定文字を埋める文字
TRIM(c FROM s)文字列の前後から指定文字（1字のみ）を取り除く文字
REPLACE(s, o, n)文字列中の旧字 o を新字 n に置き換える（省略で削除）文字
CONCAT(s1, s2)文字列1と文字列2を結合する（s1 || s2 と同じ）文字
SUBSTR(s, m, n)s の m 文字目から n 文字分を抽出する（n 省略で最後まで）文字
INSTR(s, f, m, n)s 中で検索文字 f が現れる位置を返す（m:開始位置, n:出現回数）数値
LENGTH(s)文字列の文字数を返す（2バイト文字も1文字）数値
LENGTHB(s)文字列のバイト数を返す（2バイト文字は2字）数値

3.7.2LOWER、UPPER、INITCAP

LOWER は小文字・UPPER は大文字へ変換 ／ INITCAP は各単語の頭文字を大文字にする（記号が単語の区切り）

SELECT ⟦INITCAP⟧('oracle_master@orcl.com') FROM dual;
例3）INITial CAPtion ＝ 各単語の頭文字だけ大文字 ／ _ と @ と . が区切りと判定される

3.7.4TRIM 関数

TRIM は文字列の前後から指定文字を取り除く ／ 指定文字に文字列は使用不可（1字のみ）
TRIM 関数 ／ 指定文字の削除と LEADING / TRAILING / BOTH オプション
SELECT TRIM('-' FROM '---SCOTT---') FROM dual;
例1）前後から指定文字（'-'）を取り除く
SCOTT
SELECT TRIM('-' FROM '---SC⟦--⟧OTT---') FROM dual;
例2）途中の '--' は残る ／ TRIM が見るのは前後だけ（パディングの逆操作）
SC--OTT
SELECT TRIM(⟦LEADING⟧ '-' FROM '---SCOTT---') FROM dual;
例3）LEADING ＝ 先頭のみ削除（LEAD ＝ 先導）
SCOTT---
SELECT TRIM(⟦TRAILING⟧ '-' FROM '---SCOTT---') FROM dual;
例4）TRAILING ＝ 末尾のみ削除（TRAIL ＝ 尻尾）
---SCOTT
SELECT TRIM(⟦BOTH⟧ '-' FROM '---SCOTT---') FROM dual;
例5）BOTH ＝ 両方から削除 ／ オプション省略時の既定
SCOTT
SELECT TRIM('　SCOTT　') FROM dual;
例6）指定文字も省略 → 前後の空白を削除（最も多い用途）
SCOTT

3.10.2RR 日付書式

RR 書式は 2000 年問題に対応するために生まれた書式 ／ 年の下2桁をもとに上2桁を補う書式です
現在の年の下2桁 ＼ 指定したデータの下2桁0〜4950〜99
0〜49（例：2022年）同じ世紀（上2桁が同じ）前の世紀（100 年前）
50〜99（例：1999年）次の世紀（100 年後）同じ世紀（上2桁が同じ）
RR 書式による世紀の補完 ／ 2000 年問題対応書式

TO_CHAR(TO_DATE('49-12-31','rr-mm-dd'),'yyyy-mm-dd')
FROM dual;
指定年 78 → 1978 年、指定年 49 → 2049 年に補完
